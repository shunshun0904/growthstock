probe
# 1行目で実験17（TabICLv2）の実行内容を指定する。
#
#   probe                   所要時間とメモリの実測・外挿だけ。本走はしない
#   run [上限] [数] [同時]  本走
#                           上限 = 文脈に入れる訓練行の上限（0 で全行）
#                           数   = TabICL 内部のアンサンブル数（既定8）
#                           同時 = 同時に流すアンサンブル数（既定2）。
#                                  メモリの上限を決める。精度は変わらない
#   no                      何もしない
#
# 例:
#   probe
#   run 0 8 2         全訓練行を文脈に入れ、アンサンブル8（最も素直な設定）
#   run 8000 4 1      直近8,000行に絞り、アンサンブル4・同時1
#                     （CPU の予算やメモリが足りないとき）
#
# なぜ最初が probe か
# ------------------
# TabICL は GPU 前提の設計（H100 で 50,000行×100列を10秒未満）で、
# CPU で何倍掛かるかは公表されていない。全10窓を回してから
# 「6時間で終わらなかった」と分かるのは、CI の実行1回を捨てることになる。
# 先に文脈の行数を変えて実測し、外挿してから設定を決める。
#
# 本走は窓ごとに out-of-fold を書き出し、data-raw Release に持ち回す。
# 予算切れで止まっても、もう一度走らせれば残りの窓から続く。
#
