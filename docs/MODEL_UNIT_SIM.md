# 選び方4通り × 1日1件 × 1単元（100株）× 枠3: 損益・資産回転率・乗り換えの腕（実験59・2026-10-03）

`research/exp/e59_unit_sim.py` / Actions の Run Experiment（run 37090951802、3b2367f）/
結果 `research/_data/oof/e59_summary.csv` ・ `e59_by_year.csv` ・ `e59_trades.csv`（artifact。取引の一覧は
銘柄コードと買値を含むので公開の場には出さない）。

運用者の依頼（2026-10-03）

> 銘柄の選び方を gbdt3モデルで97.5%以上 / 95%以上、全5モデルで95%以上 / 90%以上 の4パターンで、
> 条件を満たす銘柄を1単元（100株）を購入した場合の損益シミュレーションをしてほしいです。
> 同時保有数は３銘柄なので、資産回転率も指標に入れたいです。

> 1日での購入数はベストなもの1銘柄にしてほしいです。なぜならスコアがいつ予測したのかという日付に
> 依存するので。購入日付も分散させたいので。ですので、問題はすでに3つ持ってる際に、よりよい4つ目の
> 候補がでた際にどれを売るかという話になるかと思います。そもそも銘柄を乗り換えるかどうかも含めて。

## 結論を先に

1. **乗り換えは、どの規則でも持ち切りに勝てない。** 「一番古い玉」「含みが一番悪い玉」「格が一番低い玉」
   「含み益の薄い玉」のどれで売っても、売った玉を持ち切っていたほうが良かった割合が 53〜78%、
   平均で −1.9〜−4.8pt 取り逃す（§3）。実験34（`docs/PLAYBOOK.md`「乗り換え…はやらない」）と同じ向き。
   例外は「伸びていない玉（買ってから5営業日以上で含み0%以下）」で、取り逃しはほぼ0（−1.2〜+0.6pt）
   だが、乗り換えの回数が少なく（年2〜9回）、1取引も総損益も上がらない。**どうしても売るならこの形**。
   **答え: 3つ持っているときに4つ目が出ても、売らずに見送る。**
2. **1取引の質は「全5モデル 95以上」が一番良い**（+4.18%、勝率 64%、+20%到達 20%）。次が
   「GBDT3 97.5以上」（+2.99%、61%、21%）。基準を緩めると取引は増えるが1取引は落ちる
   （GBDT3 95: +1.56%、全5モデル 90: +2.00%）。ただし SE が 1.3〜1.8pt あり、4つの差は誤差の範囲
3. **円の総損益は4つとも 50〜66万円（5.3年、100株ずつ）で並ぶ。** 年あたり 9〜12万円。1取引の質が高い
   選び方は取引が少なく（年 8.5〜10.6回）、緩い選び方は取引が多い（年 16〜18回）ので、掛け算で揃う
4. **必要資金は 146〜183万円**（3枠が最も埋まった日の買付額の合計。1取引の買付額の中央値は 18〜24万円、
   最大 77〜130万円）。年あたり損益 ÷ 必要資金 = **+6.2〜7.3%/年**。資金の回転は年 1.5〜2.6回で、
   枠の稼働率は 21〜45%。**厳しい選び方では枠3の資金の 7〜8割が遊ぶ**
5. **乗り換えは回転を上げるが利益は上げない。** 「一番古い玉を売る」で回転は 1.9→3.2〜5.4回/年、取引は
   約2倍、保有日は 18→10日になるが、1取引は +1.3〜1.9% に落ち、総損益の差は ±30万円の中（誤差の範囲）
6. **参考の現行の規則（GBDT3 90・発火8件以上・上位2件・乗り換えなし）は、この OOF では +0.67%（126件）。**
   前のモデル（205列・9/20 学習）の OOF で測った +2.20%（`docs/PLAYBOOK.md`）より低い。
   モデルの差か期間の差かは分けていない。SE 1.0pt なので、まだ結論にしない
7. **百分位を「その日より前の分布」で出すと、「OOF 全体の分布」より1取引が 1〜2pt 低く、取引は 1.4〜1.5倍。**
   後者は後半ほどスコアが高いので選定が 2024〜25年に偏る（先の値を見ている）。本命は前者（画面と同じ立場）

**運用者の決定（2026-10-03）**: 候補の発火条件は **全5モデル 95以上** でいく。1日1銘柄。あとは資金の
状態も見て目視で買うこともある。乗り換えはしない。

## 測り方

- **モデルと OOF**: 本番5モデル（LightGBM / XGBoost / CatBoost / ロジスティック回帰 / MLP、2026-09-27 学習、
  `all_plus_prog_listing_vol_book` 239列）の out-of-fold。16,235行 / 1,274営業日 / 2021-05-06〜2026-08-25
- **百分位**: そのモデルの OOF の分布のうち、そのスコアより低い割合 × 100（画面の `pctHistorical` と同じ式）。
  本命は **過去分布**（その日より前の OOF だけ。過去の行が 500 未満の日は判定しない → 2021-07-30 から）。
  参考に **全期間分布**（OOF 全体。`research/live_track.py` の見込みと同じ約束）
- **選び方**: 合議のモデルすべてが基準の百分位以上。**1日1件**（合議の最小の百分位 p_min が最大。同点は
  LightGBM のスコア順）。発火数の足切りは置かない。持っている銘柄は買い増さない
- **売買**: 翌営業日の寄りで 100株。+20% の指値（買った日の高値から見る）、届かなければ 20営業日目の終値。
  同時に 3銘柄まで。手数料・税・配当・スリッページは含まない。終わっていない玉は数えない
- **乗り換えの腕**（枠が埋まっているときに候補が出たら）。判断はその日の終値、売りも買いも翌営業日の寄り。
  売った玉は「持ち切っていたら」規則どおりの出口で幾らだったか（持ち切り）も数える

  | 腕 | 売る玉 |
  |---|---|
  | A なし | 埋まっていたら見送る（先着順。実験33〜35・実運用の追跡と同じ） |
  | B 一番古い玉 | 保有日数が最長 |
  | C 含みが一番悪い玉 | 終値での含み損益が最小 |
  | D 格が一番低い玉 | 入ったときの p_min が最小の玉を、候補の p_min がそれより高いときだけ |
  | E 伸びていない玉 | 買ってから 5営業日以上たって含みが 0% 以下の玉があるときだけ、その中で一番悪い玉 |
  | F 含み益の薄い玉 | 含み益が 0% 以上の玉があるときだけ、その中で一番薄い玉（実験34 の運用者案の形） |

- **円の損益**: 買付額 = **調整前の始値 × 100株**（分割調整後の値だと、後で分割した銘柄の当時の金額を
  小さく見積もる。日足の 12.6% の行で調整前と調整後が違う）。損益 = 買付額 × 収益率（値動きは調整後）
- **投下資本**: その営業日に持っていた玉の買付額の合計。**必要資金** = その最大、**平均投下** = 平均（空き枠は 0）
- **回転** = 年間の買付額 ÷ 必要資金（用意した資金が年に何回まわるか）。**稼働** = 枠が埋まっていた営業日の割合。
  年間は暦の日数で割る（5.3年）
- 腕 A は `live_track.forward` + `simulate` と同じ取引になることをテストで固定（`tests/test_e59_unit_sim.py`）

底で売っている（実現 −0.3〜−1.4%、持ち切りなら +0.5〜+4.0%）。E（伸びていない玉）だけは持ち切りも
悪い（−0.8〜−4.8%）ので切っても損にならないが、その分を入れ替えた玉（+2.7〜+4.7%）で取り返しても
総損益は腕 A と同じ程度（§2）。

## 注意

- OOF は「その行より前のデータだけで学習したモデル」の採点で、本番の毎週の再学習とは学習の頻度が違う
  （本番は毎週、OOF は窓ごと）。1つのモデルの OOF で測った数字なので、過適合の確認（窓をずらす・種を変える）は
  していない。4つの選び方の差（1取引で 1〜2.6pt）は SE（1.3〜1.8pt）と同じ大きさ
- 乗り換えの結論は実験34（別のモデル・別の期間・1日2件）と同じ向きなので、こちらは2回目の確認になる。
  腕 E の「5営業日・0%」は1通りしか測っていない
- 1単元 100株なので買付額は銘柄の株価で決まり（中央値 18〜24万円、最大 77〜197万円）、円の総損益は
  高い銘柄の当たり外れに引きずられる。1取引の % と円の両方を見ること
- 手数料・税・配当・スリッページを含まない。+20% の指値は「高値が届けば約定」と見ている（寄りで飛べば
  実際はもっと取れる）。20営業日目は終値で売れると見ている
