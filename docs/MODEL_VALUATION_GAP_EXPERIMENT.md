## 現金区分なしモデルの追加（2026-11-15追補）

運用者の承認により、欠損現金を0と補完せず、現金を控除も別建て加算もしない専用EVAを追加した。
親会社の利益・自己資本・実績配当性向と外生KeによるRIMを対照にする。
主EVAは年次財務、RIMは四半期更新を含むTTMで、同一行でも財務の鮮度・定義は異なる。

現在の51推論対象、118,467銘柄営業日での実測：

| 指標 | 有効件数 | 割合 |
|---|---:|---:|
| 現金区分なしEVAの理論株価 | 46,893 | 39.583% |
| 外生KeのRIM理論株価 | 88,452 | 74.664% |
| EVAの評価乖離率 | 46,843 | 39.541% |
| RIMの評価乖離率 | 87,917 | 74.212% |
| 両方の乖離率がある共通行 | 42,632 | 35.986% |
| 現金区分必須の営業EVA | 0 | 0% |

最新営業日2026-11-13の51銘柄では、EVA25銘柄、RIM44銘柄、両方の乖離率24銘柄。
市場価格が欠損・0の行では、理論価値があっても乖離率を生成しない。
これは現在の推論対象での算出率で、全東証銘柄での算出率ではない。

## 2026-11-15の実データ結果

対象は現行`predictions.json`に含まれる直近3推論日の51銘柄。
2016-10-03〜2026-11-13の利用可能期間、合計118,467銘柄営業日を生成した。
これは**現在の推論対象での実装確認**であり、過去の全学習銘柄での算出率ではない。
株価・TOPIXの最終日は2026-11-13、国債金利の最終基準日は2026-11-12。

| 系列 | 有効件数 | 銘柄営業日ベースの算出率 |
|---|---:|---:|
| 現金控除なしROIC・税率30%（参考） | 68,565 | 57.877% |
| 現金控除なしROIC・実績税率（参考） | 61,882 | 52.236% |
| 簿価WACC・ERP5%・税率30% | 84,328 | 71.183% |
| 識別済み非事業性現金による営業投下資本ROIC | 0 | 0% |
| 主EVA理論株価・評価乖離率・EV_gap | 0 | 0% |
| 乖離率の252日Zスコア | 0 | 0% |

保存済みEDINET財務には現預金があるが、営業必要現金と非事業性現金の区分はない。
そのため、全118,467行で`non_operating_cash_unidentified`となった。
必要な現在・比較年度の現金区分がなく、営業投下資本ROICも算出できない。
既存の「現金全額控除ROIC」や欠損を0にした価格で代用していない。

理由は重複を許して集計する。有利子負債欠損25,304行、非支配持分欠損38,066行、
年度情報の不足・400日超18,440行、株数不明6,810行も存在する。
`AdjFactor`だけでは分割・併合と株価由来のライツ補正を区別できないため、
保存データに`ExRT`がない非1係数を跨ぐ5,034行も株数の基準未確認とした。
その後の財務開示で新しい株数基準を確認できる場合に限り計算を再開する。

集計・コードおよび入力のSHA256・実験前検査は
[2026-11-15の保存記録](experiments/roic-wacc-2026-11-15/summary.json)に残す。
公開Gitには生の財務残高・全日次データを入れず、集計とハッシュだけを保存する。

## 学習を止めた理由

保存済みのE120/E121検証用マート（2018-04-03〜2026-10-02、22,110行・3,748銘柄）へ結合した。
最新版の本番マートの再構築・本番再学習を実施した結果ではない。

- 既存373特徴量と元の行は一致した。
- 現在の表示用51銘柄のうちマートと一致するのは50銘柄で、過去の3,698銘柄の系列が不足する。
- 結合後の主評価乖離率は0行。`incomplete_historical_universe`と`no_observed_fundamental_valuation_gap`で停止した。
- 固定パラメータ比較、各群の再チューニング、20日先ランキングの外側評価は**いずれも未実施**。
- 特徴量重要度、IC、収益改善幅、本番採用可否は評価していない。

現在の51銘柄に限定して過去を学習すると、現在のモデルが選んだ銘柄への選択偏りが生じるため、
そのような代替実験で不足を隠さない。既参照期間の結果を独立した将来検証とも扱わない。

## 再開に必要なデータと代替案

1. 根拠書類・公表日付きの当期・前期の非事業性現金区分。原本で区分できない場合は、営業必要現金の推計定義に別の仮定が必要となる。
2. 有利子負債・リース・非支配持分の範囲の照合。必要なら出典付きレビューCSVで補う。
3. 株価比から逆算しない、日付・種類付きの分割・併合情報。ライツは新しい株数開示との照合が必要。
4. `--universe-dataset`による過去の全学習対象の系列。公開用JSONは現在の推論対象だけに制限する。
5. 原本訂正履歴と新しい未参照期間。保存APIの訂正未照合を、日付の先読み防止だけで解消したとは主張しない。

営業必要現金の推計は今回の標準モデルには導入していない。
簿価構成、固定リスクプレミアム、信用スプレッド1.5%、5年ROIC収束、成長率0〜3%も
探索的な感応度仮定であり、当該銘柄の真の資本コスト・成長予測として実証されていない。
この制約は計算が価格非依存であることとは別問題である。

## 比較の事前定義

| 腕 | 内容 |
|---|---|
| A | 現行`features.DEFAULT_PRESET`の373列 |
| B | A＋ROIC・簿価WACC・税・鮮度・入力品質 |
| C | B＋評価乖離率・ログ乖離率・EV_gap・ROIC−WACC |
| D | C＋252日Z/百分位・5/20/60日変化・平均・分散・価値変化・開示更新等 |
| R | A＋外生RIMのROE・Ke・配当性向・鮮度・乖離率・時系列 |
| P | Dの値だけを日付内・欠損パターン内で入れ替える対照。品質フラグは保持 |
| M | B＋同じ窓で作る価格・会社予想PER・PBRの時系列対照 |

追補後のC/Dは現金区分なしEVAの系列、RはRIMの系列を使用する。
Mは「乖離率が単なるモメンタムの追加列なのか」を調べるための追加対照。
既存の価格・PER・PBR・ROE・モメンタムとの順位相関も出すが、相関から因果性は主張しない。
すべての腕で同じ訓練行・評価行を使い、欠損を含む全行と、EVA/RIM両方の乖離率がある共通行の成績を分ける。
欠損のためにAだけ別の銘柄集合になった比較はしない。

日次LambdaRankの目的変数は翌営業日寄りから20営業日目終値の収益。
既存`ltr.attach_r20`・段階・利得・NDCGを再利用する。
主指標は日付内NDCG@5。上位5件の20日収益、日付内上位10%の超過収益、Spearman IC、
期間別結果、特徴量重要度、算出可能率を保存する。
`--classification`で固定+10%/+15%の分類も同じ窓・行で補助検証する。

## 時系列とパラメータ

- 外側は36か月訓練・6か月評価を順送り。
- 各銘柄の実際の日足で20日目の結果確定日を求め、評価開始時点で未確定の訓練行を除外。
- 現在の51銘柄を過去の全期間へ固定して学習することは禁止。歴史上の学習ユニバースの系列が必要。
- 固定比較の設定は事前の中立値を全腕で共通に使う。後日チューニングされた現在のパラメータを過去の外側へ使わない。
- 再探索は全腕で同じ30候補・同じ3つの内側6か月窓。候補は中立設定＋既存探索範囲からの固定RandomSampler。
- 各腕は自身の内側NDCG/APで別々に選ぶ。外側の成績は選択に使わない。
- 全腕・全窓の設定を凍結してから外側評価を開始する。最終学習種は42/43/44、木200本。
- この初期探索の予算・反復は、本番採否規則の全要求を満たすという主張ではない。

```sh
# 最初は必ず算出率・対象範囲・実行可否を確認（学習しない）
python research/exp/e132_valuation_gap.py --dataset /private/current-features.parquet \

# 前処理がreadyの場合に限り実行
python research/exp/e132_valuation_gap.py --dataset /private/current-features.parquet \

```

`preflight.json`の`ready`には全過去銘柄の系列と非欠損の主価値・乖離率が必要。
満たさなければ`blocked`と理由を出して停止し、学習結果・改善幅を作らない。
作業中の調査集計だけを、比較が完了した性能レポートと呼ばない。

追補では全日次系列の代わりに、`build_valuation_feature_mart.py`が日次の過去窓を計算した後の
元キーだけのマートを`--feature-mart`で渡せる。全元キー・データセットSHA256・各出力チャンクSHA256を検査する。
RIM乖離率が0件でも停止する。資料の不足で値を作れない行は欠損のまま保持する。

```sh
python research/exp/e132_valuation_gap.py --dataset /private/dataset.parquet \
  --feature-mart /private/valuation-features --prices /private/adjusted-prices.parquet \
  --output /private/e132-retuned-2fold --run --retune --last-folds 2 \
  --trials 30 --inner-folds 3 --trees 200 --threads 1 --jobs 2
```

CVは外側評価行を含まない学習データだけを別プロセスへ渡す。未確定ラベル混入も入口で拒否する。
各群・各窓のCVだけを独立に並列化し、親プロセスがすべての設定を凍結してから外側を評価する。
候補ごとに入力指紋付きで保存し、同じ設定の続行だけを再利用する。
株価系列の解析自体の欠損・事後訂正まで解消したとは主張せず、本番採用はしない。
