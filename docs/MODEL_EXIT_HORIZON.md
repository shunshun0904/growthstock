# 20営業日を越えて持つ出口と、ラベルを「40営業日で +30%」に厳しくする案（実験65・66、2026-10-08）

`research/exp/e65_exit_horizon.py` / `research/exp/e66_label_strict.py`（手元の4コアで実行。
Release の生データ・5モデルの OOF・`build_dataset.py` で作り直したデータセットを使った）。
結果 `research/_data/oof/e65_*.csv` / `e66_*.csv`。**実測値のみ**を記載する。

運用者の問い（2026-10-08）

> 20営業日以内に購入時価格の +10% 上昇していればその時点で売る（購入時に指値）。+10% に到達して
> いなくとも購入時価格と比較してプラスであればその時点で売る。20営業日時点でマイナスであれば一旦は
> 保有、というルールで売却をするロジックですが、一応ブレイク銘柄なので、10% 到達時点で売るか、
> そのまま保有するか、20営業日時点でもプラスでもそのまま保有を継続するということもあり得るのかなと
> 思っています。期待値的には、売らずに持っておいた方がよいのかどうかを検証したいです。
> というより、40営業日後に +30% 到達（今よりラベルをシビアにする）とかでモデルを構築した方が
> よさそうでしょうか？

## 結論を先に

1. **今のルールでいちばん損をしているのは「+10% の指値」。** +10% に届いた銘柄（現行の選定で 41.5%、
   GBDT3 90 で 35.1%）は、そのまま20日目まで持つと平均 +14.1% / +12.9%、40日目で +17.1% / +14.6% に
   なる。指値で +10% に止めると 1取引の平均が 20日目の終値で売る場合より **−1.70pt（対SE −2.8、
   勝ち窓 1/5）/ −1.03pt（−4.1、3/10）** 下がる。実験32・41 §9・§11 と同じ向きで、3回目の確認。
2. **「20日目にマイナスなら建値まで持ち越す」は、1取引では +0.3pt 上がるが、1日あたりでは下がる。**
   指値を外して「20日目プラスで売り・マイナスは建値まで（上限40日）」にすると +5.30% / +3.86%
   （20日目の終値 +5.01% / +3.54% との差 +0.29pt（対SE +1.2）/ +0.32pt（+3.3、勝ち窓 8/10））。
   持ち越しは取引の 31% / 36% で、建値に戻るのは半分（15% / 20%）、上限40日まで戻らないのが 16% / 17%
   （その平均 −9.9% / −12.4%）。保有は 20日 → 24日に延びる。
3. **20日を越えて持つと 1取引の平均は上がる（+2pt）。40日目の終値で +7.30% / +5.47%
   （差 +2.29pt 対SE +2.6 勝ち窓 4/5 ／ +1.93pt 対SE +6.9 勝ち窓 9/10）。** 20日目から40日目の追加分は
   平均 +2.3pt / +1.9pt（勝率 61% / 58%）で、20日目にプラスの玉（+2.9 / +2.0）もマイナスの玉
   （+1.0 / +1.8）も同じ向き。40日目から60日目は伸びない（60日目 +6.94% / +5.34%）。
4. **ただし1日あたりの収益は 20日目の終値が最も高く（0.250% / 0.177%、40日目は 0.182% / 0.137%）、
   枠3の模擬の年率でも 20日目の終値が上。** 現行の選定（1日1件・枠3）で 20日目の終値 +20.2%、
   40日目の終値 +15.3%、現行ルール（上限60日）+13.0%。GBDT3 90（上位2件・発火8件以上）で
   +18.8% / +16.4% / +15.0%。枠の数を 1・2・3・5 と変えても、20日目の終値が 40日目の終値を
   下回ったのは 8通り中 1通り（GBDT3・枠5、+10.6% 対 +11.2%）だけ。長く持つと枠が埋まって見送りが
   増える（現行の選定で 46件 → 60件。候補は同じ日に固まる）ので、1取引の +2pt は回転の低下で消える。
5. **「+10% に届いても売らずに持つ」「20日目にプラスでも持ち続ける」は、1取引ではどちらも持ち切り
   （40日目の終値）と同じ水準になる（指値なし・プラスは持ち続け 上限40日: +7.29% / +5.14%）。**
   中央値は下がり（+4.96 / +2.09）、勝率も下がる（63% / 55%）。平均を押し上げているのは、届いた
   後もさらに伸びる上位の玉。
6. **+20% / +30% の指値を 40日置く形は、40日目の終値とほぼ同じ**（+6.75 / +6.91% と +4.96 / +5.21%）。
   +30% に 40日以内に届くのは 12.8% / 9.7% しかなく、指値が効く場面が少ない。
7. **運用としては、指値を外して 20日目の終値で売るのが、1日あたり・年率ともに最も良い。** 持ち越し
   （20日目にマイナスなら建値まで）は 1取引では少し上、年率では 現行の選定で下（+19.2% 対 +20.2%）、
   GBDT3 で上（+27.3% 対 +18.8%）と割れる。どちらを選んでも、+10% の指値を置くよりは良い。
8. **ラベルを「40営業日で +30%」にしても、学習し直しで選定の実収益は上がらなかった（実験66、§6）。**
   固定しきい値のラベルは正例率が 10% 前後に落ちて（現行 17%）窓ごとの正例が減り、日次ボラの高い帯に
   正例が偏る。今の本番モデルの上位（全5モデル 95以上）は、学習していない +30%/40日 のラベルでも
   母集団の 1.5倍（12.6% 対 8.5%）を当てている。詳しい数字は §6。

## 測り方

- **選定**: 本番5モデル（2026-10-04 学習、239列）の out-of-fold（Release の `oof.parquet` /
  `<algo>_oof.parquet`、16,297行、2021-05-06〜2026-09-01）に、画面と同じ「過去分布の百分位」
  （その日より前の OOF の分布。実験59 の `pct_expanding`）を付け、2つの基準で選ぶ
  - **現行**: 全5モデル 95以上・その日のベスト1件（運用者の決定 2026-10-03）。基準を満たした 104件
  - **GBDT3 90以上**: ブースティング3モデルすべて 90以上（実験41 と同じ）。1,154件。件数が多いので再現性の確認用
- **値動き**: 翌営業日の寄り（`AdjO[t+1]`）で買い、1〜120日目の四本値（実験41 の `forward`）。
  1取引ごとの表は **120日目まで値動きが揃う取引だけ**（全出口で同じ取引。現行 94件・GBDT3 1,047件）
- **出口**（`e65_exit_horizon.exit_rule`。約定の仮定は実験41 と同じ保守側。`tests/test_e65_exit_horizon.py` で固定）
  - 指値: 1〜20日目（40日の形は 1〜40日目）に高値が 買値×(1+X) に届けば、ちょうど +X で売る（飛び越えても）
  - 20日目の終値が買値以上なら「売る」か「持ち続ける」、買値未満なら「売る」か「建値まで持ち越す」
  - 持ち越した玉は 21日目から建値の指値（高値が建値に届けばちょうど 0% で売る）。上限の日の終値で必ず売る
  - 同じ日に複数が当たれば 指値 → プラ転 → 終値 の順。手数料・税・配当・スリッページは含まない
- **比べ方**: 「20日目の終値」との **同じ取引の差**（差 ÷ 差の標準誤差 = 対SE）と、本番の OOF と同じ
  窓（36/6/6か月・エンバーゴ20営業日）ごとの差の勝ち負け（現行の選定は 5窓、GBDT3 は 10窓）
- **枠3の模擬**: 実験41 の `slot_sim`。空き枠があれば翌営業日の寄りで買う（先着）、資金は買うたびに
  「現金＋建玉の簿価」の 1/3、月利は実現ベース。現行の選定は 1日1件、GBDT3 は PLAYBOOK の形
  （発火8件以上の日・上位2件）
- **していないこと**: 窓の切り方をずらした確認（実験41 §6）は、5モデルを学習し直さないとできないので
  していない。1つの OOF で測った数字なので、切り方を変えると順序が入れ替わる可能性は残る

### 6-4. 読み方

1. **+30% のラベルで学習したモデルは、+30% に届く銘柄を3倍見つける（上位10% の 24.9% 対 8.5%）が、
   上位の平均収益は下がる（20日 +0.22% 対 +2.32%、40日 −0.12% 対 +3.58%）。** 外れたときの損が大きい
   （−10% 未満が 34.6% 対 9.8%）。上位の 7割が日次ボラの最高帯で、最低帯は 0.1%。
   **モデルが「+30% 上がりそうな銘柄」ではなく「値動きの荒い銘柄」を選ぶようになる**
2. 40日の物差し（ret_o1_40）でも同じ。新ラベルは40日先を見て作ったのに、40日持っても現行ラベルの
   上位のほうが +3.7pt 高い
3. 実験52（目的を収益の回帰にした腕 R）・実験54/55（σ の窓を長くしたラベル）と同じ現象。到達の
   しきい値をボラから切り離すほど、モデルは高ボラ側に寄り、順位は良くなっても運用の実収益は上がらない
4. **判定: 「40営業日で +30%」の固定ラベルには変えない。** 変えるなら σ 正規化を残したまま k と h を
   上げる形（例: 2ヶ月内 +1.7σ）になるが、それは実験55 で σ の窓を変えたときと同じく、運用規則の取引で
   現行に一貫して勝つことを先に示す必要がある（`docs/MODEL_ADOPTION_RULES.md` §7）
5. この実験は LightGBM 1本・本番の木の形のまま（探索し直しなし）・窓の切り方1通り。新ラベル向けに
   探索し直せば差は縮むかもしれないが、6-1 の偏り（ボラで正例率が 8倍違う）は探索では消えない

## 注意

- 出口の比較（§1〜§5）は本番5モデルの OOF 1本で測ったもの。窓の切り方をずらした確認はしていない。
  現行の選定は 94件（5窓）しか無く、対SE が 2 を越えたのは「+10%指値は下げる」「40日持つと1取引は上がる」
  の2つ。GBDT3 90（1,047件・10窓）で同じ向きが出ているので、向きは信じてよいが、差の大きさは幅がある
- 枠3の模擬は 1本あたり 27〜137件で、年率の水準は切り方や枠の数で大きく揺れる（§4）。順序だけを読む
- 持ち越し（建値まで待つ）の上限は 40 / 60 / 120日を置いた。「上限なし」は模擬できない。上限を延ばすほど
  建値で売れる割合は増える（15% → 25%）が、戻らなかった玉の損は深くなる（−9.9% → −25.4%）
- 約定はすべて保守側（指値はちょうどその値、窓を開けて飛び越えた分は数えない）。実際の指値売りはこれより
  少し良くなるが、§3 の「届いた後の伸び」（+4pt / +7pt）を埋める大きさではない
- 手数料・税・配当・スリッページは含まない。持ち越しの含み損は時価で見ればこの表より深い時期がある
