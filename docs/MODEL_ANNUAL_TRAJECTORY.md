# 年単位の業績の軌道（悪化 → 立て直し → 新高値）は効くか（実測・2026-09-21）

## 結論を先に

1. **特徴量1本ずつの検出力は「弱いが、方向は揃っている」。** 62本のうち
   |z|>2 を越えたのは 7本（偶然なら 3本）。上位はどれも「2期前は伸びていて、
   前期に落ち、直近で持ち直した」形（`*_yoy3` / `*_vshape3` / `Sales_accel`）。
   落ち込みが無かった銘柄（`*_dip3` が 0）はむしろ負（z −1.8）。仮説の向きと合う。
2. **ただし大きさは小さい。** 最大でも上位10%で +1.4pt（`Sales_accel`）、
   V字などの二値特徴量は +0.3〜0.6pt。単体では、モデル全体の実収益
   （+1.2〜1.6pt）に比べて数分の一。
3. **モデルに足すと、実収益は +0.4〜0.5pt 上がる方向だが、足切り（z>2）は
   越えない（実験21）。** 依頼の文言どおりの「前年比・2年前・3年前」20列を
   足した腕 B が `ret_o1_20` で +1.12 → +1.61pt（z +0.70）、`ret_o1_40` で
   +1.26 → +1.76pt（z +0.77）。最悪の窓が −2.41pt → −0.04pt に縮み、勝ち窓が
   8/10 → 9/10。差はノイズ床（0.143pt）の3倍あるが、窓ごとのばらつきに対しては
   有意でない。**「有望だが未証明」。本番の特徴量には入れない。**
   軌道の形（V字・回復など）をさらに足した腕 C は B と差が無い（z −0.08）。
4. EDINET の明細（販管費・設備投資・有利子負債・のれん・従業員・浮動株）の
   軌道は、取得が揃い次第 同じ方法で測る（`research/exp/e22_edinet_screen.py`）。

## なぜ測ったか

母集団は78週ぶりの高値更新日。「業績が悪化し、立て直しを経て新高値」が
典型なら、**直近の値だけでなく 2年前・3年前の値と、年ごとの変化率**に
情報があるはず。既存の決算特徴量は四半期の刻み（q0〜q3）で、見ているのは
直近1年ほど。年単位で3期の軌道を見る特徴量は無かった。

EDINET DB の取得（1社1リクエスト、日 85社）を待たずに、J-Quants の通期開示
（`CurPerType == "FY"`）で先に白黒をつけた。EDINET で足せるのは J-Quants に
無い明細であって、軌道そのものの検出力はここで分かる。

## 実験20: 特徴量1本ずつの検出力

`research/exp/e20_annual_trajectory.py` / 結果 `research/_data/oof/e20_screen.csv`

作り方
- 年次パネル: 各 (Code, 年度末) について通期の**最初の開示**の値（訂正後の
  値で過去を上書きしない）。前期〜3年前は年度末の間隔が k年 ± 65日のときだけ
  連続とみなす（決算期変更をまたがない）
- 各サンプルには開示日 ≤ Date の最新の通期を merge_asof で付ける。
  400日より古ければ捨てる
- 対称変化率 sym(a,b) = (a−b) / ((|a|+|b|)/2)。符号をまたいでも定義できる
- 4項目（売上・営業利益・純利益・EPS）× 15種 + 営業利益率の変化 = 62本
- 検出力: 本番の out-of-fold と同じ 11窓で、特徴量が上位10%の行の
  `ret_o1_20` 平均 − 窓全体の平均。その窓平均 / SE を z とする

- 62本は互いに強く相関している（同じ4項目の組み合わせ）。7本が越えたと

## 実験21: 本番の特徴量に足すと実収益はどう動くか（A/B）

`research/exp/e21_annual_ab.py` / 結果 `research/_data/oof/e21_*.parquet`, `e21_summary.json`

| 腕 | 特徴量 | 列数 |
|---|---|---:|
| A | 本番の `all` | 151 |
| B | A + 変化率（4項目 × yoy1 / yoy2 / yoy3 / 2年 / 3年） | 171 |
| C | B + 軌道（加速・過去3期の山からの回復・落ち込み・V字・4年ぶり高値）+ 営業利益率の変化 | 193 |

公平にするための細工
- **パラメータは本番の `research/lgbm_params.json`（`all`）を全腕で共用。**
  探索を引き直すと、その引きの差（0.6〜1.5pt）が特徴量の差を覆い隠す
  （`docs/MODEL_TUNING_NOISE.md`）
- 行は同じ 16,220件（足すだけ。無い行は NaN で LightGBM に任せる）。
  足した列の充足率は 変化率 83.2% / 軌道 78.5%
- 種3つ（42 / 7 / 123）の確率平均。窓は本番の out-of-fold と同じ

### 分離力（out-of-fold、16,220件、正例率 18.51%）

| 腕 | PR-AUC | PR/正例率 | ROC-AUC | 日内AUC |
|---|---:|---:|---:|---:|
| A | 0.2574 | 1.39x | 0.5929 | 0.6047 |
| B | 0.2580 | 1.39x | 0.5939 | 0.6065 |
| C | 0.2583 | 1.40x | 0.5929 | 0.6036 |

分離力はほぼ動かない（実験20 の併合 AUC が 0.5 付近だったことと整合）。

### 実収益（上位10%、窓平均）

| 腕 | `ret_o1_20` | SE | 勝ち窓 | 最悪の窓 | `ret_o1_40` | SE | 勝ち窓 | 最悪の窓 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| A | +1.12pt | 0.53 | 8/10 | −2.41pt | +1.26pt | 0.44 | 9/10 | −1.65pt |
| B | **+1.61pt** | 0.47 | **9/10** | **−0.04pt** | +1.76pt | 0.48 | 9/10 | −0.27pt |
| C | +1.55pt | 0.54 | 8/10 | −0.34pt | +1.80pt | 0.65 | 8/10 | −0.61pt |

差の検定（z = 差 / √(SE_a² + SE_b²)、足切り z>2）

| | `ret_o1_20` | `ret_o1_40` |
|---|---:|---:|
| A → B（変化率を足す） | +0.49pt / z +0.70 | +0.50pt / z +0.77 |
| A → C（変化率 + 軌道） | +0.43pt / z +0.57 | +0.54pt / z +0.69 |
| B → C（軌道をさらに足す） | −0.06pt / z −0.08 | +0.04pt / z +0.05 |

### 読み方

- 2つの物差しで同じ向き・同じ大きさ（+0.5pt）。ノイズ床（同一設定で種だけ
  振ったときの窓平均レンジ 0.143pt）の 3倍あり、種のばらつきでは説明しにくい
- それでも z は 0.7。窓ごとのばらつき（SE 0.5pt）に対して差が小さい。
  **10窓では、この大きさの効果は有意にならない**（有意にするには差が
  +1.4pt 以上か、窓が4倍要る）
- 最悪の窓が −2.41pt → −0.04pt に縮んだのは、B の利点として一番大きい。
  ただし1窓の話で、次の窓で逆になることもある
- 軌道の形（C）は変化率（B）の上に何も足さない。木のモデルは変化率から
  V字や回復を自分で組めるので、明示的に渡す必要が無い
- **判定: 見送り（有望だが未証明）。** 本番に入れるのは、EDINET 版
  （明細の軌道を足したもの）で同じ向きの差が出て、合わせて z>2 を越えたとき

### EDINET 版で確かめること

J-Quants の通期は売上・営業利益・純利益・EPS の4項目しか無い。EDINET の
`research/edinet_features.py` は 18項目 × 10種 + 比率 18本 × 4種 = 252列を
作れる。取得（1社1リクエスト、日 85社）が 2,000行ぶん揃ったら、
`research/exp/e22_edinet_screen.py` で実験20 と同じ検定をし、通った項目だけを
腕 B に足して実験21 と同じ A/B を回す。

注意: EDINET の会社一覧は上場中の会社だけなので、母集団の行の 9% は
EDINET 特徴量が NaN になる（`docs/DATA_EDINETDB.md`）。A/B は同じ行で
比べるので影響しないが、本番で使うなら「上場廃止した銘柄の過去」を
学習に使えないことを受け入れる必要がある。
