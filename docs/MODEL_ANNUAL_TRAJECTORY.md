# 年単位の業績の軌道（悪化 → 立て直し → 新高値）は効くか（実測・2026-09-21）

## 結論を先に

1. **特徴量1本ずつの検出力は「弱いが、方向は揃っている」。** 62本のうち
   |z|>2 を越えたのは 7本（偶然なら 3本）。上位はどれも「2期前は伸びていて、
   前期に落ち、直近で持ち直した」形（`*_yoy3` / `*_vshape3` / `Sales_accel`）。
   落ち込みが無かった銘柄（`*_dip3` が 0）はむしろ負（z −1.8）。仮説の向きと合う。
2. **ただし大きさは小さい。** 最大でも上位10%で +1.4pt（`Sales_accel`）、
   V字などの二値特徴量は +0.3〜0.6pt。単体では、モデル全体の実収益
   （+1.2〜1.6pt）に比べて数分の一。
3. **モデルに足したときの効果は実験21（下）で判定する。** 足切りは z>2。
4. EDINET の明細（販管費・設備投資・有利子負債・のれん・従業員・浮動株）の
   軌道は、取得が揃い次第 同じ方法で測る（`research/exp/e22_edinet_screen.py`）。

## なぜ測ったか

母集団は78週ぶりの高値更新日。「業績が悪化し、立て直しを経て新高値」が
典型なら、**直近の値だけでなく 2年前・3年前の値と、年ごとの変化率**に
情報があるはず。既存の決算特徴量は四半期の刻み（q0〜q3）で、見ているのは
直近1年ほど。年単位で3期の軌道を見る特徴量は無かった。

EDINET DB の取得（1社1リクエスト、日 85社）を待たずに、J-Quants の通期開示
（`CurPerType == "FY"`）で先に白黒をつけた。EDINET で足せるのは J-Quants に
無い明細であって、軌道そのものの検出力はここで分かる。

## 実験20: 特徴量1本ずつの検出力

`research/exp/e20_annual_trajectory.py` / 結果 `research/_data/oof/e20_screen.csv`

作り方
- 年次パネル: 各 (Code, 年度末) について通期の**最初の開示**の値（訂正後の
  値で過去を上書きしない）。前期〜3年前は年度末の間隔が k年 ± 65日のときだけ
  連続とみなす（決算期変更をまたがない）
- 各サンプルには開示日 ≤ Date の最新の通期を merge_asof で付ける。
  400日より古ければ捨てる
- 対称変化率 sym(a,b) = (a−b) / ((|a|+|b|)/2)。符号をまたいでも定義できる
- 4項目（売上・営業利益・純利益・EPS）× 15種 + 営業利益率の変化 = 62本
- 検出力: 本番の out-of-fold と同じ 11窓で、特徴量が上位10%の行の
  `ret_o1_20` 平均 − 窓全体の平均。その窓平均 / SE を z とする

充足: 通期 98.2% / 前期 95.1% / 2年前 86.0% / 3年前 76.9%

読み方
- `yoy3` = 2期前の前年比、`vshape3` = 前期が過去2期の山より低く、直近で
  上向いた、`dip3` = 前期が過去の山からどれだけ落ちたか（0 = 落ちていない）、
  `4y_high` = 直近が過去3期の最高を超えた、`accel` = 前年比の加速
- 併合 AUC は 0.49〜0.53 で、ラベルとの相関はほぼ無い。それでも実収益の
  上位10%に差が出るのは、特徴量が「当たる/外れる」より「当たったときの
  大きさ」に効いているため
- 62本は互いに強く相関している（同じ4項目の組み合わせ）。7本が越えたと
  いっても独立な7本ではない
