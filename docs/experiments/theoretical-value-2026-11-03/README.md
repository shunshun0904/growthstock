# CAPM・理論株価：初期検証の記録

2026-11-03。本番のモデル・パラメータ・特徴量・契約プランの変更なし。

算出は残余利益（RI）89.1%、配当割引（DDM）78.2%（分母22,110行）。CAPMは株主資本コストを求めるために使い、利益・配当の仮定と合わせて現在価値を計算する。下限・上限・平均・中央値・母標準偏差を各方式ごとに保存し、モデルには株価比の10列を追加した。幅はシナリオ感応度であり、信頼区間ではない。

| タスク・主指標 | A：既存仕様 | B：両方式追加 | B−A | B−C：元指標のみとの比較 |
|---|---:|---:|---:|---:|
| +10%分類 AP | 0.231862 | 0.237814 | +0.005952 | +0.007369 |
| +15%分類 AP | 0.189120 | 0.190730 | +0.001610 | +0.000119 |
| 日次ランキング NDCG@5 | 0.595749 | 0.600500 | +0.004751 | +0.004156 |
| 直近5営業日ランキング NDCG@5 | 0.519082 | 0.537901 | +0.018819 | +0.011041 |

4タスク×6条件×3種=72 fits。主表は3種の予測を平均後に集計。Cは元の財務比率、β、金利、古さ、利用可能性を加えた対照。Aは同じマートで再学習した既存仕様の参照モデルで、保存済み本番モデルそのものではない。

+10%と直近5日ランキングのB−Cは3種・4四半期すべて正。ただしB−Aは全期間・種で一律に正ではない。+15%のBは値を入れ替えたPにも劣り、両方式一括追加の効果は支持しない。RI単独では+15% AP 0.193058だったが期間依存がある。日次ランキングも期間により符号が変わる。

参照済みの単一ホールドアウトの探索結果であり、**本番採用は保留し、新しい期間での再検証候補**とする。調整余地の大きい財務仮定、配当抜きβ、原APIの過去訂正履歴、会計基準変更の遡及組替え等の制約がある。再チューニングやXGBoost/CatBoost比較は未実施。
