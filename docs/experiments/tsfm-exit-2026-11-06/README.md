# E125 — 購入後の上値分布をゼロショットTSFMで予測

2026-11-06完了。既存8モデル・本番画面・売買処理は変更していない。
E124の購入候補を固定し、Chronos-2、過去の購入候補の日数別到達率、ボラティリティモデルを比較した。
このChronos-2の設定には採用を支持する結果がなく、本番への接続は見送る。

## 対象と事前固定

- 親研究：E124、ソースコミット `37bd6bd9462b1516db22c65be50825300de8d5a8`。
- [事前プロトコル](protocol.json)を推論前に保存。目標は固定買値から+10%/+15%、最大20市場営業日。判断日の翌寄りで購入し、購入1〜19日目引けに残期間を予測する。
- 購入条件：基本3分類器の凍結した過去CDF分位が全て95以上、同日上位2件。残るモデルを含む8つのOOFと現行メタデータの一致を照合。8モデルの全一致を購入条件にした研究ではない。
- 2025-11-01〜2026-10-05を評価窓とした。実際の購入判断日は2025-11-14〜2026-10-02。
- 65購入候補中、E124の順位再現条件で4件を除外。残る61件から、256点中の有効文脈192点以上を満たさない1件を予測前に除外。最小157点。採用60件の最小は193点。
- 共通60購入分・57銘柄・43判断日、1,140引け時点。+10%の未到達時点は55購入分・652時点、+15%は59購入分・880時点。各方法の母集団を同じにした。
- 到達率の参照用は、評価開始前に20日分の結果が確定した過去の購入候補215件のみ。広い候補群のラベルは使わない。TSFMの追加学習・確率校正・ハイパーパラメータ探索なし。
- この歴史期間はE121〜E124で参照済みであり、完全に新しい将来検証ではない。

## TSFMの予測対象

残りr日なら、過去のr日移動最高値Mを構築する。

```text
M[t+r] = max(H[t+1], ..., H[t+r])
```

既知時点までのMを現在終値で割り、対数化した256点をChronos-2に入力し、rステップ先の最後の分位点を使う。
これは残り期間の最高値そのものの分位点である。各日の周辺分位点の最大値を取る処理はしない。
入力は過去高値由来の単系列のみ。決算、8モデルスコア、将来共変量は入力しない。

モデル：[`amazon/chronos-2`](https://huggingface.co/amazon/chronos-2/tree/95a9710e2596287d08352589f42634fa5abdf0a7)、
重みアップロード2025-10-30T14:58:57Z、コミット `95a9710e2596287d08352589f42634fa5abdf0a7`。
重みSHA256 `ddcda3c7508bf2528087723e98a20707cc04b7f370ae275a9fd88078ddba4f42`。
float32/CPU、cross_learning=False。単独・バッチ推論の最大差は対数値1.79e−7。
重みの公開が全評価判断日より前であることを確認した。

価格に戻した分位関数を価格に対して線形補間し、1%未満・99%超の裾は端点で固定する。
この近似分布を積分した平均・標準偏差と、固定買値からの到達確率を保存する。
真の期待値の推定には裾の仮定が残る。線形外挿を感度分析とし、良い方を採用する選択は行っていない。
交差した分位点15箇所は昇順に並べ直した。

## 結果

未到達の引け時点を等重みとしたBrier誤差。小さいほど良い。

| 方法 | +10% | +15% |
|---|---:|---:|
| 過去の購入候補：日数別到達率 | 0.136328 | 0.111776 |
| ボラティリティモデル | 0.143101 | 0.106149 |
| Chronos-2 | 0.150298 | 0.119250 |

Chronos-2との差は両比較・両目標とも点推定で悪化し、95%区間はゼロを含む。
購入等重みの診断、日数帯、校正帯、対数損失も併記した。+15%の購入等重みでは過去到達率とほぼ同等だが、ボラティリティモデルを上回らない。

最高値の平均予測のMAEは、現在値を1とした比でChronos-2 0.109109、ボラティリティ0.077040。
10〜90%分位区間の実績包含率は77.89%・80.96%。
裾を線形外挿すると平均値が平均0.038pt、最大9.43pt（現在値比）変わった。平均は一部の大きな分位点に敏感である。

売却の主ルールは「残り到達確率20%未満で翌寄り売却」。固定利確・20日目満了を共通に維持。
上方寄りギャップは利確幅までに制限し、往復費用0.2%を控除する。

| 目標 | 固定利確の平均損益 | Chronos-2の平均損益 | 固定との差 | 差の95%区間 |
|---|---:|---:|---:|---:|
| +10% | −0.18% | −0.49% | −0.31pt | −2.00〜+1.98pt |
| +15% | −1.97% | −0.43% | +1.54pt | −1.30〜+4.73pt |

副ルール「購入初日引けの確率から半減」、実際の寄りギャップを得る場合、費用0/0.2/0.5/1%も保存した。
日数別到達率の半減ルールの+15%は差+1.90pt、区間+0.52〜+3.80ptだが、費用後損益は−0.07%。
複数比較の補正なし・歴史期間参照済みで、これを確定した優位性とみなさない。
区間は購入判断日の21市場営業日循環ブロック、2,000回、seed123。日次時点や乱数経路を独立購入数として扱わない。
損益は1購入分等額の平均であり、資金制約・複利を含むポートフォリオ利回りではない。

## 再実行

研究環境を本番用Pythonから分ける。依存は [requirements-tsfm-exit.txt](../../../research/requirements-tsfm-exit.txt)。
固定重みをHugging Faceから取得する場合は`revision`を必ず指定し、SHA256を照合する。

```python
from huggingface_hub import snapshot_download
snapshot_download('amazon/chronos-2',
    revision='95a9710e2596287d08352589f42634fa5abdf0a7',
    local_dir='MODEL_DIR', allow_patterns=['config.json','model.safetensors'])
```

既存E124/E123の入力を指定する。各出力は私用ディレクトリへ保存し、個別行を公開Actions成果物へ書き出さない。

```bash
python research/exp/e125_tsfm_exit.py \
  --source E124_RESULTS --prices E123_RESULTS --model MODEL_DIR \
  --output E125_RESULTS --phase all
python research/exp/e125_verify.py E125_RESULTS E124_RESULTS E123_RESULTS
python research/exp/e125_report.py E125_RESULTS
python research/exp/e125_verify_display.py E125_RESULTS
python -m unittest tests.test_tsfm_exit tests.test_daily_arrival tests.test_exit_upside
```

`prepare / baseline / tsfm / evaluate`を個別にも実行できる。推論キャッシュは入力・プロトコル・重みのハッシュで拘束する。
入力不備は予測前に購入分全体を除外し、推論失敗は停止する。予測結果を見て一部の不都合な行だけを捨てない。
Notebookは`E125_RESULTS`で開けばCSV等だけから再実行できる。

## 検査・限界

関連40単体テストを実行。実データの全入力の過去限定、最高値ラベル、分散、分位関数の積分、確率・約定・集計を独立再計算した9,752検査が通過。
売却1,680ケースが一致。外部通信無効・JavaScript無効の1440/390px表示で、11集計表・60日次表・3画像を確認し、ページ全体の横はみ出しなし。

汎用TSFMの移動最高値への転用、端点の裾、Gaussian独立変動・将来固定ボラティリティ、日足と簡易約定には仮定がある。
除外5件、スコア閾値の別設定、8モデル全一致、資金枠、税・配当・板・約定拒否は評価していない。
1モデル・1設定の探索的結果であり、TSFM全体の無効性を示すものではない。
次の設定を試す場合は別実験とし、新しい購入期間の前向き検証を確保する。
