## 比較条件

- LightGBM4タスク、A/C/B各30候補、内側の6ヶ月×3前進窓。同じタスクの各条件に同じ候補を与え、各条件が自分のCV最大を選ぶ。
- 候補は既存設定1組＋Optuna RandomSamplerの29組、探索種42、木200本。探索の種を変えた反復は未実施。
- 各会社の実際の日足による結果確定日で訓練をpurge。全12条件の設定を凍結してから外側の評価を実施。
- 4×3×30×3=1,080検証学習。最終学習は種42/43/44、合計36回。
- 外側はE120と同じ2025-10-06〜2026-10-02。以前に参照済みであり、完全な未使用期間ではない。
- 財務入力・算出シナリオ・行をE120と共通に固定。LTR5は候補日で金融特徴量を凍結。
- 収益は配当・手数料・保有制約等なしの重複する20日単純収益で、運用損益ではない。

定義・実行手順は [MODEL_THEORETICAL_VALUE_RETUNED.md](../../MODEL_THEORETICAL_VALUE_RETUNED.md)。
新しいDCF等を学習へ入れた比較ではなく、従来のRI/DDM10列の一括追加だけを評価している。
