# 価格帯別需給：平均建値の補助検証結果

今回承認された条件では、回転率による減衰の追加は改善につながりませんでした。
調整期間で選ばれた係数は **k=0（減衰なし）**。したがって最終評価では出来高重みと回転率モデルが同一の予測になります。
探索範囲を広げたり、最終評価を使って選び直したり、本番を変更したりしていません。

**価格帯別の残存建玉の正解分布は未入手で、今回評価したのは平均建値だけです。分布形状・各価格帯の残高の精度を確認した結果ではありません。**

## 最終評価

主指標はレコード均等のRMSPE。公表約定金額÷残高株数を正解とし、公表金額を推定に入力しません。

| 対象 | レコード数 | 出来高重みのRMSPE | 回転率モデルのRMSPE |
|---|---:|---:|---:|
| 買い売り合計 | 54,816 | 13.9187% | 13.9187% |
| 信用買い | 32,336 | 13.5751% | 13.5751% |
| 信用売り | 22,480 | 14.3986% | 14.3986% |

合計のMAPEは8.0636%、円単位MAEは171.91円。RMSPEは平均誤差率や到達確率ではありません。

調整期間のRMSPEはk=0で13.3035%、k=0.1で13.3091%、k=3で13.5157%。
最良係数は探索範囲の下限でした。指示どおり0〜3の範囲を拡張していません。

最終評価のRMSPE差は0ポイント、5日ブロック1000回の95%参考区間も[0, 0]です。
**k=0で計算自体が同じになるためのゼロであり、独立した2モデルの同等性を高い確度で証明した区間ではありません。**
最終評価も10営業日と短く、長期間・別相場での優劣はこの結果だけでは確定できません。

## 除外と制約

取得済み普通株の買い売りレコードについて、最初に該当した除外理由は以下です。

| 理由 | レコード数 |
|---|---:|
| 残高0で平均建値を定義できない | 45,540 |
| 60営業日の履歴が揃わない | 731 |
| 60日窓に出来高の欠損・不正値がある | 11,056 |
| 時点整合した有効な純株数が揃わない | 5,611 |
| 共通評価に含めたもの | 180,844 |

公表平均が60日価格範囲外の44,541件（共通評価の24.63%）も、削除せず誤差に含めました。
非負の重みでこの60日間の価格を平均する2手法では、範囲外の平均建値を構造的に再現できません。
分割を含む窓の3,546レコードも調整して評価しています。

改善しなかった理由の因果的な特定はしていません。市場出来高は信用新規・返済ではなく、
60日より前の残存建玉や日中の分布は表現できず、買い売り共通係数では両側の建値差も分離できません。
過去の株数引継ぎは欠損を0で補うより時点を保てますが、その後の新株発行・自己株取得を完全に復元するものではありません。
現在取得した過去データには後日の訂正が反映される可能性があります。

今回の出来高重みは本番の平均合わせ付き分布とは別の計算です。
この結果を本番の分布が正しいという根拠や、本番の分布表示を置き換える根拠にはしていません。
