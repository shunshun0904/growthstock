# E123：現行8モデルの上昇余地と売却方法

2026-11-05集計。**本番モデル・売買ルールは変更していない。** 最大保有期間は依頼どおり20市場営業日。

基準3本（+10%分類のLightGBM・XGBoost・CatBoost）の固定95百分位以上・各日上位2件を対象に、翌市場営業日の寄りから数えた。
95は過去スコアの百分位で、成功確率95%ではない。分布の参照期間は2025-09-05以前で固定している。

| 後続評価：2026-05-11〜2026-10-05 | 結果 |
|---|---:|
| 対象 | 52件・36判断日・49銘柄 |
| 20日内+5%到達率 | 76.92%（日付ブロック95%区間69.38〜85.00%） |
| 20日内+8%到達率 | 61.54%（同47.37〜73.02%） |
| 到達した場合の到達日中央値 | +5%は2日目、+8%は3日目 |
| 20日最大高値の上昇幅中央値 | +10.51% |
| +5%指値・未到達は20日目終値 | 平均純損益+1.10%、勝率76.92% |
| +8%指値・未到達は20日目終値 | 平均純損益+0.23% |
| +10%指値・未到達は20日目終値 | 平均純損益−0.43% |
| 20日目終値まで保有 | 平均純損益−3.50% |

純損益は往復コスト0.2%を買値比で一括控除。配当・税・実際の板・値幅制限・約定不能等を含まない。
取引ごとの平均であり、資金管理込みの年率収益ではない。最高値の上昇幅は実現できる利益ではない。

## 判定

小さめの利確幅を検証する余地はあるが、採用は未決定。
+5%指値の平均損益の95%区間は−0.04〜+2.45%、+10%指値とのペア差+1.53ptの区間は−1.10〜+4.73pt。
優位性を断定できない。損切りを付けると、後で+5%に到達する銘柄も先に離脱するため、到達率76.9%をそのまま勝率にできない。

前半2025-10-08〜2026-03-31には基準95条件が5件しかなく、事前の最低30件・10判断日を満たさなかった。
72売却ルール×取引のある7購入条件＝504組を集計したが、売り側の最適設定は選べていない。
後続期間を見て+5%を選び直していない。`selection_frozen.json`は後続の指標計算前の固定記録なので、`holdout_metrics_computed`はfalseのまま。
基準の+10%・20日ルールへフォールバックした。

## 8モデルの役割と個別推定

- 分類6本の95／97.5／99百分位条件、2ランキングを加えた条件を比較した。厳しくするほど必ず良くなる結果ではない。
- 8本すべてをゲートにした条件は、後続で0〜1件と少なすぎる。全数同意を前提に精度を主張できない。
- 6分類の固定百分位と日次・5日ランキングの組内百分位を8変数とし、過去の近傍の最大上昇幅分布・到達率を推定した。
- K=50／100／200を前半の最大上昇幅RMSEで比較しK=50。ただし前半評価4件なので設定の信頼性は低い。
- ランキングの候補全体を再現できない前半1件・後半3件を個別推定から除き、後半49件。分類だけの購入候補52件とは対象が異なる。
- 月初以前に20日経路が確定した高評価サンプルだけを参照。後続RMSEは19.07pt、全参照の平均による19.82ptから少し改善。
- 参照先の平均終値リターンが最大になる日を購入前に固定して売ると、平均純損益−2.06%。銘柄別に分けない全参照平均の日で売ると+1.16%。個別の売却日推定に優位性は確認できない。
- 11月5日の実際の推論を同じ条件で確認したが、強い買い条件の通過は0件。銘柄別予測は生成していない。

## 時点・入力・約定の検査

- 現行元指標追加版8モデルのOOFは、全8ファイルで本番meta.jsonのSHA256と一致。分類・日次373列、5日377列。
- 5日LTRは**実際に保存された5段階モデル**を使用。11月8日向け10段階設定は使っていない。
- 基礎8モデルのチューニング対象は2025-09-05以前。20会社日足先のラベル最終確定2025-10-07より後を評価。
- 既存OOFの29暦日エンバーゴを会社別20日足で再監査し、確定当日以前の境界予測を除外。2025-11-04の24件、2026-05-07の43件など。
- 新マート全体は直接取得できなかった。前回固定マート22,110行と現在OOFの追加11キーを合わせ、現在学習件数と同数の22,121キーで再構成。**最新全特徴量値の完全照合を行ったという意味ではない。**
- 5日組の学習窓内の7キーは20会社日足後が存在せず、R20が有限にならないため元の学習でも対象外。日足確定日の上限から除かれる。
- 最終監査で、OOFランキングの候補から将来R20欠測行が除かれている日を検出した。前半・後半16判断日で完全な候補の順位を再現できない。その日の順位は不明として、ランキングのゲートと個別推定の学習・評価から除外。分類のみの52件の結果は不変。除外は候補キー集合の欠落に基づき、収益で選んでいない。修正前の個別推定値は置き換えた。
- これはランキング履歴を再現できる日に限定した条件付き評価で、実運用で将来欠測を予知して見送れるという意味ではない。除外日を含む個別推定の成績は未評価。
- 価格は2026-11-05まで、全期間の分割・併合係数でOHLCを再調整。次の市場営業日の寄りがなければ先送りせず未約定。
- 20日経路のOHLC不完全54件を記録し、全経路がある16,438件で診断。対象の前半5件・後半52件に価格経路除外はない。
- 同日中に利確・損切り両方に到達したら主集計は損切り先行。寄りのギャップは寄りの順序を優先。損切りのギャップは寄りで約定、利確のギャップは指値価格。
- トレーリングは前日までの終値最高値、+5%終値到達の翌日から有効。将来高値を当日のストップに使わない。
- 21市場営業日の移動ブロック・ブートストラップ2,000回、種123。短い期間での近似で、30件未満等では区間を出さない。

**この歴史期間は以前の特徴量比較で参照済み。** 売り側の設定選択と後続評価は分けたが、プロジェクト全体で未使用の将来確認ではない。
強い閾値の件数不足、相場依存、日足約定の仮定が残る。本番適用前に、固定した候補ルールの前向きな評価が必要。
