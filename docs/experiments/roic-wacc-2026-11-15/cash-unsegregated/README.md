# 現金区分なしEVA・外生RIMの追補

運用者が、現金の欠損を0と補完せず、現金を控除も別建て加算もしない近似EVAと、外生割引率RIMの比較を承認。
現在の推論対象51銘柄・118,467銘柄営業日で、EVA株価39.583%、RIM株価74.664%、両方の乖離率42,632行を算出した。
最新営業日2026-11-13では、EVA25銘柄、RIM44銘柄、両方の乖離率24銘柄。

- `summary.json`・`coverage.csv`：現在の推論対象での件数・算出率。
- `eva_reasons.csv`・`rim_reasons.csv`：重複を含む算出不能の理由。
- `training-feature-generation.json`：過去の全3,748銘柄・22,110元キーを試行した証拠。
- `preflight.json`：元373列一致、EVA乖離7,818行、RIM17,485行、共通7,206行。
- `input_fingerprints.json`：計算コード・既存ソースのSHA256。

初回の性能比較範囲は、運用者が選択した**最後の2評価窓のランキング**。
各群30候補・内側3窓・木200本・最終種42/43/44を同じ条件で実施する。
補助分類と残りの評価期間は今回実行しない。計算可否を予測力改善の証拠にしない。
生の財務残高・全銘柄の日次系列・個別予測スコアは公開Gitへ追加していない。
