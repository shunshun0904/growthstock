## 再現方法

表示用Notebookは `pandas`・`nbformat`・`nbclient`・`nbconvert`・`ipykernel` がある環境で、同じフォルダを作業ディレクトリにして実行できる。
HTMLはそのまま開ける。モデルの再比較には、別途管理するraw・調整済み価格パネル・原本に基づく補正入力が必要。

```sh
python research/exp/e119_capital_efficiency.py \
  --dataset /path/to/dataset.parquet --data-dir /path/to/raw \
  --prices /path/to/adjusted_panel.parquet \
  --corrections /path/to/private/reviewed_corrections.csv \
  --output /tmp/capital-efficiency --threads 2
```

入力の一致は保存したSHA256で確認する。補正入力の根拠書類と利用開始日を保ち、将来の比較値を過去行へ無条件に適用しない。
