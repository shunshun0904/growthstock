**仮定付きの機械算出率で、原本確認済み率や投資判断に使える品質の認定率ではない。**
DCF等は観測負債小計の完全性が未検証。算出行に前回の負債原本照合済みフラグが付いた行はなかった。
算出率には0円のモデル評価を含み、正の中央値の行はcoverage.csvに別集計。未算出を0とはしない。
逆算の出力は価格ではなく成長率。時価修正NAVの0%も価格0円を意味しない。簿価ストレスを時価修正NAVに数えない。

## 仮定の確認

- 同日・同業、自己除外、最低10社。同業を候補サンプルや現在の銘柄一覧に限定しない。過去の業種履歴を利用。
- CF明細は有形・無形の取得支出の両方、または合計。片方の欠損を0で埋めない。開示設備投資額の代用を別集計。
- DCFは5年の比率固定、324シナリオ。終価でROIC=WACCとし、成長と再投資を連動させる。
- MCは仮定した分布の1,024経路。入力分布と相関の企業別校正は未実施。実際の将来価格分布・信頼区間とは呼ばない。
- 過去実績が成長−5〜10%に入る割合は57.34%、利益率変化±20%は56.12%。ただし実績変動は予測誤差ではない。
- 設備投資額/現金支出が0.8〜1.2倍なのは、比較できた904行の73.67%。同一性は確認できない。
- 正のDCF中央値の約75%は終価依存度80%超。逆算成長率はERP3→7%で中央値約17ポイント変化。

詳しい [方法・問題点](../../MODEL_VALUATION_METHOD_FEASIBILITY.md) を参照。

## 記録

`coverage*.csv`、入力品質、全仮定、同業母集団、年別、要約統計、実績との比較、逆算診断を保存。
`inputs.json`は27入力・コードファイルの指紋。`verification.json`は10テスト、全行再集計、独立DCF計算80行、MC再現10行、HTML表示11表とNotebookのZIP再実行の証拠。
個別銘柄の金融値、候補値、元マート、レポート一式は公開Gitに含めず別アーティファクト。
本番・契約・元データの変更、追加手法のバックテスト・学習採用は行っていない。
