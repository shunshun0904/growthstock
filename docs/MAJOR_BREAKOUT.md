# 本ブレイク予測モデル（2026-09-23 中止）

運用者の判断（2026-09-23）:
「こちらの「本ブレイク」モデルは中止します。月利3%をめざす、ミニブレイク予測を動かししばらくは予測結果が
実運用に耐えうるかを確認します。数カ月後にはedinet DBのデータも溜まることですし。」

このブランチ（claude/major-breakout-model）は記録として残す。本番（claude/jquants-browser-app-bwk19a）には
何もマージしていない。

## 何をしたか

| 段階 | 内容 | 記録 |
|---|---|---|
| ラベル | 78週高値の更新日の翌営業日の寄りで買い、60営業日以内に終値 +50% かつ 120営業日以内に終値2倍（買った日の急騰は 0）。正例 447 / 20,129件（2.22%） | `docs/MAJOR_BREAKOUT_LABEL.md` |
| m01 | 205列で学習し、今のモデルと同じ窓で分離力を測る | `docs/MAJOR_BREAKOUT_OOF.md` |
| m02 | 205列でパラメータ探索（時期で5つの塊・前後121営業日を外す）、日次ボラ1本との比較、ボラ系を外したモデル、3モデル95%超で買い2倍か120営業日で売る損益 | `docs/MAJOR_BREAKOUT_TUNE.md` |
| m03 | 利確 +30%・3モデル98%超、「下落が先」の割合、ファンダメンタルズ・信用残で見分けられるか | `docs/MAJOR_BREAKOUT_EXIT.md` |
| m04 | 目的変数を「+30%に −20%より先に届くか」に変える。運用に近い形（月の買い付け数・同時に持つ数に上限）で資金の増え方 | `docs/MAJOR_BREAKOUT_DIRECTION.md` |

## 分かったこと（中止の理由）

1. 本ブレイクのラベルは、日次ボラ（直近20営業日の値動きの荒さ）1本と同じくらいしか当てられない
   （窓6〜10のリフト: 探索後の3モデル 4.01倍、日次ボラ 4.17倍）
2. 3モデル95%超で買い、2倍か120営業日で売ると、1取引の平均は +2〜4%、中央値は −13〜−17%（窓の区切り方3通り）。
   ブレイクを全部買う（+7〜8%）より低い
3. 候補の 56〜62% は +30% より先に −20% に触れる。信用倍率では見分けられず（AUC 0.499）、ファンダメンタルズは
   弱い傾向だけ
4. 目的変数を「+30%に −20%より先」に変えると、1取引の平均は +5〜10% に改善した。ただし良かったのは
   2023年11月以降の窓だけで、運用に近い形（月1件・同時3件）では 0.87倍 / 1.47倍 / 1.30倍（4.5〜4.9年）。
   TOPIX を持ち続ける（2.0〜2.2倍）にも、ブレイクから毎月無作為に買う（中央値 1.4〜1.7倍）にも安定して勝てない
