# EDINET で作る特徴量の候補 —— 基礎分析つき（実測・2026-09-21）

EDINET の取得（1社1リクエスト、日 85社）が貯まるまでの間に、
「どの明細を、どう特徴量にすれば目的変数（78週ぶり高値のブレイク後
20営業日の実収益 `ret_o1_20`）に効きそうか」を、今あるデータで測れる
ところまで測って決めた。**列挙している EDINET の項目名はすべて、取得済みの
55社 817行（`edinet_fin.parquet`、176列）に実在する列**。充足率は
2016年度以降の行での実測。

## 結論を先に

1. **一番大きい発見は EDINET ではなく「開示のタイミング」だった。**
   直近の決算開示から Date までの日数（`jq_days_since_disc`、J-Quants で
   今すぐ作れる）は、単体で窓 AUC 0.553 と、本番の特徴量 151本のどれより
   高い。開示当日〜5日のブレイクは +1.2〜1.6pt、次の開示の直前
   （80〜100日）は +1.6pt（10/11窓）、その間の 20〜60日は −1.0〜−1.5pt
   （正の窓 1〜2/11）。本番の特徴量に「開示からの日数」は入っていない。
   **モデルに足すと分離力が一段上がる**（実験24: PR-AUC 0.2574 → 0.2763、
   リフト 1.39x → 1.49x、ROC 0.593 → 0.614）。上位10% の実収益は
   +1.12 → +1.24pt（z +0.20）で足切り（z>2）には遠いが、**10窓すべてで
   正、最悪の窓が −2.41 → +0.05pt、SE が 0.53 → 0.29** と、ばらつきが半分に
   なった。確認実験（実験26、種5つ・窓を3か月ずらす）で 10/10 は 8/10 に
   戻ったが、分離力の改善（PR-AUC +0.015〜0.016、種レンジ 0.0024 の6倍）は
   窓の切り方を変えても再現し、平均も4比較すべて正（+0.3〜0.7pt）、直近2年
   でも正。探索込み・5モデルでも分離力の改善は再現し（実験27・27b）、
   運用の規則（ブースティング3モデルが揃って上位）で正例率 28.7 → 30.5%。
   **採否の基準を分離力に置き直して採用**（`docs/MODEL_ADOPTION_RULES.md`
   §7、`docs/MODEL_DISCLOSURE_TIMING.md`）。本番の `all` に入っている
2. **EDINET で優先する次元は、証拠の強い順に**
   ① 割安さの精密化（本番の `earnings_yield` / `book_yield` / `per` / `pbr` は
   両端で ±1〜1.8pt、z 3〜4）→ EDINET で EV/EBITDA・FCF 利回り（実際の
   設備投資で）・純現金/時価総額・利益剰余金/時価総額・政策保有株/時価総額
   ② 資産の縮小（総資産・自己資本が縮んだ下位10%が −1.2〜−1.3pt、z −2.5〜−2.9）
   → EDINET で 設備投資/減価償却・有形固定資産の成長・従業員の増減
   ③ 収益性の傾き（四半期の `op_margin_chg_3q` / `ROA_chg_3q` の下位10% が
   −1.6pt、z −4.5）→ EDINET で 売上総利益率・販管費率・研究開発費率の
   年ごとの変化（構造の変化）
   ④ 資本政策（増資 = 発行済株式数の増加の上位10% −0.87pt、z −1.7。
   自社株買いは代理では効かない）→ EDINET で 分割調整後の株数の変化・
   役員持株比率の変化（浮動株は取れない。`float_shares` は発行済 − 自己株）
   ⑤ 人的資本（代理が無く未検証）→ 平均給与・従業員・臨時従業員の変化
3. **効かない、または向きが逆のもの**: 自社株買い（`jq_tsy_chg1` z 0.4）、
   現金比率（高すぎる上位10% が −1.7pt）、配当の変化（+0.6pt、z 1.7）。
   EDINET でもここに工数は割かない。
4. 実装は `research/edinet_features.py`（水準 36項目 × 10種、比率 39本 ×
   4種、時価総額との組み合わせ 7本 = 523列。2026-09-22 に固有項目を足した後の数）。検定は `research/exp/e22_edinet_screen.py`
   で、2,000行ぶん揃ったら回す。採否は実験21 と同じ A/B（z>2）。

EDINET 側では「有価証券報告書の提出からの日数」が同じ性質の特徴量になるが、
有報は年1回で決算短信の約1.5か月後なので、四半期の周期は J-Quants の
`DiscDate` で取るほうが素直。EDINET では「有報の提出が遅い（期末から
3か月を超える）」を別の信号（内部統制・監査の問題）として持たせる。

### 1. 割安さの精密化（優先度 高、証拠 ◎）

  外れる窓が消えた
- なぜ平均が動かないか: 開示からの日数は母集団の**全銘柄**に一様に効く
  （相場の状態と同じく、その日のブレイクの多くが同じ位相にある）。日内の
  順位（日内AUC +0.01）より、日をまたいだ選別（どの日のブレイクを買うか）
  に効いている。上位10% の平均は日内の順位で決まる部分が大きい
- **判定: 見送り（足切りの規則どおり）。ただし本番に入れる第一候補。**
  「平均で z>2」の規則は、ばらつきを減らす特徴量を拾えない。採用するなら
  「勝ち窓 10/10 かつ最悪の窓 > 0 かつ AUC の改善」のような規則を先に決めて
  からにする（規則を結果を見てから変えない）
- 年次の変化率（C）は、この上には積み上がらない（実験21 の +0.5pt は
  開示からの日数と重なる部分があったと読める）
- 本番で使うには `build_dataset.py` に「直近の決算開示からの日数」を足す
  （J-Quants の `DiscDate` から作れる。予測日には当日までの開示が入っている）
- **同じ特徴量は実験10（2026-09 上旬、`research/exp/e10_earnings_calendar.py`）で
  一度「効かない」と判定している。** 当時の記録（コミット 1a50bd5）:
  「素の関係としては強かった（経過0〜5日で実収益 +3.91%、21〜45日で +0.71%）
  が、モデルに足しても優位は動かない」。当時の判定は旧ラベル・出口60営業日の
  物差し・既定パラメータ・平均（しきい値優位、ノイズ床 0.51pt）だけで見ていた。
  今回も**平均は動かない**点は同じで、新しいのは「ばらつきが減る」「AUC が
  上がる」という別の見方。採否は `docs/MODEL_ADOPTION_RULES.md` の規則で決める

## 実験25・26: 種ノイズの測り直しと、開示からの日数の確認実験

`research/exp/e25_auc_noise.py` / `research/exp/e26_timing_confirm.py`
（規則は `docs/MODEL_ADOPTION_RULES.md` に先に固定してから回した）

### 実験25: 同一設定（本番の特徴量・本番のパラメータ）で種だけを振る

| 指標 | 1種ずつ（5通り）レンジ | 3種平均（10通り）レンジ |
|---|---:|---:|
| PR-AUC | 0.0061 | **0.0024** |
| ROC-AUC | 0.0069 | 0.0043 |
| 窓平均 `ret_o1_20` | 0.59pt | **0.67pt** |
| 勝ち窓 `ret_o1_20` | 7〜8 | 7 |
| 最悪の窓 `ret_o1_20` | 2.99pt | 1.18pt |

現行の設定では窓平均の種ノイズは 0.6〜0.7pt で、docs の「0.143pt（実験11）」
より大きい。実験21 の +0.5pt はこの範囲に入る。

### 実験26: 開示からの日数（実験24 の腕 B）を種5つ・別の窓で確認

| 窓 | A→B の PR-AUC | 窓平均20 | B の勝ち窓 / 最悪 | 窓平均40 | B の勝ち窓 / 最悪 |
|---|---:|---:|---:|---:|---:|
| 元の窓 | +0.0150 | +0.27pt（z +0.38） | 8/10 / −1.77pt | +0.55pt（z +0.64） | 9/10 / −0.87pt |
| 3か月ずらした窓 | +0.0163 | +0.69pt（z +1.69） | 10/10 / +0.22pt | +0.38pt（z +0.40） | 7/9 / −1.40pt |

初版の規則では不採用（元の窓で全窓正にならない。ずらした窓でも `ret_o1_40`
が 7/9）。改訂版の規則（AUC の改善が種レンジの2倍超、平均が全期間と直近2年で
悪化しない）では採用。「当たる確率を上げ、平均を少し上げるが、外れる窓は残る」
特徴量で、外れる窓が残ること自体は不採用の理由にしない、と規則を改めた。
