## 測り方

- **窓**: 今のモデルの out-of-fold と同じテスト窓（36か月 / 6か月 / 6か月）。新しいラベルが
  付くのは 2026-03-26 までなので、使えるのは窓1〜10（2021-05〜2026-03）。14,594行・正例312件
- **学習**: テスト開始の**121営業日前までの行だけ**。ラベルが120営業日先まで見るので、それより
  後の行を入れるとテスト期間の値動きが答えに混ざる（今のモデルは20営業日あけるだけ）
- **列**: 本番の205列（`all_plus`）
- **モデル**: LightGBM / XGBoost / CatBoost、種3つの確率平均。**パラメータは本番の今の値**
  （LightGBM は153列で探索した `all`。新しいラベル用には探索していない）。正例の重みは
  学習データの正例率から（本番と同じ）
- **比べ物**: 今のモデル（20日ラベルの LightGBM、同じパラメータ・同じ窓）のスコア、
  列1本（向きは結果を見る前に決めた）

## 結論

1. **分離力はある。** ROC-AUC 0.79〜0.81、PR-AUC は正例率の 3.2〜3.8倍、窓の中で上位10%に
   入った行の正例率は 8〜9%（全体 2.1%）。10窓すべてで無作為より上（3モデルの平均順位の
   リフトは最低 2.56倍）
2. **ただし、日次ボラの高い順に並べるだけとほぼ同じ。** 列1本（日次ボラ）で ROC-AUC 0.802、
   PR-AUC 3.96倍、日内AUC 0.818、上位10% 9.1%。モデルの上位10%の日次ボラは中央値 4.91%
   （全体 1.89%）で、ほぼ「値動きの荒い銘柄」を選んでいる
3. **ボラの近い銘柄どうしで比べると、モデルには上乗せがある。** ボラの五分位の中の ROC-AUC は
   3モデルの平均順位 0.655（LightGBM 0.634 / XGBoost 0.657 / CatBoost 0.668）、日次ボラ1本は
   0.581。ボラ以外の情報も持っているが、全体ではボラを直接使うのを上回れていない
4. **今のモデルのスコアは、このラベルに対して逆向き**（ROC-AUC 0.40、PR-AUC 0.76倍）。
   ボラの五分位の中では 0.53 でほぼ無関係。今のモデルは静かな銘柄を選ぶので、本ブレイクとは
   見ているものが違う。別のモデルにするのは筋が通っている
5. **上位の銘柄は「上がって、戻る」ものが多い。** 3モデルの平均順位の上位10%は、120営業日の
   うちの最高値（終値）が平均 +47.4%（全体 +25.6%）と大きく上がる一方、60・120営業日後の
   5日平均は +0.4% / +0.6%（全体 +3.0% / +6.1%）。収益は売り方（+50%・2倍での利確など）で決まる

## 次に決めること

- **このラベル用のパラメータ探索**（205列。今は本番の値を借りている）
- **合格ラインを「日次ボラ1本を上回る」に置く**。今はほぼ同点
- 売り方の設計（上位の銘柄は最高値が大きい一方、最後の値は平らなので、+50%・2倍での
  利確などをどう置くかで収益が決まる）
- ラベルの形。値幅（+50%・2倍）で切ると、荒い銘柄ほど届きやすいのは避けられない。
  ボラで割った基準にすると「その銘柄にしては大きい動き」を当てる形になる（今のモデルの
  ラベルはこちら）。目的（2倍を取りたい）に合うのは今の形
