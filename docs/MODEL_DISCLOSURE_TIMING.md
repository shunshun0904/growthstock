# 「開示からの日数」は本番に入れてよいか（実測・2026-09-21〜22）

`days_since_disc`（直近の決算開示からの日数）と `days_since_fy`（直近の
通期開示からの日数）の2列。実験23 で単体の検出力が最も強く、実験24〜26 で
本番のパラメータを固定した A/B を通り、2026-09-21 に本番の `all` に入れた
（`docs/MODEL_ADOPTION_RULES.md` §6）。その後、探索込み・5モデルで測り直した
（実験27・27b）。**この文書の結論が最終判断**。

## 結論を先に

1. **本番に入れる（2026-09-22、運用者の判断）。** 採否の基準を「分離力
   （PR-AUC）が上がるか」に置き直した（`docs/MODEL_ADOPTION_RULES.md` §7）。
   分離力は5モデルすべてで上がり、探索を引き直しても再現する
   （LightGBM 3引きの平均 0.2564 → 0.2767）
2. 運用の実態は「ブースティング3モデルが揃って上位（85 パーセンタイル以上
   など）」の銘柄からの選定で、単一モデルの上位10% ではない。その規則で
   測ると、正例率が 28.7% → 30.5%（母集団 16.9%）に上がり、実収益は同等、
   探索し直した B2 は最悪の窓が −2.65 → −0.56pt と浅い
3. 単一モデルの上位10% で見ると、実収益は上がらず（LightGBM 3引きの平均
   +1.04 → +0.96pt）、最悪の窓が悪化する（−2.32 → −4.22pt）。この見方では
   一度見送った（同日）が、運用の規則で見直して採用に戻した。両方の数字を
   残す
4. 特徴量が何をしているか: 上位の中身を「開示から21〜60日の中間」から
   「次の開示の直前」へ寄せる。平均では正しい寄せ方だが、決算期に賭けが
   集中し、決算絡みのブレイクがまとめて崩れる窓（2025-11〜2026-05）で
   単一モデルの上位10% は損が深くなる。3モデルの合議ではその窓の損が
   浅い（B2 −0.28pt）

### 読み方

1. **分離力（PR-AUC）は5モデルすべてで上がる**（木のモデルで +0.013〜
   +0.020、MLP +0.006、線形 +0.004）。ラベル（ブレイクの成否）を当てる力は
   本物で、探索を引き直しても同じ大きさで出る
2. **上位10% の実収益は上がらない。** LightGBM で ±0、他の3モデルでは
   −0.3〜−0.5pt。最悪の窓は XGBoost で −2.1 → −5.3pt、LightGBM の探索し直し
   で −2.4 → −5.4pt と悪化する
3. 線形（ロジスティック回帰）で分離力がほぼ上がらないのは、効き方が
   「開示直後と次の開示直前が良く、間が悪い」の U 字で、単調な傾きでは
   拾えないため。木のモデル向けの特徴量

### なぜ AUC が上がるのに実収益が上がらないか（診断）

上位10% の中身が変わる。中間（開示から21〜60日）のブレイクが減り、
次の開示の直前（80日以上）が増える。

| モデル | 腕 | 開示直後 ≤5日 | 中間 21〜60日 | 直前 ≥80日 |
|---|---|---:|---:|---:|
| LightGBM | A | 15.1% | 40.4% | 14.4% |
| | B1 | 13.7% | **25.5%** | **25.9%** |
| XGBoost | A | 15.6% | 39.9% | 14.0% |
| | B1 | 14.2% | 25.0% | 25.8% |

LightGBM A の上位10% の中で、帯ごとの `ret_o1_20`（%）:

| 帯 | 件数 | 上位10% の平均 | 母集団全体の同じ帯 |
|---|---:|---:|---:|
| 開示直後 ≤5日 | 314 | +2.41 | +1.85 |
| 6〜20日 | 253 | +2.22 | +0.41 |
| 中間 21〜60日 | 837 | **+0.68** | −0.55 |
| 61〜80日 | 392 | +2.89 | +1.69 |
| 直前 ≥80日 | 276 | +2.98 | +2.04 |

平均では「中間を減らして直前を増やす」のは正しい。それでも窓平均が上がらない
のは、**直前のブレイクは平均が高いが窓ごとのばらつきも大きい**から。
A の上位10% から中間の帯を外すだけの規則を試すと:

| | 窓平均 | SE | 勝ち | 最悪の窓 | 取引数 |
|---|---:|---:|---:|---:|---:|
| A そのまま | +1.12pt | 0.53 | 8/10 | −2.41pt | 2,073 |
| A から中間（21〜60日）を外す | +1.47pt | **1.10** | 9/10 | **−6.93pt** | 1,236 |
| A から開示直後 ≤10日 と ≥61日 だけ残す | +1.20pt | 1.36 | 9/10 | −9.93pt | 1,067 |

窓10（2025-11〜2026-05）が −2.41 → −6.93pt。この窓では決算に絡んだブレイクが
まとめて崩れており、決算の時期に賭けを寄せると1つの窓に損が集中する。
特徴量として入れると木のモデルはこの寄せ方を（弱く）学び、最悪の窓が
悪化するのはこのため。XGBoost / CatBoost / MLP でも窓5・7・10・11 に
負けが集中している（`research/_data/oof/e27_*`）。

読み方
- PR-AUC の差（+0.020）は引きに関係なく出る。分離力の改善は本物
- 窓平均は A と B で重なる（差 −0.08pt）。特徴量は平均を上げない
- **最悪の窓は B が 3引き中2引きで −5pt 台**。A の3引きはどれも −2.8pt より
  良い。探索し直すと、木は開示のタイミングに寄せる設定を選びやすく
  （CV PR-AUC は B が一貫して高い）、窓10 の損が深くなる
- §5 の「B の3引きの平均が A のレンジの下端を下回ったら不採用」は
  +0.96 ≥ +0.85 で通る。しかし最悪の窓の分布は明らかに悪い。規則に
  この条件が無かった
