# 本番5モデルの傾向 —— どの特徴量に頼り、何を過大評価し、どこで意見が割れるか（実験60・2026-10-03）

`research/exp/e60_model_tendency.py` / Actions の Run Experiment（run 37094987550、d4fc55d、6分）/
結果 `research/_data/oof/e60_*.csv`・`e60_summary.json`（artifact）。

運用者の依頼（2026-10-03）

> この５個のモデルの、傾向を知りたいです。例えば lgbm は比較的 xxx の特徴量を過大評価する傾向がある、
> MLP は比較的 yyyy の特徴量を過大評価する傾向がある、のような知見がほしいです。
> 必要であれば shap やクラスタリングなどを算出してもらっても良いです。

対象は本番5モデル（2026-09-27 学習、`all_plus_prog_listing_vol_book` 239列）。ロジスティック回帰の前処理は
この時点では v1（10/4 の再学習から v2）。

## 結論を先に

1. **5モデルとも土台は同じ: 「自分の平常より静かな銘柄」を選ぶ。** どのモデルでも最大の依存は「ボラの分解」
   （`vol_rel_long` = 直近20日のボラ ÷ 直近120日、`vol_20d`）で、区分の列を入れ替えると順位相関が 0.25〜0.34
   落ちる。上位10% の銘柄は同じ日の候補の中でボラが下位3割（百分位 0.27〜0.37）。次が「市場全体の需給」
   （外国人の4週買い越し +、自己売買・個人の買い越し −）と「株価・ブレイク」
2. **LightGBM / XGBoost は双子**（順位相関 0.89、上位10% の重なり 0.49）。他より **決算の変化（fund_trend）と
   次の決算までの日数（earn_ahead）を重く**、連続改善回数（fund_streak）を軽く見る。寄与の上位30列のうち
   12列は単独では効かない列（グロース250の20日リターン、金の20日リターン、業種対TOPIX、信託名義の大株主など）
   で、**地合いの細かい列を交互作用として拾う**
3. **CatBoost は「ボラ・需給フロー・開示タイミング」に偏り、決算をほぼ見ない。** 列の寄与が最も集中
   （`vol_rel_long` 11.1%、`days_since_disc` 7.9%、`vol_20d` 7.2%）。他より vol_factors +6.9pt、flow +6.6pt、
   timing +6.6pt 重く、fund_book −5.6pt、fund_trend −5.0pt 軽い。決算（変化）の列を入れ替えても順位相関は
   0.018 しか落ちない（LightGBM は 0.048、MLP は 0.187）。上位10% は最もボラが低く（0.29）、決算開示から
   最も時間がたった銘柄（0.60）。高ボラ・高PBR の型（§6 型2）を最も避ける
4. **ロジスティック回帰は「連続改善回数」と「本の第2・3章の列」を重く**（fund_streak +4.9pt、fund_book +2.3pt）、
   決算の変化を軽く見る（−4.9pt）。上位10% は5モデルで最も小型・低流動性（時価総額の百分位 0.42、売買代金
   0.39）で、信託名義の大株主が少ない（0.40）
5. **MLP は「ファンダ全般」を広く使い、ボラ・需給・タイミングを軽く見る。** 決算（変化）の寄与 20.5%（+7pt）、
   入れ替えると順位相関が 0.187 落ちる（他は 0.02〜0.05）。決算（水準）0.110、本の列 0.147、バリュエーション
   0.068 も他の3〜8倍。逆に vol_factors −7.7pt、flow −6.4pt、timing −3.2pt、breakout −3.1pt。寄与と単独の
   分離力の相関が最も弱く（+0.43。他は +0.64〜0.66）、**単独では効かない列（規模区分・業種コード・EPS の
   プラス回数・空売り比率・上場年数・PEG）に薄く広く重みを置く**
6. **木と線形・MLP の意見が割れたら、木が正しいことが多い。** LightGBM だけ上位10%（MLP は下位半分）の
   226件は正例率 28.8%、MLP だけ上位の 192件は 15.1%（母集団 18.0% より低い）。ロジスティック回帰だけ上位の
   71件は 11.3%。両方が上位なら 35.9%。**ロジスティック回帰・MLP の価値は「代わりに選ぶ」ではなく
   「木の候補を絞る」ことにある**（全5モデル合議の根拠）
7. **上位銘柄の「型」は5モデルで大きくは違わない。** 上位10% の和集合を5つの型に分けると、各モデルの内訳の
   差は ±5pt。最も当たる型は「売買代金が少なく、78週高値の近くで、終値が高値側で引け、PBR が低い」（正例率
   33%）、最も外れる型は「高PBR・高ボラ・信託名義の大株主が少ない」（20%）で、後者は CatBoost が最も避け
   （9%）、ロジスティック回帰と MLP が最も多く拾う（16%・15%）

## 測り方

- **寄与**（対数オッズの単位でそろえる）: 木は TreeSHAP（LightGBM `pred_contrib`、XGBoost `pred_contribs`、
  CatBoost `ShapValues`）、ロジスティック回帰は係数 × 標準化後の値（合計が decision に一致することを確認）、
  MLP は積分勾配（基準 = 標準化後の 0、32段。合計と f(Z)−f(0) の差は最大 0.09）。one-hot と欠損指示子の
  寄与は元の列に戻して足す。学習に使った 21,855行（2018-04-03〜2026-08-25）で出す
- **置換の物差し**（5モデルを同じ物差しで比べるため）: 区分（32の中区分 → 17の大区分に集計）または1列を、
  行の間でまとめて入れ替えて採点し直し、元のスコアとの順位相関の落ち（1 − ρ）を依存の大きさとする。
  ラベルを使わないので学習に使った行でも偏らない。1回の置換（種0）
- **過大評価**: 2つの意味で出す。(a) 寄与の上位30列のうち、その列単独の ROC-AUC が 0.48〜0.52 の列
  （頼っている割に単独では効かない）。(b) 大区分・中区分の寄与の割合が5モデルの平均（または他の4モデルの平均）
  より大きい区分
- **一致・不一致**: OOF（Release の `oof.parquet` / `<algo>_oof.parquet`、16,235件）でスコアの順位相関、
  上位10% の重なり（Jaccard）、階層クラスタリング（平均連結）。LightGBM と「片方だけ上位10%・もう片方は
  下位50%」の行で正例率
- **性格**: 各モデルの上位10%（OOF 全体のスコアで）について、代表的な 24列（5モデル平均の寄与が高い順、
  中区分あたり2列まで、同じ日の候補で値が同じ列と、すでに選んだ列とほぼ同じ列は除く）の「同じ日の候補の中での
  百分位」（(順位 − 0.5) ÷ 件数。偏りが無ければ 0.5）の平均
- **型**: 5モデルの上位10% の和集合（3,916件）を、その 24列の百分位で k-means（k=5）に分け、型ごとの特徴・
  各モデルの上位に占める割合・OOF の正例率

**「全5モデル 95以上」が厳しいのは、MLP が木と最も違う候補を選ぶから**（木との重なり 0.20〜0.23）。

LightGBM と意見が割れた行の正例率（片方だけ上位10%・もう片方は下位50%。母集団 18.0%）:

| 相手 | lgbm だけ上位 | 相手だけ上位 | 両方上位 |
|---|---|---|---|
| xgb | 0件 | 1件 | 1,061件 33.6% |
| cat | 89件 21.3% | 11件 27.3% | 806件 37.3% |
| logit | 96件 20.8% | 71件 **11.3%** | 736件 35.9% |
| mlp | 226件 **28.8%** | 192件 **15.1%** | 601件 35.9% |

MLP・ロジスティック回帰が単独で推す銘柄は母集団より当たらない。木が推して MLP が否定した銘柄（28.8%）は、
両方が推した銘柄（35.9%）より落ちる。つまり MLP の否定には情報があり、MLP の単独の肯定には無い。

## 注意

- 寄与と置換は、最終モデルを学習に使った行に当てた「頼り方」であり、「正しさ」ではない（正しさは OOF の §3）。
  SHAP は相関の強い列の間で寄与を分け合うので、1列の数字は近い列と足して読む（vol_20d と vol_rel_mkt など）
- 置換は1回（種0）。区分の順は安定しているが、小さい値（1pt 未満）の差は読まない
- MLP の積分勾配は relu の折れ目で合計が最大 0.09（対数オッズ）ずれる。順位には影響しない大きさ
- ロジスティック回帰は v1 の前処理で測った。10/4 の再学習（v2）の後に同じ台本で測り直すと、線形の頼り方は変わりうる
  （木3つと MLP は変わらない）。再実行は Run Experiment の `e60_model_tendency.py`、約6分
- 「上位10%」は OOF 全体のスコアの上位（日ごとではない）。運用の「全5モデル 95以上」とは閾値が違うが、
  性格の向きは同じ
