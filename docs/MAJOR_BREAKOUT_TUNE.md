`research/exp/m02_major_tune.py` / Actions の Run Experiment（run 35849903656。§6〜7 は
run 35852144185、§8 は run 35853958081 で追加。探索結果とスコアは保存したものを読んでいる）。
ラベルは `docs/MAJOR_BREAKOUT_LABEL.md`、最初の測定は `docs/MAJOR_BREAKOUT_OOF.md`（m01）。

運用者の依頼: 「１をお願いします」（このラベル用に205列でパラメータを探索し、合格ラインを

## 測り方

- **探索**: 窓6の学習の最後（2023-05-10）までの 9,634行（正例213件）で、LightGBM / XGBoost /
  CatBoost を各50試行（Optuna TPE）。分割は**時期で5つの塊に切り、検証の塊の前後121営業日を
  学習から外す**（今の探索の year_cap_date は日付を年ごとに振り分けるので、120営業日先まで
  見るラベルでは同じ銘柄の重なった期間が両側に入り、検証が簡単になる）。目的は塊ごとの
  PR-AUC ÷ 正例率（リフト）の平均。木は200本固定（今の探索と同じ組み方 `tuning_multi.build`）
- **評価**: 探索に使っていない**窓6〜10**（2023-11〜2026-03、8,444行・正例208件・2.46%）。
  学習はテスト開始の121営業日前まで。種3つの確率平均
- **合格ライン**: 日次ボラ（`vol_20d`: ブレイク日までの直近20営業日の、終値の前日比の標準偏差）
  の高い順に並べただけのもの
- **差の幅**: 29か月を月ごとに入れ替えるブートストラップ1,000回の 5〜95%点

## 結論（全205列）

1. **探索で良くなった。** 3モデルの平均順位のリフトは 3.65倍（本番の値）→ **4.01倍**、
   ROC-AUC 0.795 → 0.803。差は入れ替えの 99% で正（+0.43倍、5〜95%点 +0.13〜+0.83）
2. **それでも日次ボラ1本（4.17倍・ROC-AUC 0.801）を上回れない。** 差は −0.20倍
   （5〜95%点 −1.37〜+0.75、正になったのは38%）。互角で、合格ラインには届いていない
3. 探索で選ばれたのは浅く強く締めた木（LightGBM は葉33・1枚あたり最低246行、XGBoost は
   深さ3、CatBoost は深さ4）。正例が少ないラベルなので、細かく覚えない設定が選ばれた
4. ボラの近い銘柄どうしでは、モデルに上乗せがある（五分位の中の ROC-AUC 0.647、ボラ1本 0.580）

### 読み取り

1. **ボラ系なしのモデルは、日次ボラとは別の情報を持っているが、1本では日次ボラより弱い。**
   ROC-AUC 0.742 対 0.801 で、入れ替えのすべてで下回った。上位1%（約85件）は 16.5% 対 14.0% と上だが、差は正例2件ほどで、上位5%・10%では負ける
2. **2つを組み合わせると日次ボラ1本に並ぶが、はっきり上回るものは無い。** 名目で最も良いのは
   「ボラ上位20%をボラ系なしで並べる」（リフト 4.30倍）と「学習した重み」（ROC-AUC 0.811）だが、
   日次ボラとの差が正になったのはそれぞれ 54% と 42%（リフト）で、偶然の幅の中
3. 学習した重みはボラとボラ系なしがほぼ同じ（0.35 : 0.34）。探索期間では、ボラ系なしにも
   ボラと同じくらいの重みが付いた
4. ボラ系なしの効き方は、ボラの高い側（五分位の上3つで 0.62〜0.66）に偏り、ボラの低い側では効かない
   （0.46・0.51）。「荒い銘柄の中で、どれが本当に走るか」を分ける役には立っている
5. 29か月・正例208件では、リフトの差の 5〜95% 点が ±1倍ほど開く。+0.1〜0.3倍の改善は、この期間では
   見分けられない

## 8. 運用者の方針での売買の損益（run 35853958081）

運用者の方針: 「こちらの本ブレイクモデルは「数打てば当たる作戦」ではないので、1ヶ月〜2カ月に一度、
本当に「絶対これだ」と言えるものしか買いません。その代わり、半年後には資産が2倍になっているので。
ですので、3つのgbdtモデルで95%（上位5%）の&条件を満たすものという銘柄で購入戦略で行きたいです。
売るのは、購入時価格の2倍に達したらその時点で売り、達さない場合は120営業日保有し、120営業日終値で売却」
「損益を全cvかつoofで算出してほしいです」

### 測り方

- **点数**: 探索後のパラメータ（§1）の LightGBM / XGBoost / CatBoost を、窓ごとにテスト開始の121営業日前
  までで学習した out-of-fold（種3つの平均）。テストは売買を数えられるブレイクすべて（120営業日たって
  いないものは除き、途中で上場廃止したものは入れる）
- **買う**: 3モデルがそろって「それより前の窓の点数」の95%点を超えた銘柄を、ブレイク翌営業日の寄りで買う
  （しきい値に先の情報を使わない。比べる前の窓が無い最初の窓は除く）
- **売る**: 場中の高値が買値の2倍に届いたら、ちょうど2倍で売る（指値。窓を開けて飛び越えても2倍で数える
  = 控えめ）。届かなければ120営業日目（買った日が1日目）の終値。途中で上場廃止したら最後の終値
- 手数料・税・約定できない日（ストップ高張り付きなど）は入れていない。株価は分割を調整した値
- **窓の切り方**: 境界を 0 / 2 / 4 か月ずらした3通り（4か月ずらしは窓が1つ少なく48か月）。
  テスト開始が 2023-11-01 以降の窓は探索に一度も使っていない。それより前の窓は探索の期間と重なる
- **件数・平均など**: 条件を満たした全部を買ったとき（何銘柄でも同時に持つ前提）の1取引あたり
- **1銘柄ずつ**: 持っている間は次を買わず、全額を1銘柄に入れて複利で回したとき。同じ日に複数出たら
  3モデルの点数（前の窓の中での位置の平均）が高いものを1つ。最大DD は売った時点の資産で測った
  （持っている間の含み損は入れていないので、実際はもっと深い）。「ブレイク全件」の1銘柄ずつは、
  空いたらその日のブレイクで点数の一番高いものを買う（しきい値なし）

### 読み取り

1. **方針（3モデル95%超）の1取引の平均は +2〜4%、中央値は −13〜−17%。** 2倍に届くのは 17〜19%
   （およそ6回に1回）で、届かなかった8割強は平均 −17〜−19%（平均と到達率から逆算）。
   勝ち（利益が出た取引）は 37〜38%
2. **窓ごとの差が大きい。** ずらし0か月の9つの窓で、平均は −22.2%（窓2）〜 +21.0%（窓8）、
   中央値がプラスの窓は2つだけ（窓3・窓8）
3. **2倍に届く割合はブレイク全件の約5倍（17.6% 対 3.5%）だが、平均の損益はブレイク全件を下回る。**
   方針の平均は、切り方3通り × 期間3つの9か所すべてで「ブレイクを全部買う」（+6.7〜+8.3%）より低い。
   中央値はブレイク全件が +1.8〜+5.1% に対し、方針は −11〜−20%。モデルは「大きく動く銘柄」を選ぶが、
   上にも下にも大きく動くので、平均では有利にならない（2倍で売らずに持つ場合も同じで、§5 の上位10%の
   120日後は +1.6% と、全体の +7.5% を下回っていた）
4. **1銘柄ずつ全額で回すと、結果は窓の切り方しだいで 4.29倍 / 0.20倍 / 0.14倍。** 回数が 8〜13回しか
   ないので、どの1銘柄を引いたかで決まる。最大DD は売った時点だけで測っても −82〜−89%
5. **95%超は「1〜2か月に1回」より多い。** 月あたり 8.5〜9.9件。月1件前後になるのは 99%超（1.2〜1.6件）
   だが、99%超も切り方で平均 +1.7% / +8.7% / +7.5%、1銘柄ずつ 0.19倍 / 0.80倍 / 0.25倍とぶれる
6. 探索と重なる窓の方が、探索に使っていない窓より悪い（平均 −3.1〜+0.3% 対 +4.9〜+6.7%）。
   重なりで甘く出るなら逆になるはずなので、期間の差が大きい。重なる期間はブレイク全件の2倍到達も
   2.6% と低い（使っていない期間は 4.1〜4.4%）
7. 日次ボラ95%超は、方針より件数が多く（月14件前後）平均も低い（−0.3〜+1.2%）
