## 表示（追加指示によりランキングへ変更）

対象は `predictions.json` の直近3営業日（候補ゼロの日も営業日として数える）の全推論対象。順位・買い規則で絞らない。重複コードは最新推論日を残して1件にまとめ、最新終値時点でRIM・DDMのみ再計算する。株価推移チャートと他手法の計算・表示は取り外す。

方法を選択し、中央値/最新終値−1の降順で全銘柄を並べる。欠損をゼロや割安として扱わず、算出不可の銘柄は末尾に残す。同率はコード順。下限・上限・平均・中央値・標準偏差、最新推論日、株価日を表示する。レンジは感応度であり価格の予測区間ではない。
