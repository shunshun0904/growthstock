## 表示

`public/data/valuations.json` は予測候補の銘柄について、最新の株価日で各手法を再計算する。20営業日の終値は最新の株式数単位へ補正。評価額はその基準日の計算であり、過去20日間の各日に同じ評価が既知だったという意味ではない。

RIM・DDM・同業PER/PBR・EV/EBITDA近似・現金設備投資DCF・開示設備投資補完DCF・両確率的DCF・両リバースDCF・簿価資産ストレス試算を比較する。時価修正純資産法は必要データ不足を明示する。主な前提・欠損・株価日・開示日・金利日を示す。相対評価は自社を除く同日同業の10社以上。営業利益＋減価償却によるEBITDA、負債内訳合計、設備投資補完、独立な未較正分布等の限界は E122 と同じ。レンジを株価の予測区間と呼ばない。

乖離率は中央値/現在終値−1、位置は（現在終値−下限）/（上限−下限）。範囲外の位置を切り詰めず、上下限が等しい場合は未定義と表示する。リバースDCFは価格ではなく織り込み売上成長率として別枠に表示する。
