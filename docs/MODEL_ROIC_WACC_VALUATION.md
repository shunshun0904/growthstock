# 価格非依存の経済的利益・ROIC/WACCによる理論価値（研究用）

2026-11-15。運用者の追加仕様「理論株価モデルの株価依存性を排除する」を優先する。
本番の特徴量、学習パラメータ、モデル本体、既存の予測結果は変更しない。
現在のRIM/DDMランキングを残し、同じ理論株価ページの研究表示から系列を確認する。

## 主モデルと計算境界

主モデルは`research/fundamental_value.py`の経済的利益モデル。
このモジュールは価格・CAPM・PER・PBR・リバースDCFのモジュールをimportしない。
閉じた`Fundamentals`型だけを受け取り、任意の辞書・DataFrameや追加の市場価格フィールドを拒否する。
`fundamental_series.py`も金融入力の許可リストだけを受け取り、株価・β等の混入を拒否する。

```text
公表済み財務、独立した企業行動・株数、財務省金利
  → 許可リスト → 簿価／事前目標構成による割引率
  → 投下資本・ROIC・再投資の予測 → EVAの現在価値
  → EV → 親会社株式価値 → fundamental_value_per_share
                                      ↓ 計算終了後だけ
市場株価 ───────────────────→ valuation_gap・市場PER・EV_gap
```

`valuation_gap.compare_with_market()`は計算終了後の比較であり、価値計算側からimportしない。
株価由来のβ・市場時価総額ウェイトを使う従来型CAPM/WACC・DCFは`roic_wacc_valuation.py`の**比較モデル**。
主モデルのレンジや特徴量にCAPM比較値を混ぜない。

## 研究対象の7要素

1. 純利益率（親会社利益／売上高）
2. 総資産回転率（売上高／期首末平均総資産）
3. 簿価財務レバレッジ（平均総資産／平均親会社自己資本）
4. BPS（ここでは比較する会計期間に揃えた平均自己資本／評価日株数。表示にも平均ベースと明記）
5. ROIC
6. 再投資率
7. 外生的割引率

これらを厳密な乗算恒等式とは呼ばない。市場PERを主価値の入力にしない。
旧5因子・単純化7因子の算術確認は比較・診断に限定する。

## 主モデルの割引率

`Ke = Rf + 事前固定の株主資本リスクプレミアム`。
リスクプレミアムは3%・5%・7%、負債コストは`Rf + 1.5%`の明示的シナリオ。
対象銘柄のβ、小型株プレミアム、市場時価総額は使わない。

`WACC = Ke × E_book/(E_book+D_book) + Kd × (1-T) × D_book/(E_book+D_book)`。
Eは既存の財務範囲チェックに従う総純資産（非支配持分を含む範囲）、Dは簿価の有利子負債。
`DiscountPolicy.target_debt_weight`を明示した場合は事前目標構成を使えるが、初期標準は簿価構成。
負債全欠損は無借金にしない。観測した負債小計と原本で網羅性を確認した合計も区別する。
個別事業リスク・レバレッジとKeの関係を精密に推定したものではなく、固定リスクの感応度である。

Rfは既存`theoretical_value.riskfree()`を再利用する。
10年国債利回りの実効年率化、公表基準日が評価日より前、7暦日超の古い金利を使わない規則を維持する。
参照：[財務省の定義・公表タイミング](https://www.mof.go.jp/english/policy/jgbs/reference/interest_rate/qa.htm)。

## ROIC・現金・税率・株数

NOPATはEBIT×(1−税率)。実績税率（税引前利益が正、税率0〜100%）と固定30%を別系列にする。
ROICの期首末平均・年度連続性・連結／単体・IFRS借入金・リース範囲・非金融区分は
`capital_efficiency.py`の処理を再利用する。

- 現金控除なしROIC：NOPAT／平均（総純資産＋有利子負債）。参考値として保存。
- 営業投下資本ROIC：NOPAT／平均（総純資産＋有利子負債−**識別できた**非事業性現金）。
- 理論EVからの株式価値：EV−有利子負債−非支配持分＋識別済み非事業性現金。
- 連結の非支配持分欠損はゼロにしない。単体での非支配持分ゼロは構造上の定義。

現預金の全額控除や、未知の非事業性現金のゼロ補完を標準モデルにしない。
出典付きの私有レビューCSVで、現在年度・比較年度の区分を与えられる。
必要項目は`Code,fiscal_year,basis,accounting_standard,source_doc_id,source_url,source_submit_date`。
値は`debt,equity,nci,non_operating_cash`の少なくとも一つで、金額は円。
元データの範囲と異なる補正、出典のない補正、同じ利用開始日に重複する補正は拒否する。
補正は根拠書類の公表翌営業日以降だけに適用し、過年度補正が新年度を押しのけない。

主モデルの株数は、公表済み発行済株式数−**観測した**自己株式数を、種類まで確認できた日付付きの分割・併合で調整する。
株価÷調整済株価の比を主モデルの株数へ使わない。企業行動の累積は評価日以前のものだけを使う。
`AdjFactor`には、株価に基づくライツイシューの補正も含まれるため、単独では株数用に使わない。
`ExRT=1/2`と確認できた係数だけを適用し、ライツや種類不明の非1係数を跨ぐ株数は欠損にする。
そのイベント後を基準とする新しい財務の株数が公表されれば、以後の確認できたイベントだけで計算を再開できる。
保存キャッシュにExRTがない場合も、0.5等の数字だけで分割と推測しない。
参照：[J-Quantsの調整・ライツと取引高の区別](https://jpx-jquants.com/ja/spec/eq-bars-daily/adj)。
自己株式数不明や株数基準までの企業行動を確認できない期間は欠損。
β・市場時価総額を使う比較モデルには既存の株価比ベースの処理を残す。

## EVAとDCFの整合

IC0は評価時点で利用可能な期末営業投下資本。観測ROICは平均投下資本で算出した実績値。
年tの利益・投資を、同じ資本経路で定義する。

```text
NOPAT_t = ROIC_t × IC_(t−1)
再投資_t = g × IC_(t−1)
IC_t = IC_(t−1) + 再投資_t
EVA_t = NOPAT_t − WACC × IC_(t−1)
FCFF_t = NOPAT_t − 再投資_t
```

主ケースは5年間の明示予測。1年目のROICは実績値、5年目にWACCへ線形収束し、終価のROICはWACC。
このとき終価のEVAはゼロ、終価EVはIC5に一致する。

`EV_EVA = IC0 + ΣPV(EVA_t) + PV(終価EVA)`。
`EV_DCF = ΣPV(FCFF_t) + PV(終価FCFF)`。
同じ経路で相対差1e−10を超えたら計算エラーとして停止する。
ROIC一定ケースも同じ式で計算し、定常成長DCF閉形式との一致を検証する。
旧`valuation_methods.dcf_value()`とは無成長など同じ予測経路へ揃えられる条件で数値を照合する。
旧DCFの売上比率固定と新EVAの資本経路が違う条件で、無理に同じ株価に合わせない。

gは長期成長と資本成長の仮定。ROIC収束中のNOPAT成長には、資本成長だけでなくROIC変化も入る。
元の定常FCFF式の`NOPAT_next`を、当期NOPAT・翌期NOPAT・平均資本と混在させない。
WACC−gは最低1%ポイント、ROIC・NOPATは正、再投資率は0〜1、親会社株式価値は正。
赤字、負の成長率、必要残高の欠損、非金融・範囲を確認できない行に値を強制しない。

## 成長率

固定gは0%・1%・2%・3%。有効な固定シナリオだけで最小・最大・平均・中央値・母標準偏差とケース数を保存する。
実績税率・固定30%、EVA収束・EVA一定、CAPM比較は別集計。

事業データ予測は別ケース`business`。
売上・NOPATの過去成長率と、取得できた場合の再投資率×限界ROICの中央値を使う単純継続予測。
売上・NOPATの過去値が正で、二つの基本成長率が非負であることを要求し、事前に0〜3%へ制限する。
この上限・予測式は株式リターンの結果から選ばない。将来実績を遡及使用しない。
高精度な成長予測を実証したものではない。
市場から逆算する成長率は固定NOPATの定常モデルの診断として**計算後**にだけ保存し、EVAへ戻さない。

## 日次・先読み・系列の品質

初期確認は既存の`predictions.json`の推論対象銘柄（直近3営業日の重複除去）を使う。
特定の2銘柄を特別扱いしない。過去の学習検証には別途、過去の全学習対象を使う。
財務は公表日の翌**営業日**から使い、四半期末・年度末へ遡及しない。休場日・午前公表も例外にしない。
財務・補正の公表日、利用開始日、根拠書類ID、株数基準、税・金利・プレミアムの仮定を保持する。
最新の財務が不完全だからという理由で、古い有効年度へ巻き戻さない。400日超のROICは欠損。

保存APIの過年度値には事後訂正が含まれる可能性があり、全原本バージョンはない。
`revision_unverified`を保持し、利用開始日を守ったことと、当時の原本数値まで再現したことを区別する。
企業対応表の業種履歴も未照合。現在のキャッシュだけで厳密な過去時点再現を保証しない。

評価乖離率は市場株価／主理論価値。EV_gapは同じ有効シナリオ・企業価値ブリッジで別計算する。
会社予想利益／当日株数のEPSとTTM実績EPSを別に保持し、片方が欠けても別系列へ自動補完しない。
252日のZスコアは当日を含む126有効観測以上、標準偏差はddof=1、ゼロ分散は欠損。
百分位は同じ窓の平均順位／有効件数。20・60日平均と60日標準偏差は全件必要。
差分のラグは営業日行の位置で、欠損前の最後の有効値まで戻って計算しない。
株価・理論価値の20日ログ変化は共通の分割調整基準で計算し、乖離率ログ変化との差を検証する。
その主理論価値の調整にも株価比を使わず、確認済み企業行動だけの株式単位指数を使う。
種類不明・ライツのイベントを跨ぐ価値変化・ログ分解は欠損として、単位変更を企業価値低下と誤認しない。

## 残る市場依存の分類

| 項目 | 分類 | 主モデルでの扱い |
|---|---|---|
| 対象銘柄の株価・PER・PBR・時価総額・価格β | 計算上の市場入力 | 主価値では禁止。計算後の比較・対照群のみ |
| 日本国債金利・固定リスクプレミアム | 外部経済・市場環境 | 日付を制限して使用。対象銘柄の価格からは算出しない |
| 株数・自己株式・企業行動 | 企業の財務・資本政策 | 日付付き公表値。株価比からの主株数逆算は禁止 |
| 評価損益・OCI・過去の自社株取得等 | 財務を通じた経済的な間接依存 | データの性質として残る。完全な経済的独立を主張しない |
| 営業利益・再投資・ROIC・業種 | 景気や経営との関係 | 会計値を使うが、因果効果・成長予測の正確さは未立証 |
| 現在の推論対象を画面確認に使うこと | 対象選択 | 過去検証のユニバースには流用しない |

## 実行と配信

```sh
python research/build_roic_wacc_series.py --data-dir /private/cache \
  --predictions public/data/predictions.json --output /private/eva-research \
  --public-dir /private/pages-derived-data --resume

# 過去の全学習銘柄を生成する場合。公開用は現在の推論対象だけに制限。
python research/build_roic_wacc_series.py --data-dir /private/cache \
  --universe-dataset /private/dataset.parquet --output /private/eva-all --resume
```

ネットワーク呼び出し・契約変更は行わず、既存キャッシュを読む。
`--adjustments /private/reviews.csv`で出典付き補正を追加できる。
データ・コードの指紋が一致し、原子的に完了した銘柄だけを再利用する。
新しい入力・訂正で指紋が変わったら、その系列を再生成する。未来値の後方補完や無検査の追記はしない。

配信用はコード・日付・株価・計算済み比率・ケース値・品質・出所日付の許可列だけを取り出す。
生の財務諸表・認証情報は出さない。`index.json`と銘柄別の列指向JSON（通常gzip）を使う。
ブラウザは研究表示を開いたときだけ一覧を読み、選んだ銘柄のファイルだけを読む。
`--plain-json`も可能。GitHub Pagesのサブパスに対応し、機密キーはブラウザへ渡さない。
`public/data/roic-wacc/`はGit管理対象外。公開用生成物を配置する場合も本番のモデル生成処理へ介入しない。
