# 年次CCC・投下資本回転率・ROICの研究用特徴量

`research/capital_efficiency.py` は取得済みEDINET DB年次財務から作る、明示的に呼び出す研究用モジュール。
本番の `features.DEFAULT_PRESET`・360列、既存 `edinet_features.py` の年次軌道、モデル・パラメータは変更しない。
`ce_*` の値が存在することと、原本照合・訂正履歴まで検証できたことは区別する。

## 定義

残高は前年と当年の期末平均。Dは照合できた会計年度の日数。

| 特徴量 | 計算 |
|---|---|
| DSO | 平均売上債権 / 売上高 × D |
| DIO | 平均棚卸資産 / 売上原価 × D |
| DPO原価代用 | 平均仕入債務 / 売上原価 × D |
| CCC原価代用 | DSO + DIO − DPO原価代用 |
| 営業運転資本 / 売上高 | (平均売上債権 + 平均棚卸資産 − 平均仕入債務) / 売上高 |
| 粗利率・販管費率・営業利益率 | 各損益項目 / 売上高 |
| 税率 | 法人税等 / 正の税引前利益（0〜100%の範囲のみ） |
| 税引後営業利益率近似 | 営業利益率 × (1 − 税率) |
| 投下資本候補 | 非支配持分込み純資産 + リース込み有利子負債 − 現金等 |
| 投下資本回転率候補 | 売上高 / 平均投下資本候補 |
| ROIC実績税率近似 | 営業利益 × (1 − 税率) / 平均投下資本候補 |
| ROIC税率30%仮定 | 営業利益 × 0.7 / 平均投下資本候補 |

仕入高の代わりに売上原価を使うDPO、会社全体の税率を営業利益に適用するNOPAT、現金等全額控除はいずれも近似。
EDINET DBの提供ROICは税前で、上の税引後ROICとは異なる。
リース込みのBS残高と、一部リースを除く借入金等明細表の合計を混ぜない。

## 欠損・範囲・利用時点

- 負債は日本基準の借入金・社債・CP・その他有利子負債・リース債務の観測合計。
  IFRSは流動/非流動と非分割合計を二重計上せず、リースを加える。
  観測合計は全額を網羅した証拠ではない。
- 全明細欠損は負債ゼロにしない。IFRSで借入金の一方の区分しかなく、完全な合計もない場合は資本効率の比率を欠損にする。
- IFRSで純資産が親会社持分と同額かつ非支配持分がある場合は、総資本の範囲が未確認として欠損にする。
  非支配持分を全社一律に加算しない。
- 銀行・保険・証券商品先物・その他金融および業種不明は値の特徴量を欠損にする。
  業種は取得済み企業対応表によるため、過去の業種変更まで保証するものではない。
- 期首末平均は同じ連結/単体・会計基準、前年の提出が既知、前期末の翌日＝当期首、通常の年次期間に限定。
  期間はJ-QuantsのFYサマリーと照合し、`CurFYEn` 欠損時は通期 `CurPerEn` を使う。
- 有報提出日の翌日から付与。最新の利用可能年度を先に選び、値が少ないから古い年度を探し直さない。
  元の有報提出翌日から400日超は値・品質特徴量を欠損にする。訂正によって古い有報の鮮度を更新しない。
- 取得rawの各社年度は原本の全訂正バージョンを保持していない。`ce_revision_unverified` を立てる。
  提出日を制限しただけで厳密な過去時点の数値が再現できたとは扱わない。

`columns('values')` は13列、`columns('quality')` は12列。品質には平均比較可否、負債欠損/一部欠落、純資産範囲、
負の投下資本、負債/純資産の照合状態、開示経過日数等を含む。原本照合状態は分母の該当項目に対するもので、
その行の全財務項目を監査したという意味ではない。

## 原本に基づく補正入力

`annual_panel(..., corrections=DataFrame)` の補正は別ファイルとして渡し、rawを上書きしない。
必須項目は `Code, fiscal_year, basis, accounting_standard, source_doc_id, source_url, source_submit_date`。
値は円で `normalized_debt, normalized_equity, normalized_cash` の少なくとも一つ。
同じ会社・年度・利用開始日に重複する補正や、元の連結範囲・会計基準と異なる補正は拒否する。

補正の利用開始は根拠書類の提出翌日。翌年の有報にある前期末比較値を使っても、翌年の提出より前の学習行には反映しない。
後日の訂正なら新しい利用開始イベントを作る。古い年度の訂正が新しい年度の有報を押しのけることも避ける。
ゼロ負債を明示する場合も同じ出所情報が必要。

今回の原本照合で、NTTの保存明細では長期借入債務と総資本範囲が不足し、任天堂ではリース明細が欠落する例を確認した。
会社・年度別の財務値・補正CSV・原本控えは作業アーティファクトに置き、公開リポジトリに追加しない。

## 探索的な追加効果の比較

`research/exp/e119_capital_efficiency.py` は既存の同じ学習行を使う比較。

| 腕 | 列 |
|---|---|
| A | 既存360列（LTR5では値動き4列を加えた364列） |
| Q | A + 品質12列 + 財務値13列それぞれの欠損フラグ |
| B | Q + 財務値13列 |
| P | Q + 同じ日付内で観測値を入れ替えた財務値13列。各列の欠損位置を維持 |

分類の+10%/+15%と、日次LTR・直近5営業日LTR5を比較。木200本、種42/43/44、既存パラメータを同じ腕で固定し、探索し直さない。
主指標は分類がAverage Precision、ランキングが日付/組内NDCG@5。付随して20日目終値収益等を集計する。
LTR5の既存特徴量・今回の財務特徴量は候補日で凍結し、判断日に差し替えない。

直近12ヶ月の境界を基点にし、各会社の実日足で20営業日目の結果確定日を確認して訓練と評価を分離する。
既存パラメータの探索に使われた行の結果確定日も評価開始より前となるよう、必要なら評価開始を後へ移す。
全腕は同じ訓練行・評価行を使い、四半期の集計も出す。

```sh
python research/exp/e119_capital_efficiency.py \
  --dataset research/_data/dataset.parquet \
  --data-dir research/_data \
  --prices /path/to/adjusted_panel.parquet \
  --corrections /path/to/private/reviewed_corrections.csv \
  --output /tmp/capital-efficiency --threads 2
```

価格パネルは `Code, Date, open, high, low, close`（分割調整済み）が必要。
入力指紋、評価前の比較計画、分割検査、腕別/種別/四半期別の集計、ローカルの予測控えを保存する。
CLIのログは件数・日付・モデル指標のみ。料金プラン変更・取得頻度変更・本番学習/公開は行わない。

これはLightGBMの初期比較であり、既に検討に使ったホールドアウト・未確認の過去年次訂正を含む。
採否規則の全条件を満たした検証、新しい将来期間での再現、全学習器の比較を代替しない。本番採用の承認も意味しない。

## 初期比較の結果（2026-11-03）

保存済み最新マート22,110行、評価は2025-10-06〜2026-10-02。
日次の評価3,654行、LTR5の評価18,247行。上の4腕×3種×4課題、計48回の学習を完了。
Aは同じ最新マートで再学習した参照で、保存済み本番モデルをそのまま採点したものではない。

| 主指標 | A 既存列 | B 財務値追加 | B−Q 品質対照 | B−P 値入替対照 |
|---|---:|---:|---:|---:|
| +10%分類 AP | 0.23186 | 0.23260 | +0.00140 | +0.00335 |
| +15%分類 AP | 0.18912 | 0.18711 | −0.00402 | −0.00210 |
| 日次LTR NDCG@5 | 0.59575 | 0.59143 | +0.00265 | −0.00565 |
| LTR5 NDCG@5 | 0.51908 | 0.51554 | +0.00686 | −0.00868 |

分類は本番と同じ訓練ラベルの負例数/正例数で不均衡を補正した結果。
3課題でBはAを下回った。+10%分類の改善は小さく、すべての課題で種別B−Aの符号が変わる。
ROICが付く行の分類でもBはQを上回らなかった。安定した追加効果は確認できず、本番への追加は保留。
これは今回のデータ・近似定義・期間での結果であり、財務指標として不要という判定ではない。
算出候補率はCCC49.5%、投下資本回転率46.9%、実績税率ROIC43.4%。原本確認済み率ではない。
