# 本ブレイク予測モデル: 目的変数を「+30%に −20%より先に届くか」に変える（m04・2026-09-23）

`research/exp/m04_major_direction.py` / Actions の Run Experiment（run 35867199627。§6 は run 35877006534 で追加。§1〜5 の数字は同じ）。
前提は `docs/MAJOR_BREAKOUT_EXIT.md`（m03）と `docs/MAJOR_BREAKOUT_TUNE.md`（m02）。

運用者の依頼:
「a.でお願いします」（a = 学習させる答えを「+30%に −20%より先に届くか」に変える）
「どちらにも届かなかった行は学習に使わず — これは、推論時は事前にはわからないので、このフィルターは無しでお願いします。」

## 結論

1. **新しいラベル（A）の3モデルで98%超を買い、+30%で利確すると、1取引の平均は +5.2% / +6.2% / +9.7%
   （窓の区切りを 0 / 2 / 4 か月ずらした3通り）。** 今のラベル（−1.3% / +3.1% / −1.3%）より3通りとも良い。
   ブレイクを全部買う（+5.8% / +6.2% / +6.3%）とは、0・2か月では同じくらいで、4か月では上。
   95%超では +7.1% / +9.0% / +10.0% で、3通りともブレイク全件を上回った
2. **「下が先」が減り、負けが浅くなった。** 98%超の候補で −20% に先に触れたのは 40〜46%（今のラベル 56〜62%）。
   上下どちらかに届いた中での「上が先」は 49〜55%（今のラベル 37〜44%、ブレイク全件 52%）。
   下位10%は −32〜−36%（今のラベル −42〜−48%）、最悪は −50〜−57%（同 −78%）
3. 代わりに、+30%に届くまでが長い（中央値 39〜40営業日。今のラベルは 12〜16営業日）。+30%に届く割合は
   50〜59% で、今のラベルとほぼ同じ
4. **良くなったのは 2023年11月以降の窓（探索に使っていない期間）。** そこでは 98%超が +11.7% / +12.6% / +14.7%
   （ブレイク全件 +5.5〜+5.9%）。2021年11月〜2023年10月の窓では +1.4% / +0.4% / +5.3% で、ブレイク全件
   （+5.8〜+7.4%）を下回った。2つの期間で結論が逆なので、まだ確かとは言えない
5. **98%超の件数は平均で月 1.8〜2.1件だが、偏りが大きい。** ずらし0か月では、2022年11月〜2023年10月と
   2025年11月以降の窓で1件も出ず、2021年11月〜2022年4月の窓では40件（うち平均 −10.5%）出た
6. 1銘柄ずつ全額で回すと、98%超は 0.95倍 / 1.01倍 / 0.65倍、95%超は 3.64倍 / 1.19倍 / 1.32倍。まだ区切り方しだい
7. A は「向き」そのものを当てているわけではない。上下どちらかに届いた行だけで見ると、上が先を分ける AUC は
   0.44 で今のラベル（0.44）と同じ。荒すぎない銘柄（買った銘柄の日次ボラの中央値 4.8%。今のラベルは 7.2〜7.4%、
   ブレイク全件 1.9%）を選ぶことで、下が先の割合を普通のブレイク並みに戻している

## ラベルと測り方

- **ラベル A**: 買値（ブレイク翌営業日の寄り）から120営業日のうちに、場中の高値が +30% に、場中の安値が −20% より先に
  届いたら 1。−20% が先（同じ日に両方なら下が先とみなす）と、どちらにも届かなかった行は 0。
  ブレイク全体の正例率 26.2%。どちらにも届かなかった行も 0 として学習に入れる（運用者の指示。予測のときには
  届くかどうかは分からないので、学習でも外さない）
- **探索**: m02 と同じ組み方。205列・窓6の学習の最後（2023-05-10）までの 9,793行（正例 24.6%）で、時期で5つの塊に
  切り、検証の塊の前後121営業日を学習から外す。各50試行（Optuna TPE 種0）。目的は塊ごとの ROC-AUC の平均
- **点数**: 窓ごとにテスト開始の121営業日前まで学習し直した out-of-fold（種3つの平均）。今のラベルの3モデル（m02 の
  パラメータ）も同じ行で作り直し、m03 と同じ数字になることを確かめた
- **売買**: m03 と同じ。3モデルがそろって前の窓の点数の98%点（95%点）を超えたら翌営業日の寄りで買う。場中に +30% に
  届いたら +30% で売る。届かなければ120営業日目の終値、途中で上場廃止したら最後の終値。手数料・税なし
- **窓の区切り**: 0 / 2 / 4 か月ずらした3通り。テスト開始が 2023-11-01 以降の窓は探索に一度も使っていない

## 読み取り

1. ラベルを変えたことで、今のラベルの弱点（荒すぎる銘柄を選び、下に先に動かれる）はかなり減った。1取引の平均は
   区切り方3通りとも今のラベルを上回り、負けも浅い
2. ただし、ブレイクを全部買うのとの差は期間で逆になる。2023年11月以降は +6〜+9pt 上、それより前は −1.7〜−7pt 下。
   窓ごとでも3勝3敗。「どの期間でも全件より良い」とはまだ言えない
3. 98%超の買いは時期にかたよる。前の窓の点数でしきい値を決めているので、点数の水準が下がる時期には1件も出ない
   （地合いで自然に休む動きになっている、とも読めるが、今回の結果だけでは確かめていない）
4. +30%までに平均で2か月近くかかる。「半年後に2倍」のような速さではない

   - 勝ちは +30% で止まるのに、負けは深い。平均が少しプラスでも、複利では増えにくい
   - 候補が出ない時期は現金のまま（窓5・窓10は +0.0%。同じ期間の TOPIX は +8.5%・+11.9%）

### 測り方

- `research/major/portfolio.py`。資金を枠の数で等分し、1つの枠で1銘柄だけ持つ。空いた枠があり、その期間（暦の月、
  または2か月）の買い付け数が上限に達していなければ、条件を満たした銘柄をその枠の資金全部で翌営業日の寄りに買う。
  同じ日に複数あれば点数の高い方。売ったら枠の資金が増減し、次の買いに使う（枠ごとの複利）。売った日の翌営業日から
  その枠で次を買える
- 売り方は §3 と同じ（+30%で利確、届かなければ120営業日目の終値）。資産は毎日の時価（持っている銘柄は終値）で、
  最大DD もその毎日の資産から測る。手数料・税・配当なし。TOPIX は配当を含まない指数
- 上限の3通り（月1件・3枠 / 2か月に1件・3枠 / 月1件・6枠）は結果を見る前に決めた
- **無作為**: ブレイク全件から、空いた枠があれば期間の最初に出たものを買う（同じ日は無作為に1つ）。200回。
  「無作為より上」= 200回のうち、資産がその選び方より少なかった回の割合
- 期間: 評価する窓の最初の日から、その窓の中のブレイクがすべて売り終わる日まで。売り終わった後は現金
