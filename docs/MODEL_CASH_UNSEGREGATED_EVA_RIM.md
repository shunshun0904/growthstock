# 現金区分なしEVA・外生割引率RIM（研究用）

2026-11-15。運用者が「現金を区分しないEVAを近似モデルとして追加し、RIMと比較」を承認。
本番のモデル、既定373特徴量、学習パラメータ、予測、公開サイトは変更しない。
研究表示の初期選択は`eva_total_fade5`。従来の現金区分必須の営業EVAとCAPM比較も別に残す。

## 計算境界

`fundamental_value.py`は株価モジュールをimportしない。
`TotalCapitalFundamentals`には現金・市場株価・PER/PBR・時価総額・価格βのフィールドがない。
`RimFundamentals`は親会社自己資本、年次換算利益、独立株数、国債金利、配当性向だけを受け取る。
任意の辞書を拒否し、`fundamental_series.py`でも入力許可リストを検査する。
市場価格は価値の計算が終了した後だけ比較に使う。

## 現金区分なしEVA

```text
総投下資本 = 簿価総純資産 + 有利子負債
総資本収益率 = NOPAT / 期首末平均総投下資本
NOPAT = 営業利益 × (1−税率)
総資本価値 = 期末総投下資本 + 将来EVAの現在価値
親会社株式価値 = 総資本価値 − 有利子負債 − 非支配持分
理論株価 = 親会社株式価値 / 調整済み株数
```

総純資産には非支配持分を含む既存の正規化値を使い、投下資本へ二重加算しない。
現金は資本から控除せず、株式価値の変換時にも加算しない。
**現金内訳が0と確認できた扱いではなく、別の資本定義による近似モデル**である。
有利子負債・非支配持分・株数などの欠損は引き続き欠損で、無借金等へ補完しない。

Ke＝Rf＋固定リスクプレミアム。ERP3/5/7%、Kd＝Rf＋1.5%、資本構成は簿価。
税率は30%固定と実績を分け、初期比較は30%。対象株価のβと時価総額ウェイトは使わない。
総資本収益率を初年度は実績値、5年目にWACCへ収束させる。収益率一定ケースも保存する。

年tのNOPAT＝収益率t×期首資本、再投資＝g×期首資本、期末資本＝期首資本＋再投資。
gは資本の長期成長仮定で、ROIC収束中のNOPAT成長率と同義ではない。
初年度NOPATは期末資本×平均資本ベースの実績収益率で、g=0でも実績NOPATと異なり得る。
固定g0/1/2/3%と、売上・NOPAT・再投資の実績に基づく単純予測を別にする。
WACC−g最低1%ポイント、収益率・NOPAT正、再投資率0〜1、親会社価値正を要求する。
同じ資本・利益・再投資経路でEVAとDCFの相対差1e−10以内を検査する。

このモデルは現金・金融収益を独立に評価しない。現金が多い企業、資本政策の変更、資本収益率の急変に注意が必要。
現金控除なしの収益率を通常の営業ROICと混同せず、価値の下限や真の本源価値を保証しない。
高ROICの永続を避けた収束仮定も、現金や事業リスクを正確に評価した証拠ではない。

## 外生割引率RIM

```text
Ke = Rf + 固定リスクプレミアム
実績ROE = 親会社TTM利益 / 最新の親会社自己資本
ROE_t = Ke + (実績ROE−Ke) × (H−t)/H
利益_t = ROE_t × 期首自己資本
配当_t = 利益_t × 配当性向
期末自己資本 = 期首自己資本 + 利益_t − 配当_t
株式価値 = 初期自己資本 + Σ(利益_t−Ke×期首自己資本)/(1+Ke)^t
```

Hは5年または10年。ERP3/5/7%はEVAと同じで、中央値は有効なERPケースだけで集計する。
固定g・税率シナリオはRIMに適用しない。利益は実績税引後利益で、ROE収束により将来経路を作る。
既存`theoretical_value.residual_value`と同じROE収束式を価格非依存の閉じた入力へ移し、数値一致を検査する。
同じ自己資本経路による配当DCF＋終価簿価とも照合する。
EVAとは初年度の収束の始め方と利益・資本の定義が異なり、同じ値になることを要求しない。

TTMは当期累計＋前期通期−前年同期、年度は約12か月を要求。連結／単体と期間を揃える。
EPSや株価比から総利益・純資産を逆算せず、J-QuantsのNP・ShEq等の財務金額から作る。
年次配当性向は観測した年間配当総額／同年利益。欠損配当は無配にせず、初期版は0〜100%を対象とする。
年次配当は期末から550日以内、財務は開示から365日以内。親会社自己資本・TTM利益・株数は正を要求する。
負債・非支配持分・現金を別建てで控除／加算する企業価値ブリッジは使わない。
RIMは金融業でも定義できるが、EVAとの共通行の比較対象はEVAの適格条件にも制約される。

将来クリーンサープラス、一定配当性向、終価簿価は強い仮定で、将来のOCI・自己株式取得等を明示予測していない。
EVAは年次財務、RIMは四半期更新を含むTTMを使う。同一行比較でも鮮度・情報集合を完全に統一した評価理論の対照実験ではない。

## 比較指標・時系列

`valuation_gap = 市場株価 / 現金区分なしEVA株価`。
`rim_valuation_gap = 市場株価 / 外生KeのRIM株価`。
主`ev_valuation_gap`は**現金を含む総資本価値**の比較で、分子は時価総額＋負債＋非支配持分。
余剰現金を控除した通常の営業EV_gapと区別し、配信メタデータ`evGapBasis`と画面の名称に記録する。
RIMにはEV_gapを表示しない。営業EVAは別の現金控除後ブリッジで表示する。

当日を含む過去252営業日、最低126有効観測、標本標準偏差、ゼロ分散は欠損。
5/20/60日差分・20/60日平均・60日変動と20日ログ変化分解を保存する。
RIMも同じ過去窓の計算を再利用する。市場PERは会社予想とTTMを混在させず比較専用。
逆算成長率は価値計算後の診断で、どちらの価値計算にも戻さない。

開示は翌営業日から、訂正も利用可能日以降。金利は評価日より前の公表基準日・7暦日以内。
株数は発行済み−観測済み自己株式数、分割・併合はExRT1/2だけで調整する。
種類不明の非1係数・ライツを跨ぐ株数は、新しい株数開示まで欠損。
主価値の調整系列にも株価÷調整済株価を使わず、独立した株式単位指数を使う。
原本の全訂正履歴、過去の業種対応表、年次資本値以後の資本政策の完全な再現は未達で品質フラグを残す。
