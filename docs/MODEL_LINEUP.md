## 条件

- 母集団: 78週高値の更新日 × 銘柄（クールダウン20営業日）/ 16,431件
- 分割: 10窓のウォークフォワード（訓練36ヶ月以上 / 検証6ヶ月 / 6ヶ月ずらし /
  エンバーゴ60営業日）。本番の out-of-fold と同じ分割
- 種: 42 / 7 / 123 の3種で確率平均
- 学習器の定義: `research/tuning_multi.py` の `build`。**本番（`models.fit`）と
  同じコード**。測る対象と出す対象を同じにしてある
- パラメータ: 5モデルすべて同条件の探索済み（年×時価総額帯で層別・
  日付単位で分割・5分割 / PR-AUC / 50試行 / 木200本固定 /
  ホールドアウトより手前のみ）
- 物差し: `ret_o1_40` = **翌営業日の寄りで買い、40営業日後の5日平均終値で売る**
- しきい値: 窓ごとに**過去の窓だけ**から上位10%の線を決める
  （全期間の分布で決めると約0.9pt 楽観的になる）

### 探索時の内側検証と順位がほぼ逆になる

| モデル | 探索 PR-AUC（順位） | 窓平均（順位） |
| --- | ---: | ---: |
| LightGBM | 0.4029 (1) | +0.84pt (3) |
| XGBoost | 0.3979 (2) | +0.78pt (4) |
| CatBoost | 0.3831 (3) | +0.69pt (5) |
| ニューラルネット | 0.3044 (4) | +1.62pt (2) |
| ロジスティック回帰 | 0.2897 (5) | +1.76pt (1) |

10窓の out-of-fold で測り直した PR-AUC でも木が上（lgbm 0.3088 /
logit 0.2829 / mlp 0.2805）。**順位付け全体の質は木のほうが高いのに、
上位10%だけを取ると線形・MLP のほうが良い。** PR-AUC は分布全体の指標で、
しきい値運用は上位10%しか使わないので、両立する。

### 差は誤差の範囲か

自分で決めた足切りは「差 / 合成標準誤差 > 2 で採用可」。

| 比較 | 差 | 合成SE | z | 判定 |
| --- | ---: | ---: | ---: | --- |
| ロジスティック回帰 − LightGBM | +0.92pt | 0.65 | 1.40 | 要確認 |
| ニューラルネット − LightGBM | +0.78pt | 0.53 | 1.49 | 要確認 |

**どちらも足切りを越えない。** 「線形・MLP のほうが運用では良い」と
言い切れる状態ではない。ただし、

- 独立した2モデルが同じ向きに出ている
- 勝った窓が 8/9 対 6/9
- 取引数が多い（2,159 / 2,351 対 1,899）のに優位が大きい。選ぶ本数が
  増えれば優位は薄まる方向なので、この差は控えめに出ている

ので、**片方を捨てる根拠にはならない**。並べて見る方針と整合する。

### 交絡していること

線形と MLP は `preprocess`（中央値補完＋欠損指示子＋標準化＋one-hot）を
通す。木は生値と欠損をそのまま食う。アルゴリズムと前処理を分離できて
いない。木に同じ前処理を掛けても無意味（木は必要としない）なので、
この交絡は設計上ほどけない。

## 同じ LightGBM でも、パラメータが違えば別の銘柄を選ぶ

画面の LightGBM をどれにするかを決める過程で測った。本番モデル
（`research/lgbm_params.json`）と、5モデル探索で選ばれた LightGBM
（`research/multi_params.json`）を、同じ10窓の out-of-fold で比べた。

| | 本番 | 5モデル探索 |
| --- | ---: | ---: |
| 探索時の CV PR-AUC | 0.4016 | 0.4029 |
| learning_rate | 0.01385 | 0.04538 |
| num_leaves | 127 | 114 |
| min_child_samples | 68 | 70 |
| reg_alpha | 0.1152 | 0.00061 |

**内側検証の PR-AUC の差は 0.0013。それでも選ぶ銘柄は大きく違う。**

| 指標 | 値 |
| --- | ---: |
| Spearman 相関 | 0.863 |
| 上位10%の重複（Jaccard） | **52.8%** |
| パーセンタイルの絶対差 中央 | 8.6pt |
| 同 90%分位 | 25.8pt |
| 同 最大 | 62.7pt |
| 20pt 以上ずれる行 | 18.0% |

比較のため、本番 LightGBM と他モデルの相関。

| 相手 | Spearman |
| --- | ---: |
| 5モデル探索の LightGBM（同じアルゴリズム） | 0.863 |
| XGBoost | 0.857 |
| CatBoost | 0.752 |
| ロジスティック回帰 | 0.687 |
| ニューラルネット | 0.610 |

**XGBoost は「同じ LightGBM を再探索した場合」とほぼ同じだけしか違わない
（0.857 対 0.863）。** 画面の XGBoost の棒は、独立した2票目というより
「LightGBM のパラメータを振り直したもの」に近い。上の塊分けと同じ結論だが、
こちらのほうが基準がはっきりしている。

この測定から2つ決めた。

1. **画面の LightGBM は本番モデルに一本化する。** 順位・スコア帯・較正・
   SHAP・追跡ファイルはすべて本番モデルのものなので、棒だけ別の当てはめに
   すると、最大62pt ずれた「LightGBM」が2本並ぶ。`train_multi.py` は
   `models.EXTRA`（xgb / cat / logit / mlp）だけを作る。
2. **1本の棒の高さを重く読まない。** 集約指標がほぼ同じでも個別銘柄の
   スコアはこれだけ動く。塊をまたいで揃っているかを見るほうが安定する。

### 運用指標の表との関係

上の運用指標の表の LightGBM 行は `multi_params.json` の当てはめで、
**いま画面に出る本番モデルとは別物**（相関 0.863）。5モデルを同条件で
比べるための行なので、そのまま本番モデルの成績として読まないこと。

## 分かっていないこと

- 3種しか回していない（本番の想定は5種平均ではなく単一種）。
  種のばらつき（実験11: 窓平均レンジ 0.143pt）は同一設定で測ったもので、
  モデルをまたいだ比較の足切りとしては狭すぎる可能性がある
- 窓が9しかないので、窓平均の標準誤差が 0.34〜0.56pt ある。この幅では
  1pt 未満の差は判定できない

## 12本の合意の百分位（2026-10-12）

運用者の指示「ダッシュボードに12本の合意の百分位を表示してください」。上の12本（本番の4モデルとラベル違いの8本）の
百分位の平均を**合意**、それが過去の予測の合意の分布で下から何%かを**合意の百分位**として、候補ごとに画面に出す
（`research/predict_daily.py` の `consensus_reference` / `consensus_fields`、`docs/OPERATIONS.md`「12本の合意の
百分位を画面に出す」）。97.5 以上 = 過去の上位2.5%、90 以上 = 上位10%。実験79〜81 で、12本の値の中で判断に効いたのは
合意の高さだけだった（`docs/MODEL_ADOPTION_RULES.md` §35〜37）。本番の合議（3モデルとも95以上）と順位・帯は変えない。
