## 問いと事前に固定する比較

同一銘柄のリターン分布の時間変化に、従来の特徴量と単純な平均・分散の変化を超える情報があるかを調べる。
FID は方向を持たない距離であり、「FID が大きいほど上昇する」とは仮定しない。
正規分布FIDはμ/σから決まる非線形変換なので、ここで測るのは特徴量表現による予測の改善である。
市場全体に共通の FID や市場ベータの変化は今回の特徴量に含めない。

| 腕 | 入力 |
|---|---|
| M0 | 既存プリセット360列 |
| M1 | M0 + 符号付き delta_mu / delta_log_sigma（3ラグ×2列） |
| M2 | M0 + FID（3ラグ）/ velocity / MA / z-score（計6列） |
| M3 | M0 + 上記12列 |

主比較は **W=30 の M3−M1 の日付を等重みとする平均 Spearman rank IC**。
M1−M0、M2−M0、M3−M0、M3−M2、NDCG@5、上位下位差、投資成績は補助比較。
W=20/60 は事前に定めた感度分析で、OOS の成績が一番よい窓を選んで主結果に置き換えない。
既存の特徴量選択も含む完全な未使用データでの実験ではないため、結果は回顧的な探索研究として読む。

## 距離と特徴量

正規分布族の Fisher 計量は `ds²=(dμ²+2dσ²)/σ²`。
`x=μ/√2, y=σ` と変換した双曲平面の測地距離から、

```text
A² = (μ1−μ2)² + 2(σ1−σ2)²
d = √2 acosh(1 + A²/(4σ1σ2))
  = 2√2 asinh(A/√(8σ1σ2))
```

となる。添付の `√2 log((b+a)/(b−a))`、`2√2 atanh(a/b)` と同値。
実装は asinh 形式を対数領域で計算し、`b−a` の桁落ちと `a/b→1` の飽和を避ける。
局所二次形式の近似ではない。σ固定の直線に沿った長さとも区別する。
低水準の関数では非有限値・σ≤0はNaN。ローリング推定側でのみσを1e−8以上に正則化する。

数学的照合：[Nielsen (2023), *A Simple Approximation Method for the Fisher–Rao Distance between Multivariate Normal Distributions*,
Entropy 25(4), 654](https://doi.org/10.3390/e25040654)、§1の式(7)〜(9)と直後の arcosh 表式。
[著者公開PDF](https://franknielsen.github.io/entropy-25-00654-v2.pdf)の5〜6ページで確認。
独立な arcosh 表式との500組の照合、σのみ変化の閉形式、対称性・平行移動/尺度不変性をテストする。

背景：[Jaroonchokanan, Suwanna, Termsaithong (2023), SSRN 4556901](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4556901)。
プレプリントの市場レジーム記述を個別銘柄の予測へ拡張する研究であり、同論文をランキング改善の根拠にはしない。
SSRN本文はアクセス制限で取得できず、同論文内の式番号との直接照合は未完。数学的定義は上記の別の一次文献で確認した。

`distribution_geometry.GeometryConfig` の既定：W=30、L=(5,20,60)、基準FID=fid_20。
列名は `geom_w30_...`（窓の感度分析で識別できるようにする）。

| 特徴量 | 定義・利用時点 |
|---|---|
| delta_mu_L | μ(t)−μ(t−L)、符号あり |
| delta_log_sigma_L | log σ(t)−log σ(t−L)、正則化後、符号あり |
| fid_L | t終端W日とt−L終端W日の距離。L<Wでは窓が重なる |
| fid_velocity | 基準FIDの1営業日差分 |
| fid_ma_10 | 当日を含む直近10営業日の基準FID平均 |
| fid_zscore_60 | **当日を除く**過去60営業日の平均・標準偏差で当日FIDを正規化 |

全列は当日終値まで。日次対数リターンの完全なW本でMLE（ddof=0）を推定する。
z-scoreの基準標準偏差が1e−12以下ならNaNとする。

### 欠損・調整・取引日

- 取引所カレンダーを必須にし、欠損行を補った日付軸で窓とラグを数える。平日の推測に切り替えない。
- `AdjC`だけを使い、未調整`C`へ穴埋めしない。欠損、非正価格、非有限値、出来高0以下では日次リターンを欠測にする。
- 価格の穴の翌日も日次リターンは欠測。2営業日の騰落を1日分として扱わない。取引停止を前方補完しない。
- 上場直後・履歴不足はNaN。FID欠測による腕別の行除外はせず、全腕同じ候補をLightGBMに渡す。年別欠測率を保存。
- 同一銘柄・同一日の重複はエラー。異なるデータ版を黙って選択しない。
- ターゲットも取引所営業日でt+1/t+Hを参照する。行欠落時に翌「観測行」へ約定日をずらさない。
- `AdjC`は分割調整価格として扱う。配当再投資や上場廃止時の回収額は別途再構築しておらず、総収益率ではない。

## 分割と評価の防護

外側の学習/評価境界は既存と揃える。そのうえで**実際のラベル終了日**が評価開始より前に収まる行だけを学習に使い、
さらに1取引所営業日のembargoを置く。内側の学習/検証も同じ条件。
標準化・全期間補完・ランダムCVは使わない。モデル選択に外側評価指標を渡さない。
同じDate/Code集合の指紋、学習最終ラベル日、内側検証開始、採用パラメータを各腕・各foldで記録する。

rank IC とNDCGは既知ラベルの候補5件以上の日。定数順位のICはNaN。
上位/下位2件はスコアで選んだ後にリターンを確認し、欠測の上位銘柄を下位の既知銘柄で置き換えない。
日次・月次・年次を保存。市場局面（TOPIX対200日線）、時価総額帯、モメンタム符号、
モメンタム×同日FIDの高低別も記述する。後付け層別から採用条件を選ばない。
FIDと`vol_20d`/`ret_20d`のOOS Spearman相関も保存し、重要度を因果効果と解釈しない。

不確実性は全営業日に戻した**同日・同銘柄条件の差**に対する40営業日の移動ブロック・ブートストラップ（2000回、種42）。
欠損日を詰めない。モデル固定に条件付けた95%区間で、特徴量/窓/種などの多重探索を補正した検定ではない。

### 投資成績の定義

20営業日ごとに、その日の上位2銘柄を翌営業日の寄りで等額購入し、20日目終値で全て売る、重複しないコホート。
最初のOOSシグナル日を起点とする固定営業日スケジュールで、候補がない枠・寄り付かない枠は現金。
最終の不完全なコホートは投資対象外。1枠は資産の1/2で、候補が1つでも全額を集中させない。
実際に保有した銘柄の終値が欠測なら運用評価は `unverified` とし、取引を消して好成績に見せない。
購入・売却双方の売買代金に片道0/5/10/25bp（10bpが主設定）のコストを課す。
購入手数料も投資予算内から支払い、日次の時価評価で資産曲線・Sharpe・最大DD・売買代金ベースturnoverを計算する。
Sharpeは252営業日換算・無リスク金利0、最大DDには初期資産1を含む。
20日リターンを日次リターンのように累積/年率換算しない。この比較ポートフォリオは本番の3枠/+10%利確の売買とは異なる。

## 結論に必要な追加確認

現在のデータ版での過去の実験であり、上場廃止を含む歴史的ユニバースの完全性、データの遡及改訂、
既存データセットのラベル欠測による除外は解消していない。manifestにこの制約を明記する。
新たなユニバースでの再構築や将来期間での追試をせず、OOSという名称だけから予測優位性を断定しない。
また、追加列の欠測パターンが情報を持つ可能性もあるため、改善が出た場合は全腕共通の完全観測行での追試が必要。
まずM3−M1が年・窓・コストに対して安定するかを見る。改善の証拠が得られるまでは、市場との関係Bや非正規分布への拡張を先行させない。
