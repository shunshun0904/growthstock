# 理論株価特徴量の同条件再チューニング比較

2026-11-03。運用者の「再チューニングしないとフェアではない」という指摘を受け、E120の固定パラメータ比較とは別にE121を実施する。本番の特徴量・モデル・パラメータ・契約プランは変えない。

## 比較の契約

4タスク（+10%分類、+15%分類、日次LambdaRank、直近5営業日LambdaRank）ごとに、以下の各条件を**別々に再チューニングしてから**比較する。

| 条件 | 内容 |
|---|---|
| A | 既存360列（LTR5は値動き4列を追加） |
| C | A＋今回作った元財務比率・β・金利・古さ・利用可能性13列 |
| B | C＋RI/DDMの下限・上限・平均・中央値・母標準偏差の株価相対値10列 |

各条件に同じ30候補、同じ3検証窓、同じデータ、木200本を与える。候補はタスクごとの既存設定1組とOptuna RandomSampler（種42）の29組。3条件で候補の引きまでそろえ、それぞれのCV成績から最良を選ぶ。TPEや打ち切り探索ではない。

探索範囲は既存の `ltr.search_space`（分類の既存探索とも同じ7項目）を再利用する。

| 項目 | 範囲 |
|---|---|
| learning_rate | 0.01〜0.2、対数 |
| num_leaves | 7〜127、対数 |
| min_child_samples | 10〜300、対数 |
| subsample | 0.5〜1.0 |
| colsample_bytree | 0.3〜1.0 |
| reg_alpha / reg_lambda | 各1e−8〜10、対数 |

行サンプルの適用頻度1、早期打ち切りなし。木の本数と金融側のシナリオ仮定は探索しない。分類目的は3窓のAP等重み平均、ランキングは各窓の日次NDCG@5等重み平均。同点なら候補番号の小さい方を選ぶ。

## 時系列分離

データはE120と同じ金融特徴量・価格スナップショットを凍結する。新しい評価結果に応じた金融仮定の変更はしない。

探索用データは2018-04-03〜2025-09-03の候補。直近18ヶ月を6ヶ月ずつ3検証窓とし、各窓より前の全履歴で訓練する。各会社の実際の日足で求めた20日目の結果確定日が検証開始日以降になる訓練行を除く。同じ日付の行を訓練・検証に分割しない。

全12条件の設定を `selection_frozen.json` に保存してから外側評価を開始する。選択ファイルのSHA256を記録し、保存された全候補のCV成績から独立に選択結果を照合する。

外側評価はE120と同じ2025-10-06〜2026-10-02。全探索行の結果確定は2025-10-03まで。候補数は分類・日次ランキング3,654、直近5日プール18,247で条件間同一。LTR5の金融特徴量も候補日に凍結する。

**外側期間は以前の研究で既に参照済みであり、完全に未使用の期間ではない。** 今回のパラメータ選択には利用しないが、本番採用の独立した証明とはしない。

## 学習と検証

探索は学習種42。選んだ各条件の設定で最終学習を種42/43/44で行い、予測平均の主指標を比較する。4タスク×3条件×30候補×3窓=1,080検証学習、最終学習36回。

高速化のため訓練側のLightGBM binを再利用する。検証行はbin作成に含めない。葉サイズを変えるためfeature_pre_filter=False、binningの種42を固定し、CV・最終学習で一致させる。クラス不均衡補正、日付グループ、5段階ラベル・線形gainは本番関数との数値一致をテストする。

E120と学習経路・探索条件が異なるので、以前の数値との差を純粋なチューニング効果とは呼ばない。主比較は今回同条件で探索したB−AとB−C。探索の種は1つのため、候補の引きを変えた反復のばらつきは未検証。3学習種は3つの独立評価期間を意味しない。

## 実行

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python research/exp/e121_theoretical_value_retune.py \
  --dataset /path/to/E120/dataset.parquet \
  --prices /path/to/panel_bounded.parquet \
  --output /path/to/new-output \
  --trials 30 --folds 3 --threads 2

JUPYTER_RUNTIME_DIR=/tmp/theoretical-value-jupyter IPYTHONDIR=/tmp/theoretical-value-ipython \
  python research/exp/e121_report.py /path/to/new-output
```

同じコード・データ・引数なら試行単位の保存から再開する。コード・入力・探索条件を変える場合は別の出力ディレクトリを使う。
公開記録には集計・パラメータ・入力指紋を残し、金融値、行別予測、学習マート、金融値入りHTMLはユーザー向けアーティファクトに保存する。

理論株価の計算定義と限界は [MODEL_THEORETICAL_VALUE.md](MODEL_THEORETICAL_VALUE.md) を参照。XGBoost/CatBoost、金融シナリオ自体の最適化、独立した将来期間での再検証は今回の対象外。
