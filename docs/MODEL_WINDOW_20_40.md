## 結論を先に

1. **両方で発火した銘柄に絞ると、1件あたりの収益率は上がって見える。** 候補単位（枠なし）で「両方」は「現行だけ
   （新は不発火）」より +0.7〜+6.2pt 高く、窓の切り方3通り × 基準2通り（95・90）× 売り方2通り（20・40営業日）の
   **12通りすべてで同じ向き**（z > 2 は5通り）。運用の規則（全5モデル95以上・1日1件・枠3・+20%/20営業日）の模擬でも
   1取引は 現行 +2.61% → 両方 +6.08%（ずらし0。2か月ずらし +3.57 → +3.88%、4か月ずらし +0.59 → +2.85%）
2. **ただし、上げ幅はほぼ 2025年の候補から来ている。** 両方95以上の候補 35件のうち 27件が 2025年。2025年の中では
   3通りとも両方が上（95以上・20営業日で +2.3〜+3.9pt）だが、**2025年を除くと今の売り方（20営業日）では差が無い**
   （95以上: −0.96 / −1.72 / +1.56pt、90以上: +0.58 / +2.53 / −0.45pt。どれも |z| < 1.3）。2025年以外は「両方」95以上の
   候補が年 0〜6件しかなく、2024年は逆向き（95以上・ずらし0: 両方 6件 −1.05% 対 現行だけ 53件 +3.49%）
3. **上げ幅の多くは、現行モデルの線を上げるだけでも得られる。** 「両方」と同じ件数になるまで現行だけの線を上げた
   対照（95 → 98.1〜98.6）と比べると、差は +0.4〜+1.9pt（20営業日）/ +0.6〜+2.8pt（40営業日）に縮む。
   新モデルの合意が足しているのはこの程度
4. **取引が約4分の1に減るので、資金全体の収益は増えない。** 全5モデル95以上・20営業日（ずらし0）: 現行 56取引
   （年11.3回）・総損益 43万円・年率 +5.7% → 両方 15取引（年3.0回）・34万円・+5.1%。枠の稼働率は 29% → 8%。
   最悪の1取引は −34.1% → −12.5% と浅くなる（2・4か月ずらしでも総損益は 46 → 12万円、5 → 6万円）
5. **新モデル単体の分離力は現行より低い**（自分のラベルで ROC-AUC 0.56〜0.61 対 0.60〜0.64、日内AUC 0.58〜0.60 対
   0.60〜0.63）。21〜40営業日目の上昇は、1〜20営業日目の上昇より当てにくい。新モデル単体（新 全5モデル95以上）の
   1取引は現行と同じくらい（20営業日 +1.94% 対 +2.61%、40営業日 +3.77% 対 +3.10%）

**勧め: 「両方で発火」を今の規則に足すのは、まだ早い。** 1件あたりの収益率が上がる向きは12通りすべてでそろったが、
その中身は「2025年の1年」と「線を上げる効果」でほぼ説明がつき、2025年以外の年では確かめられていない。
規則に足すと取引は年3回に減り、総損益も増えない。2026年以降の候補が貯まったところで、2025年以外の年でも
同じ向きが出るかを測り直すのがよい（この台本を回し直せば同じ表が出る）。採否は運用者が決める。
満期を40営業日にする売り方と組み合わせた場合は、2025年を除いても ずらし0 で +1.9pt（95）/ +3.2pt（90）残るが、
切り方で符号が割れる（95以上: +1.94 / −4.84 / +1.71pt）。

## 新しい目的変数

`build_dataset.RiseConfig(start=21, horizon=40, sigma_days=20)`。名前は
`21〜40営業日目+1.2σ（σは20営業日） / 終盤+0.50倍 / MA5>=MA20 / 翌営業日寄り基準`。

| # | 軸 | 現行（t+1〜t+20） | 新（t+21〜t+40） |
|---|---|---|---|
| 基準 | 価格 | $O_{t+1}$（翌営業日の寄り） | 同じ |
| 1 | 到達 | $\max(C_{t+1 \ldots t+20}) \geq (1 + 1.2\sigma)\,O_{t+1}$ | $\max(C_{t+21 \ldots t+40}) \geq (1 + 1.2\sigma)\,O_{t+1}$ |
| 3 | 終盤 | $\overline{C}_{t+16 \ldots t+20} \geq (1 + 0.6\sigma)\,O_{t+1}$ | $\overline{C}_{t+36 \ldots t+40} \geq (1 + 0.6\sigma)\,O_{t+1}$ |
| 4 | トレンド | $\text{MA}_5(t+20) \geq \text{MA}_{20}(t+20)$ | $\text{MA}_5(t+40) \geq \text{MA}_{20}(t+40)$（MA20 は t+21〜t+40 = 判定窓そのもの） |
| | σ | $\text{vol\_20d}/100 \times \sqrt{20}$ | 同じ（運用者の選択） |
| | 確定に要る将来 | 20営業日 | 40営業日 |

コードの変更は `RiseConfig` に2つの欄を足しただけ（`start` = 到達を測る窓の始まり、`sigma_days` = σ の √日数）。
既定（`start=1`・`sigma_days=None`）は今の定義そのままで、名前・しきい値・ラベルは1件も変わらない
（`tests/test_e65_window_20_40.py`、実データでも下の 0. で確認）。本番のデータセット・学習・予測は何も変えていない。

## 測り方

**変えないもの**: 母集団（本番の `build_dataset.py` で作ったデータセットの行。21,926行・2018-04-03〜2026-09-03）、
特徴量（本番の239列 `all_plus_prog_listing_vol_book`）、5モデル（LightGBM / XGBoost / CatBoost / ロジスティック回帰 /
MLP）の作り、探索の手順、OOF の窓（36ヶ月 / 6ヶ月 / 6ヶ月）、選定の規則。

- **新ラベルの付け方**: データセットの行に、本番と同じ `price_panel` → `attach_rise_label` で新ラベルを付ける。
  同じ経路で現行ラベルを引き直すと、本番のラベルと全行一致する（下の 0.）。新ラベルが未確定の行（先 40営業日の
  日足が無い）は学習・評価に使わない（「未確定を正例・負例に混ぜない」は今の規則どおり）
- **エンバーゴ**: 「ラベル確定に要る営業日数」という今の規則のまま、値が 20 → 40営業日になる。
  `walkforward.make_folds` は訓練の終わりを固定してテスト窓の始まりを後ろへずらすので、新ラベルの OOF は
  約1か月遅く始まる。ホールドアウトの境界（探索の打ち切り日）も同じ規則で前に動く
- **探索**: 本番の週次再学習と同じ関数・条件。LightGBM は `tuning.tune`（`run_tuning.py` と同じ。年×時価総額帯で層別・
  日付単位の5分割・50試行・木200本）、xgb / cat / logit / mlp は `tuning_multi.tune`（`e15_tune_all.py` と同じ。
  logit は前処理 v2）。探索に使うのはホールドアウト（直近12か月）とエンバーゴより前だけ。Optuna の記録は本番の
  `optuna_multi.db` とは別のファイルに書く（新ラベルの試行を本番の探索に混ぜない）
- **OOF**: LightGBM は `train_production.oof_scores`、ほか4モデルは `train_multi.oof_scores`（本番と同じ関数。
  エンバーゴとパラメータを引数で渡せるようにした）。現行の5モデルも同じデータ・同じ関数で本番のパラメータ
  （10/4 の週次再学習のもの）から作り直し、Release の OOF と照合した（下の 0.）
- **選定と売買**（実験59 と同じ。`docs/MODEL_UNIT_SIM.md`）: 百分位はそのモデル自身の OOF の「その日より前」の分布
  （過去分布）。合議のモデルすべてが基準以上の候補から、1日1件（合議の最小の百分位が最大。同点は現行 LightGBM の
  スコア順）。翌営業日の寄りで100株、+20% の指値（買った日から高値で見る）、届かなければ満期の終値。枠3、
  埋まっていたら見送る（乗り換えなし）。手数料・税・配当・スリッページは含まない
  - **現行** = 現行の5モデルすべてが基準以上（運用者の規則そのもの）
  - **新** = 新ラベルの5モデルすべてが基準以上
  - **両方** = 10モデルすべてが基準以上（= 現行で発火し、かつ新でも発火）
- **比べる期間**: 10モデルの百分位がそろい（新ラベルの OOF は遅く始まる）、満期40営業日の出口まで日足がある選定日だけ。
  売り方2通りとも同じ期間・同じ候補で数える
- **候補単位（枠なし）**: 枠の模擬は取引が少なくなるので、基準を満たした候補をすべて数えた比較も出す。
  「両方」と「現行だけ（新は基準未満）」は重ならない組なので、差の z を出せる。SE は同じ日の候補をまとめて出す
  （同じ日の銘柄は地合いを共有するので、行ごとの SE は小さく出すぎる）
- **発火数をそろえた対照**: 「両方」は2つの基準を重ねるぶん選定が厳しくなる。厳しくしただけで上がるのか、
  新モデルの合意に中身があるのかを分けるため、「両方」と同じ件数になるまで現行だけ（と新だけ）の線を上げた組と比べる
- **年ごと**: どの年から差が来ているか。「両方」の候補は 2025年に偏るので、2025年を除いた差も出す
- **切り方3通り**: OOF の窓の境界を 0 / 2 / 4か月ずらした3通り（実験26・41・55 と同じ切り方。パラメータは同じもの）。
  1本の OOF の数十件の取引は、0-2 のとおり計算の細部だけでも入れ替わるので、向きがそろうかを見る
- **計算の細部**: OOF はすべて1スレッド（現行・新とも同じ作り方。本番は4スレッド）。探索は2本を並べて回した
  （lgbm 87分・xgb 36分・cat 19分、logit 45分・mlp 14分。lgbm は他の計算と CPU を取り合って長くかかった）。
  xgb は途中で止めて、CPU を3コアに固定して再開した。完了済みの試行は Optuna の記録から引き継ぐ（日曜の再学習が
  やり直しのときに使う仕組みと同じ）ので、50試行のうち1試行だけ同じパラメータを2回測っている

## 結果

### 0. データとラベル

データセットは本番と同じ作り（10/6 の取り込みまで、21,926行・2018-04-03〜2026-09-03。実験64 の腕 B と同じデータ）。
同じ経路で引き直した現行ラベルは、本番のラベルと **21,926行すべて一致**（label・future_rise・end_level・
uptrend_end・entry_price）。

新ラベルは 21,599行で確定。未確定 327行のうち 288行は末尾（2026-08-05 より後。先 40営業日の日足がまだ無い）、
39行は途中（21〜40営業日目の間に日足が途切れた銘柄など。各年 1〜9行）。

同じ 21,599行で、条件を重ねたときの正例率:

| | 到達 | ＋終盤 | ＋トレンド（= 正例） | 正例の最大上昇（中央値） | 正例の終盤水準（中央値） |
|---|---:|---:|---:|---:|---:|
| 現行（t+1〜t+20） | 4,890（22.64%） | 4,087（18.92%） | **3,714（17.20%）** | +15.70% | +11.95% |
| 新（t+21〜t+40） | 6,887（31.89%） | 5,873（27.19%） | **4,156（19.24%）** | +18.73% | +15.21% |

しきい値は同じ（σ√20、行ごとに一致を確認）なので、見る窓が後ろにずれたぶん届きやすく、到達は 1.4倍になる。
トレンド条件（t+40 で MA5 ≥ MA20）が新では 27.19% → 19.24% と大きく削る（現行は 18.92% → 17.20%）。

現行ラベルと新ラベルの重なり（21,599行）:

| | 新 0 | 新 1 |
|---|---:|---:|
| 現行 0 | 15,372 | 2,513 |
| 現行 1 | 2,071 | 1,643 |

一致は 78.78%。現行の正例 3,714件のうち新でも正例は 1,643件（44%）で、**2つのラベルは別の上昇を当てている**。
年ごとの正例率（現行 → 新）: 2018 12.4→10.8% / 2019 17.4→18.6% / 2020 15.7→18.3% / 2021 13.5→13.7% /
2022 12.6→15.7% / 2023 18.8→24.5% / 2024 15.1→18.4% / 2025 22.1→27.0% / 2026 21.2→14.1%。

### 3. 運用の規則での模擬（ずらし0・枠3・1日1件・100株）

比べる選定日は 2021-08-24〜2026-08-05（4.95年・候補 15,326件・1,186営業日）。新モデルの百分位が無い候補
（新ラベルが未確定）は 30件で、新・両方の基準は満たさない。年率 = 年あたり損益 ÷ 必要資金（実験59 と同じ）。
