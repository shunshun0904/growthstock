# 目的変数のホライズンとトレンド条件（実測）

`research/exp/e18_horizon.py` の出力。**実測値のみ**を記載する。

目的変数を 60営業日 から 20営業日 に短くしてよいか、そのときトレンド条件を
どうするかを、本番の学習に入れる前に測った（2026-09-17）。

## 結論を先に

1. **ホライズンの短縮（60 → 20）はコストゼロで通る。** 2つの物差しで
   差が z<0.2。加えて最悪の窓が −1.07pt → −0.11pt と改善する。
2. **トレンド条件は外すのがよい。** `MA5>=MA20` は2つの物差しで符号が
   そろって負（−0.38pt / −0.22pt）。条件を外した場合が最も安定していた
   （**9/9 勝ち窓・最悪の窓 +0.21pt・標準誤差も最小**）。
3. どの差も足切り（z>2）は越えていない。**平均では優劣がついていない**ので、
   決め手は安定性の指標（勝ち窓・最悪の窓・SE）にある。

### 採用した設定（2026-09-17）

**`h=20` / `MA5>=MA20`**（上の「新」）。トレンド条件は**残す**判断。

当初（実験18、全条件で共通パラメータ）の実測は「無」（条件なし）を
支持しており、この文書の 2. と 3. はその内容のまま残してある。

**その後、条件ごとに探索し直した実験18b で順位が入れ替わった**
（`MA5>=MA20` が4条件で最良になった）。ただし入れ替わったこと自体が
「この差はパラメータのノイズに支配されている」ことの証拠なので、
`MA5>=MA20` が良いと言えるようになったわけでもない。**どちらの実験でも
足切り（z>2）を越えていない**。詳細は下の「条件ごとに探索し直すと
順位が入れ替わる」を読むこと。

見直すべきタイミングの目安:

- 窓が増えて（データが貯まって）同じ比較の z が 2 を越えたとき
- 実運用の成績が「無」の推定（9/9 勝ち窓）より明確に悪いとき

## 測り方

| | |
|---|---|
| 条件 | 4つ（下表） |
| 学習 | LightGBM / 特徴量 `all` / 種 (42, 7, 123) の確率平均 |
| 窓 | ウォークフォワード9窓。**エンバーゴは全条件60営業日に固定** |
| 評価行 | **4条件すべてでラベルが確定している 21,138行**に限定 |
| 期間 | 2018-04-03 〜 2026-06-16 |
| 物差し | `ret_o1_20` / `ret_o1_40`（翌営業日の寄り買い → h営業日後の5日平均終値売り） |
| 判定 | z = 差 / √(SE_a² + SE_b²) > 2 で採用（実験11 のノイズ床） |

**公平さのための細工を2つ入れている。**

- 評価行を揃えた。`h=60` のラベルは直近60営業日ぶんが未確定なので、
  絞らないと `h=20` のほうが新しいデータを多く使えてしまい、
  「ラベルの質」と「データ量」が混ざる。
- 窓を揃えた。`lab.folds` のエンバーゴは `B.RISE_HORIZON` から取るので、
  条件ごとに変わると窓の形まで変わる。厳しいほう（60）に固定した。
  本番の `h=20` は20営業日のエンバーゴで走るので、**この実験は
  `h=20` 側にやや不利な（保守的な）見積り**になっている。

> **20日と40日の数字どうしを直接比べてはいけない。** 保有期間が違えば
> リターンの大きさが違うのは当たり前で、意味があるのは同じ物差しの中での
> 条件間の差だけ。両方を出しているのは、結論が物差しの選び方で
> ひっくり返らないことを確かめるため。実際どちらでも順序は同じだった。

## 分離力（out-of-fold）

同じ out-of-fold から PR-AUC / ROC-AUC も出す。

| 条件 | 件数 | 正例率 | PR-AUC | PR-AUC ÷ 正例率 | ROC-AUC | 日内AUC |
|---|---:|---:|---:|---:|---:|---:|
| 旧　 h=60 / MA20>=MA60 | 15,190 | 21.67% | 0.2891 | 1.33x | 0.5894 | 0.5985 |
| 中間 h=20 / MA20>=MA60 | 15,190 | 20.81% | 0.2900 | **1.39x** | **0.5946** | **0.6063** |
| 新　 h=20 / MA5>=MA20 | 15,190 | 18.73% | 0.2618 | **1.40x** | 0.5873 | 0.5967 |
| 無　 h=20 / 条件なし | 15,190 | 20.82% | 0.2899 | **1.39x** | 0.5943 | 0.6055 |

> **PR-AUC の生値を条件間で比べてはいけない。** PR-AUC の下限は正例率
> そのものなので、正例率が違えば土俵が違う。`MA5>=MA20` は正例率を
> 18.73% まで下げるぶん生値が小さく出る。正例率で割ると 1.40x で、
> むしろ4条件で最も高い。**ROC-AUC と日内AUC は正例率に鈍いので、
> こちらはそのまま比べてよい。**

読み取り:

- **ROC-AUC は4条件とも 0.587〜0.595 に収まる**（幅 0.007）。ホライズンを
  縮めてもトレンド条件を変えても、分離力そのものはほとんど動かない。
- 順序は実収益の結果と一致する。`h=20` かつトレンド条件なし（中間・無）が
  最も高く、`MA5>=MA20` がわずかに最も低い。**同じ方向を向いている**。
- ただし **AUC にはノイズ床を測っていない**ので、この 0.007 の差が
  ノイズかどうかは判定できない。採否の判定は、ノイズ床を測ってある
  実収益（窓平均・z>2）のほうで行う。
- 日内AUC（同じ日の候補どうしの順位付け）は 0.597〜0.606。運用では
  同じ日の候補から選ぶので、この指標がいちばん運用に近い。

**実験表と本番表を直接比べないこと。**

> **`meta.json` の `tuning.mean_pr_auc` (0.3969) / `mean_roc_auc` (0.7168) とも
> 比べてはいけない。** あちらは Optuna の探索に使った**層別 k 分割**の値で、
> フォールドの訓練側に将来のデータが入る（`tuning.year_folds` は

> ウォークフォワードの out-of-fold より必ず楽観的に出る。
> ハイパーパラメータを選ぶための相対比較には使えるが、
> 実力の推定値として読んではいけない。

## トレンド条件について分かったこと

**`h=20` では `MA20>=MA60` が条件として機能していない。** ラベル確定
27,307件のうち、この条件が削るのは **2件（0.04%）** だけだった
（`h=60` では473件削っていた）。`MA60(t+20)` は `[t−39, t+20]` の平均で
大半がブレイク**前**の安い期間になる。基準日は78週高値の更新日なので、
`MA20(t+20)`（すべてブレイク後）がそれを下回るには相当な下落が要る。

実測でも「中間（MA20>=MA60）」と「無（条件なし）」の差は
−0.03pt / z=−0.08 で、**同じものだと確認できた**。

**`MA5>=MA20` は条件としては効くが、成績には効かない。** 削る件数は
561件（5,671 → 5,110）で機能はしている。しかし窓平均は下がり
（−0.38pt / z=−0.86）、勝ち窓も 9/9 → 7/9 に減る。5日と20日の交差は
短い窓どうしの比較なので、トレンドではなく短期のノイズを拾っている可能性が
ある。正例率も 19.69% → 17.71% に落ち、そのぶん推定も不安定になる。

## 条件ごとに探索し直すと順位が入れ替わる（実験18b）

実験18 は4条件すべてに同じパラメータを使っていた。そのパラメータは
`research/lgbm_params.json` の探索済みの値で、**旧ラベルに対して、しかも
ETF を含む母集団で**探索されたもの。旧条件だけが自陣だった。

`research/exp/e18b_tuned.py` で、**条件ごとに自分のラベルで探索してから**
同じ比較をやり直した。行・窓・シード・物差しは実験18 と同一で、
違いはパラメータだけ。

### この結果の読み方（重要）

**順位が入れ替わったこと自体が、いちばん強い情報。** 同じ比較が
パラメータを変えただけで符号を変えた（`MA5>=MA20` は実験18 で −0.38pt、
実験18b で +0.37pt）。**この差はラベルの質ではなくパラメータのノイズに
支配されている**と読むのが正しい。どちらの表も足切り（z>2）を越えていない。

**実収益と分離力が食い違っている。** 実収益では「新」が最良になったが、
ROC-AUC と日内AUC では依然として「新」が最も低い。2つの指標が逆を向くのは、
差がノイズであることのもう1つの裏付け。

**取引数が揃っていない。** 旧 2,658 / 中間 2,187 / 新 1,819 / 無 1,603。
しきい値は過去の窓のスコア分布の90%点で決めるので、パラメータが変わると
分布のドリフトも変わり、選ばれる件数がずれる。実験18 では
1,887 / 1,831 / 1,815 / 1,831 とほぼ揃っていた。**件数の少ない条件は
「選り好みした結果の平均」なので、窓平均が高く出やすい**。この点でも
実験18b の窓平均どうしの比較は実験18 より粗い。

したがって結論は変わらない:

- **ホライズンの短縮（60 → 20）は、どちらの実験でもコストが出ていない。** 安心して通してよい。
- **トレンド条件の選び方（`MA5>=MA20` / なし）は、実測では決められない。**
  ノイズ床を越える差が出ていない。`MA5>=MA20` を採用しているのは運用側の
  判断であり、実験18b はそれを**否定していない**（実験18 は弱く否定していた）。
