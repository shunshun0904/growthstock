# 反発を狙う戦略: 「下がった」の定義（2026-11-22 に固定）

> **運用者の依頼（2026-11-22）**: 「下がった銘柄の反発を狙う戦略を立てたいです。まずは「下がった」の定義ですね。
> 反発を狙うので、上昇トレンド下降トレンドどちらもありえると思います。」
> → 候補ごとの件数（下の §3）を見たうえで、AskUserQuestion で次を選択:
> 基準「20日高値からの下落率」・深さ「固定 −15%」・市場の下げ「含めて、別の列で分ける」・トレンド「下げる前（20営業日前）に測る」。

ブレイク予測（高値更新の母集団）とは別の、新しい戦略の準備。**この文書で決めたのは「下がった」という出来事の定義だけ**で、
「反発した」の定義（目的変数）・買い方・売り方・物差し・比べ方はまだ決めていない（§5）。

**定義を決めるまで、事後のリターン（下げた後に反発したか）は一度も見ていない。** 見たのは件数・トレンド別の内訳・
特定の日への集中・決算の近さ・定義どうしの重なりだけ。結果を見てから定義を選ぶと、過去に合う定義を選ぶことになるため
（`docs/MODEL_ADOPTION_RULES.md` の冒頭と同じ考え方）。

## 1. 定義

| 項目 | 中身 |
|---|---|
| 母集団 | ブレイク予測と同じ（`research/build_dataset.py`）。市場区分が「その他」（ETF・REIT 等）・TOKYO PRO MARKET でない（月末ごとの `master_hist` を時点でさかのぼって当てる）、普通株（5桁コードの末尾が 0）、20営業日平均の売買代金が 0.1億円（1,000万円）以上 |
| 価格 | 調整済み終値（`AdjC`）。分割・併合をまたいでも下落と数えない |
| **下がった** | **その日の終値が、直近20営業日（その日を含む）の終値の最高値から −15% 以下**。判定はその日の終値で行う |
| 間引き | 同じ銘柄は、該当した日から20営業日は数えない（ブレイク予測の `BREAKOUT_COOLDOWN` と同じ）。−15% を割り込んだ最初の日が1件になる |
| 市場の下げ（別の列） | `mkt_chg` = 銘柄の20日高値の日から当日までの TOPIX の騰落率。`excess` = (1 + 株価の下落率) / (1 + `mkt_chg`) − 1（市場の分を除いた個別の下げ）。**判定には使わず**、後で分けて見るための列 |
| トレンド（別の列） | **下げる前の t−20 で測る**。上昇 = t−20 の終値 > 200日線 かつ 200日線が20営業日前より上 / 下降 = t−20 の終値 < 200日線 かつ 200日線が20営業日前より下 / 混在 = どちらでもない / 不明 = 200日線が引けない（上場から日が浅い）。**母集団は分けずに両方とも残す** |
| 決算（別の列） | 決算予定日（`earndate` の `SchDate`。休日なら次の営業日）が t−4〜t に入るか。**判定には使わず、外さない**（この列は運用者に選んでもらっておらず、置き方は仮。変えるなら次の段階で） |

### なぜこの形か

- **20日高値からの下落率**: 戻ったときに取れる幅と直結する。−15% から高値に戻れば +17.6%。売りの指値をブレイク予測と同じ
  +10% にすると、下げの約2/3を戻した水準（高値から −6.5%）にあたる
- **窓が20営業日（約1か月）**: 米国株の古典的な実証では、1週〜1か月の騰落は次の期間に反転しやすく
  （[Jegadeesh 1990, Journal of Finance 45(3)](https://econpapers.repec.org/RePEc:bla:jfinan:v:45:y:1990:i:3:p:881-98)・
  [Lehmann 1990, Quarterly Journal of Economics 105(1)](https://ideas.repec.org/a/oup/qjecon/v105y1990i1p1-28..html)）、
  3〜12か月の騰落は続きやすい（[Jegadeesh & Titman 1993, Journal of Finance 48(1)](https://ideas.repec.org/a/bla/jfinan/v48y1993i1p65-91.html)）。
  窓を長くするほど「反転」より「続落」の領域に入る。日本株のこの母集団で同じことが言えるかは測っていない
- **固定 %**: 売りの指値（+10%）と同じ物差し。ボラ換算（σ）にすると、市場全体が急落した日に件数が偏る（§3）
- **市場の下げを含める**: 2024-08-05（TOPIX が1日で −12.2%）のような日も1件として残し、`mkt_chg` で後から分ける
- **トレンドを下げる前に測る**: 下げた日に測ると、下げそのものが200日線を割らせる。下げる前に上昇トレンドだった銘柄の
  39.5% が、該当した日には200日線の下にいた

## 2. 採用した定義の件数（2018-01-04〜2026-11-20、2,167営業日）
