# 会計フローグラフ研究 — 結論と経緯（2026-09-23 時点）

この研究ラインは、上場企業の決算（PL・BS・CF）を勘定科目の流れのグラフとして表し、
決算発表後の**ベンチマーク控除後リターン**を3クラス（下落 / 中立 / 上昇、±2%）に
分類できるかを調べたものです。この文書は、ここまでの結果をまとめて区切るためのものです。
数字はすべて、下に挙げた自動生成の文書（GitHub Actions で実データから作ったもの）から転記しています。

## 結論

1. **会計情報だけで、決算後20営業日の超過リターンはわずかに予測できる。ただし損益には結びつかない。**
   最良の AUC は 0.558 前後（当て推量は 0.5）。一方、コスト（往復30bp）を引いた損益は、
   ほぼすべてのモデルで Sharpe がマイナスだった。
2. **GNN（GraphSAGE + GRU）は、平らな特徴量の LightGBM に有意に負けた。**
   AUC の差は −0.0098、95%区間 [−0.0149, −0.0047]。事前に決めた基準で「ベースラインのほうが良い」。
3. **グラフにした効果（エッジ）も、8四半期の時系列の効果も、GNN の中では検出できなかった。**
   差はエッジが +0.0023、時系列が +0.0014 で、どちらも95%区間が0をまたいだ。
4. **EDINET の明細（売上原価・販管費・減価償却費・運転資本など）は、取得済みの106社の範囲では上積みが無かった。**
   2段構えで測っても、補正は毎回ほぼゼロになった。

したがって、この問題設定（会計フローグラフ → 決算後20営業日の超過リターン）では、
GNN を運用に進める根拠は得られなかった。

## 問題設定

| 項目 | 内容 |
| --- | --- |
| データ | J-Quants API V2（`/fins/summary`、日足、TOPIX・業種指数）。EDINET DB（有価証券報告書の明細、年1回） |
| グラフ | J-Quants の18ノード・21エッジ（売上 → 営業利益 → 経常利益 → 純利益 → 営業CF → FCF など）。EDINET の明細を足すと29ノード・37エッジ |
| 時系列 | 過去8四半期。各時点は、その日までに開示済みの値だけで組む（訂正開示は後の時点にだけ反映） |
| 目的変数 | 発表翌営業日の始値で入り、20営業日後の終値で出たときの、TOPIX 控除後リターン。+2%超 / ±2% / −2%未満 の3クラス |
| 母集団 | 20日平均売買代金 1億円以上。56,870件（2016-10-18 〜 2026-08-21） |
| 検証 | 訓練窓を伸ばす walk-forward 6本（テスト窓は 2020-10 〜 2026-08）、Purge / Embargo つき |
| 区間 | 発表日単位のブートストラップ 1,000回の95%区間（同じ日の銘柄は地合いを共有していて独立ではないため） |

`/fins/details`（明細）は 403 で取れなかったので、J-Quants 側のグラフは粗い科目までです。
CF は 2Q と通期にしか開示されないので、1Q・3Q の CF ノードは欠測として扱いました。

## 経緯と結果

### 1. ベースライン（[`ACCGRAPH_BASELINE.md`](ACCGRAPH_BASELINE.md)）

グラフを数値の並びに潰し、logit / LightGBM / MLP で分類しました。

| 特徴量 | モデル | AUC | Sharpe（上昇判定） |
| --- | --- | ---: | ---: |
| seq（過去8四半期） | lgbm | 0.5578 | −0.95 |
| latest（当該四半期） | lgbm | 0.5538 | −1.18 |
| latest_rank（同日内の順位） | lgbm | 0.5528 | −0.45 |
| seq_rank | lgbm | 0.5531 | −0.72 |
| majority（クラス比を返すだけ） | — | 0.4744 | — |

- 同じ発表日の中で順位に直しても AUC はほぼ変わらなかったので、拾っていたのは企業規模ではありません。
- 全件買い（判定を使わない）の Sharpe は −0.91 で、どのモデルもコスト控除後の損益はマイナスでした。

### 2. EDINET の明細（[`ACCGRAPH_EDINET.md`](ACCGRAPH_EDINET.md) / [`ACCGRAPH_DIAGNOSE.md`](ACCGRAPH_DIAGNOSE.md) / [`ACCGRAPH_INCREMENT.md`](ACCGRAPH_INCREMENT.md)）

EDINET DB の取得枠（月900リクエスト）の都合で、明細が揃ったのは106社・2,923件でした。
全体に混ぜると9割以上が欠測になるので、3段階で測りました。

| 段階 | やったこと | 結果 |
| --- | --- | --- |
| 群の中で比べる | 明細ありの群だけで学習・評価し、明細ノードを出し入れ | J-Quants だけのベースラインでも AUC 0.47〜0.52。比べる土台が無い |
| 原因の切り分け | 全体で学習し、群に分けて評価 | 明細ありの群は 0.522〜0.536 まで戻った（件数の不足）。それでも流動性を揃えた対照群より 0.02〜0.05 低い（群の性質）。両方が効いていた |
| 2段構え | 1段目は全体で J-Quants だけ、2段目は明細ありの群だけで明細による補正を学習 | 補正の強さが24回すべて最大（補正ほぼゼロ）。明細あり − なし の AUC の差は logit −0.0003、lgbm +0.0002 |

- 2段構えの判定は「差が見えない」です。差の区間が ±0.002 と狭いのは補正がほぼゼロだからで、
  上積みの上限を示すものではありません。訓練データ（563〜2,121件）の中の検証で、
  明細が予測を良くする設定が一度も見つからなかった、という意味です。
- ロジスティック回帰の結果は、実行ごとに小数4桁目が揺れます（2026-09-22 と 09-23 の実行で
  −0.0004 と −0.0003）。同じデータ・同じコードでも、ランナーごとに数値計算の丸めが違うためです。
  判定や結論が変わる大きさではありません。
- 明細ありの群は、本流（78週高値の更新銘柄）の母集団の順に取得したので、大型・人気株に偏っています。
  流動性を揃えた対照群より予測しにくい理由は、この研究では突き止めていません。

### 3. Temporal GNN（[`ACCGRAPH_GNN.md`](ACCGRAPH_GNN.md)）

J-Quants の18ノード・21エッジ・過去8四半期を入力にしました。
ベースライン6本（`latest_jq` / `seq_jq` × logit / lgbm / mlp）と同じ分割・同じ行（34,812件・3,126社）で比べ、
各版を乱数3通りで学習して予測を平均しました。

| モデル | AUC |
| --- | ---: |
| `seq_jq/lgbm`（最良のベースライン） | 0.5574 |
| `latest_jq/logit` | 0.5557 |
| `latest_jq/lgbm` | 0.5533 |
| sage_gru（GNN 本体） | 0.5476 |
| sage_latest（時系列を外した版） | 0.5462 |
| mlp_gru（エッジを外した版） | 0.5453 |

| 比較 | AUC の差 | 95%区間 | 判定 |
| --- | ---: | --- | --- |
| sage_gru − `seq_jq/lgbm` | −0.0098 | [−0.0149, −0.0047] | ベースラインのほうが良い |
| sage_gru − mlp_gru | +0.0023 | [−0.0003, +0.0047] | エッジの効果は見えない |
| sage_gru − sage_latest | +0.0014 | [−0.0013, +0.0040] | 時系列の効果は見えない |

- 乱数を変えただけで、本体の AUC は 0.5421〜0.5495 の範囲で揺れました。版の違いと同じくらいの大きさです。
- 検証の損失で早期打ち切りをかけると、最良のエポックは多くが2〜9でした。学習はすぐに頭打ちになります。

## 判定基準について

どの段階でも、判定基準は実データの結果を見る前に決め、コードとテストに固定しました。
途中で基準の不備が見つかったときは、判定そのものは変えずに理由の書き方だけを直しています。

- 切り分けで「0.5 は上回るが対照群より有意に低い」形が出た。事前の2つの型のどちらにも当たらないので「判定できない」のまま、理由を「両方が効いている形」と書き分けた
- 2段構えで、合成データ（明細に情報が無い）でも区間だけだと「効く」と出た例があった。実データを見る前に、明細を入れ替えた偽の明細19回を上回ることも条件に足した
- 2段構えで補正がほぼゼロになったとき、狭い区間を「上積みの上限」と書いていたのを直した

## この結論の範囲

次の点は試していません。結論はこの範囲のものです。

- 保有期間は20営業日、控除は TOPIX だけで測りました。5・10営業日、業種指数控除では測っていません
  （ワークフローの手動実行で選べます）
- GNN もベースラインも、ハイパーパラメータ（隠れ層の大きさ、層の数、学習率、木の数など）は調整していません
- EDINET の明細は106社だけです。取得の順番が本流の母集団順なので、全銘柄を代表していません
- J-Quants の明細（`/fins/details`）は取れていません
