# 日証金（日本証券金融、taisyaku.jp）の需給データ

運用者の希望（2026-09-25）で、JPX の週次の信用残に加えて、日証金の毎日の需給データを
特徴量の候補にする。「今の目的変数（20営業日のブレイク）的にも直近の需給は大事」。

このページには**実際に確かめたこと**だけを書く。公式ページは作業環境（Claude Code）から
開けない（egress の設定）ので、(a) 検索結果に出る公式ページの記述と、(b) GitHub Actions
から叩いた実測（`research/probe_jsf.py`、`Probe JSF`）で書いている。

## 公開されているもの（公式ページの記述。検索結果で確認、2026-09-25）

- 銘柄検索で、直近7営業日より前の期間も指定して見られる。8営業日以上を指定すると CSV で
  確かめる形になる。**過去3年より前のデータは公開していない**（[よくあるご質問](https://www.taisyaku.jp/about/faq/)）
- DATA ページのファイルは直近のデータを銘柄一覧の形で載せている。過去のデータは銘柄検索で
  銘柄ごとに取り出せる（[DATA](https://www.taisyaku.jp/download/)）
- 速報は申込日の当日中（18時半過ぎ）、確報は翌営業日の11時ごろ。確報は、貸株超過株数が出た
  銘柄に翌朝の追加申込み（翌朝訂正）を反映したもの
  （[銘柄別融資・貸株残高（速報、確報）について](https://www.taisyaku.jp/about/report/)）
- サイトの掲載内容の著作権は日証金と情報提供者にあり、私的利用の範囲を超えて使えない。
  無断の改変・複製・賃貸・貸与・売買・出版・送信・放送など第三者の利用に供することを禁じる
  （各ページの注記）

## 取り込み（`research/jsf_fetch.py`、`Fetch JSF`）

| 動き | 中身 | 保存（Release `data-jsf`） |
|---|---|---|
| daily | DATA ページの残高・品貸料率・制限措置の3本。Claude の Routine が平日 13:10 JST に起動（2026-10-05 から。それまでは GitHub の cron で、実際は 17〜19時ごろだった。`docs/OPERATIONS.md`） | `jsf_balance.parquet`（申込日×銘柄×取引所区分）、`jsf_lending.parquet`、`jsf_restrict.parquet`（その日の写し） |
| history | 銘柄ごとの過去3年。1回45分（約320銘柄、1銘柄3リクエスト・間隔2秒）ずつ、母集団に多く出る銘柄から。平日は daily に続けて、土日は 10:20 JST に history だけ | `jsf_hist.parquet`（申込日×銘柄、東証） |

- 取り込み・週次学習は data-raw の全ファイルを落としてまとめて上げ直すので、同じ Release に
  置くと、その間に積んだ分を古い版で潰しうる。そのため別の Release（`data-jsf`）に置く
- 続けて5銘柄失敗したら止める（サイトが止めている・落ちているときに叩き続けない）。
  銘柄のページが無い（404）銘柄はデータ無しとして記録し、二度と叩かない
- 値の無い「－」などは欠測。桁区切りは外す。コードは J-Quants の5桁（末尾 0）にそろえる
- daily のファイルは1日ぶんしか載らない。起動に失敗した日の残高は後から DATA では取れない
  （history で埋める）
- **history の最後の日は、取った当日の速報**（試運転は 20:00 JST に取り、申込日 2026-09-25 の
  行まで入った）。確報は翌日の daily（残高）に入る。特徴量を作るときは、同じ申込日なら
  daily（確報）を優先する
- 実測（試運転 run 36126899236、2026-09-25 19:59〜20:04 JST）: daily は残高 4,756行・4,351銘柄
  （申込日 2026-09-24）、品貸料率 912行、制限措置 524行。history は30銘柄で 21,930行
  （1銘柄 731営業日、2023-09-26〜2026-09-25）、失敗0。1銘柄約8.4秒。そこで1回45分
  （約320銘柄）で区切り、50銘柄ごとに保存する

## 時点の扱い（案）

学習と予測で同じ値を使うため、**ある日 T の予測には、申込日 T−1（前営業日）の確報**を使う。
確報は T の昼（実測 12:21 JST）に出ているので、夜の予測に間に合う。当日の速報（18時半過ぎ）は
翌朝に訂正されうるので使わない（学習は確報、予測は速報、という食い違いを作らない）。

## 置き場所

運用者の決定（2026-09-25）: このリポジトリの Release に置く（のちにリポジトリを非公開にする
予定）。上の理由で data-raw ではなく `data-jsf` に置く。公開のあいだは、Actions のログに
データの値を出さない。

## 特徴量（案。過去3年がそろってから作り、§7 の手順で比べる）

時点: 取引日 T の行には、申込日が T の前営業日の確報を使う（上の「時点の扱い」）。

| 候補 | 中身 | ねらい |
|---|---|---|
| 貸借倍率 | 融資残高 ÷ 貸株残高（対数） | 週次の信用倍率（`credit_ratio`）の日次・制度信用版 |
| 融資・貸株の増減 | 5・20営業日の変化 ÷ 20日平均出来高 | 直近の買い方・売り方の積み増し |
| 差引残高 | （融資 − 貸株）÷ 20日平均出来高 | 需給の偏りの大きさ |
| 逆日歩 | 品貸料率（年率換算）、直近20営業日で逆日歩の付いた日数、最高料率に張り付いた日 | 売り方の苦しさ（踏み上げの余地） |
| 制限措置 | 注意喚起・申込制限・申込停止が掛かっているか | 過熱の目印 |

- 日証金の残高は制度信用の分だけ。貸借銘柄でない銘柄は値が無い（欠測は欠測のまま）
- 2023年秋より前の行は値が無い。比べられるのは、それ以降の検証の窓だけ

- **特徴量**: `research/jsf_features.py`（17列。貸借倍率とその変化、残高・増減・新規を20日平均出来高で割ったもの

  の確報（原則 T の前営業日。8暦日以上前は欠測）を付ける。母集団の行の 44.0%（2023年10月以降では 94.4%）に付く
- **値の確認（実験66、`research/exp/e66_jsf_eda.py`、run 37888171436）**: 残高の恒等式（前日差 = 新規 − 返済）

  値の比が中央値 1.002。制限措置の文言は「注意喚起」「申込停止」の2つ（「申込制限」は出てこない）。貸借倍率と
  週次の信用倍率（JPX）の順位相関 0.69。単独の ROC-AUC は 0.49〜0.53
