## 測り方

- **選定は本番の形**: 実験39 の腕 B2（本番の205列 `all_plus`・**205列で探索したパラメータ**・
  種3つの平均）。2026-09-27 の週次再学習から本番はこの形（`docs/MODEL_ADOPTION_RULES.md` §8）。
  基準は「3モデル 90以上」（`ops_rule.consensus`）。**選定 1,261件 / 正例率 33.2% /
  20日後 +2.29%**。実験39 の B2 と同じ数字
- **窓**: 本番の out-of-fold と同じ11窓（窓1は比べる過去が無いので除く）。
  2021-11-01〜2026-08-21、母集団 14,966件
- **値動きは買値（翌営業日の寄り）から**。1日目 = 買った日
- **確かめたこと**: ラベルを部品（到達・終盤・トレンド）から組み直すと食い違い0件。
  値動きの表から作った20日保有と物差し `ret_o1_20` の差は最大 4.4e-16
- **約定の仮定**（`tests/test_stop_loss.py` で固定）
  - 逆指値: 場中に触れたらその値。寄りの時点で割っていたら（窓を開けて割った）寄値
  - 終値判定: 終値で割ったら次に寄りが付いた日の寄値
  - 利確 +20%: ちょうど +20%（窓で飛び越えても。保守側）
  - 同じ日に損切りと利確の両方に触れたら損切りが先（保守側）
  - 手数料・スリッページ・税は入れない
- **過適合の確認**: 窓の境界を 0 / 2 / 4 か月ずらした out-of-fold を3モデルとも学習し直し、
  同じ選定・同じ規則で測った（実験26 と同じずらし方。パラメータは同じ）

## 結論を先に

1. **外れた2/3の大半は「そもそも届かなかった」銘柄。** 正例以外 66.8% のうち、
   必要な上昇率に届かなかったのが全体の 58.7%。届いたのに失速・トレンド割れで外れたのは 8.1%。
   正例以外の20日後は平均 −2.48%・勝率38%（全部が負けではない）
2. **正例はほとんど下げない。** 20営業日以内の最大下落は中央値 −1.6%。−5% に触れたのは 10.0%、
   −10% は 0.7%。正例以外は中央値 −5.6% で、23% が −10% に触れる
3. **20営業日を過ぎても持つと平均は上がる。** 20日 +2.24% → 40日 +4.47%。20日目にマイナスでも、
   次の20日で平均 +2.26%（勝率62%）戻す。1日あたりは 0.112% で変わらない
4. **損切りは平均を上げない。窓ごとにも、窓の切り方を変えても同じ。** 3通りの切り方 ×
   2つの絞り込み（全55窓）で、損切りなしを上回った窓は −5% で 11、−10% で 13、−15% で 18。
   狭い損切り（−5%・−8%・−1σ）と「5日目で切る」は一貫して損
5. **それでも −15% の逆指値は「ほぼ無料の保険」。** 発火20件以上では、3通りの切り方すべてで
   平均 +0.03〜+0.04pt。発動は取引の約5%。最悪の1件が −59.1% → −24.4%（全件）
6. **損切りが損をしたのは、2024年8月の急落を含む窓（3通りの切り方で一致）。** 急落してすぐ
   戻したので底で売らされた。効いた窓は2022年に多いが、切り方によっては効かない
   （ずらし2か月の2022年の窓では逆）。検証期間は上昇相場が長く、損切りに不利に出やすい
7. **大負け（20日で −10% 以下）は銘柄の特徴では選び分けにくい。** 母集団では「荒い・小型・
   走った後・割高」に多いが、モデルがすでに避けている。大負けの約2割は相場全体の下げと重なる。
   例外は「総資産利益率の2期変化が上位10%」で、外すと3通りの切り方すべてで平均 +0.16〜+0.27pt
   （§7-1）。ただし列の選び方に先読みがあるので、まだ採らない
8. **運用者の出口案（+20% の指値・20日目にマイナスなら建値に戻るまで待つ）は、回転が落ちて
   年率が下がる。** 20日目にマイナスで持ち越すのが約4割。3枠での保有は 19日 → 26〜32日、
   取引は月 2.0〜2.4回 → 1.6〜1.8回。年率は6通り中5通りで「+20%指値・20日目」より低い
   （残り1つはほぼ同じ）。1取引の平均は +0.3〜0.7pt 上がるが、1日あたりは下がる（§8）
9. **+20% の指値は平均を下げる。最も良いのは「20日目の終値で売る」。** 1取引で6通りすべて
   −0.36〜−0.63pt、枠3の年率でも6通りすべてで下回る。選定した銘柄は +20% に届いた後も
   伸びる（`docs/MODEL_EXIT_RULES.md` と同じ理由）。実験32 の「上位1〜2件なら +20% 利確は
   持ち切りと同等かやや上」は、腕 B2・枠3の模擬では再現しなかった
10. **月2回の利確・月利10% は、出口の設計では届かない。** +20% に届くのは取引の約9%
    （枠3で月0.1〜0.3回）。月利の平均は最も良い出口でも 1.0〜3.5%。
    月利 ≈ 稼働率 × 21日 × 1取引の1日あたりの損益 で、10% には「20日で平均 +10〜13%」が要る
    （今の選定は +2.6〜3.8%）
11. **+10% で売っても結論は変わらない。選んだ銘柄は短期で跳ねやすいわけではない。**
    20営業日以内に +10% に届く割合は全ブレイクと同じ（約31〜33%）、+20% はむしろ少ない
    （8〜9% 対 11%）。強みは +10% に届いた後も伸びること（20日目に平均 +12.6〜13.1%。
    全ブレイクは +10.5% で止まる）で、+10% の指値はそこを切る。1取引で9通りすべて
    −0.5〜−1.3pt。枠3の年率は、本番と同じ窓では +10% が上だが、窓をずらした4通りでは
    すべて下（§9）

- 手数料・スリッページ・税は入れていない。損切りや利確で回転が上がると、そのぶん不利になる

- 建値で売る出口（§8）は、手数料を入れると 0% ではなく小さなマイナスになる
