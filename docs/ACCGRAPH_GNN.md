# 会計フローグラフ — Temporal GNN（GraphSAGE + GRU）

`research/accgraph/gnn.py` の出力。**実行した結果のみ**を載せる。

## 結論

**ベースラインのほうが良い**。sage_gru − 最良のベースライン（`seq_jq/lgbm`）の AUC の差は -0.0098 [-0.0149, -0.0047]。
エッジを外した版との差は +0.0023 [-0.0003, +0.0047]（エッジの効果は見えない）。
時系列を外した版との差は +0.0014 [-0.0013, +0.0040]（時系列の効果は見えない）。

## 条件

- ベンチマーク: TOPIX控除 / 20営業日（発表翌営業日の始値でエントリー）
- 母集団: 流動性1億円以上の全銘柄。比べた行 34,812件・3,126社（2020-10-19 〜 2026-08-21）
- クラス比: 下落 44.6% / 中立 20.2% / 上昇 35.2%
- 分割: 訓練窓を伸ばす walk-forward 6本（Purge / Embargo つき）。全モデルで同じ分割・同じ行
- GNN の入力: J-Quants の18ノード・21エッジ、過去8四半期。乱数 [0, 1, 2] の予測確率を平均
- GNN の設定: {'hidden': 32, 'layers': 2, 'id_dim': 8, 'dropout': 0.1, 'lr': 0.002, 'weight_decay': 0.0001, 'batch_size': 512, 'max_epochs': 25, 'patience': 4, 'min_epochs': 5, 'val_frac': 0.15, 'clip': 5.0}
- 区間: 発表日単位のブートストラップ 1,000回の95%区間
- 取引コスト: 往復 30bp（バックテストは参考）

## 読み方

- 採ったエポックが毎回1〜2なら、学習がすぐ過学習に入っている。検証の損失が最初から下がらない（信号が弱い）か、モデルが大きすぎる。
- ベースラインは `latest_jq`（当該四半期のみ）と `seq_jq`（過去8四半期）。どちらも J-Quants のノードだけで、GNN と同じ情報を平らに並べたもの。
- 損益は判定に使っていない。20営業日保有だと独立な期間が少なく、運の影響が大きいため。
