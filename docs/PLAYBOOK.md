# 運用手順（実測にもとづく現時点のベスト）2026-09-22

ここまでの実験（`docs/MODEL_SELECTION_EDA.md` 実験29 / `docs/MODEL_DAY_REGIME.md`
実験30・31 / `docs/MODEL_EXIT_RULES.md` 実験32 / 実験33）から組んだ手順。
**すべて out-of-fold（2021-11〜2026-08、14,966件）の実測で、将来の保証ではない。**

## 1行でいうと

**発火の多い日に、3モデルが揃って高く評価した銘柄を1〜2件だけ、翌朝の寄りで買う。
+20% の指値を置き、届かなければ20営業日で降りる。**

## 毎日の手順

### 1. 候補を見る（終値後）

母集団は 78週ぶりの高値更新日（ETF除外・流動性フィルタ済み）。1日平均12.5件。

### 2. その日を取るか決める

| その日の発火数 | 判断 | 根拠 |
|---|---|---|
| 7件以下 | **見送る** | 上位2件でも +0.02%、−10%割れが 11.9%（実験31） |
| 8〜19件 | 取ってもよい（平均 +1.8〜2.0%） | 枠が空いていれば |
| **20件以上** | **本命** | 選定銘柄の持ち切り +3.60%、正例率39% |

地合い（TOPIX の200日線）の条件は**足さない**。発火15件以上の日は100%が
200日線より上で、発火数が地合いを内包している（実験31）。

### 3. 銘柄を選ぶ

1. **3モデル（LightGBM / XGBoost / CatBoost）すべてが上位10%**（90パーセンタイル以上）
2. 通った銘柄を **「3モデルの最小順位」**（3つのうち最も低い順位が高い銘柄 =
   3モデルが揃って高く見ている銘柄）で並べる
3. **上位1〜2件**を買う

**lgbm 単体の順位で並べてはいけない。** 2番手が +0.87% まで落ちる（最小順位なら
+2.99%）。lgbm の順位と収益は対応していない（実験31）。

### 4. 買う

**翌営業日の寄り**で成行。当日終値では買えない（候補が判明するのが終値後）。

### 5. 売る

- **+20% の指値**を置く。到達は約1割、届くときの中央値は11〜12営業日
- 届かなければ **20営業日で手仕舞い**
- 損切りは**未計測**（下位10% が −6.7%、最悪 −26%）。入れるかは別途判断

### 資金枠を固定したとき（信頼度: 低。51取引しかない）

枠2・+20%利確・発火20件以上・上位2件で、4.8年の out-of-fold を回すと:

| 項目 | 実測 |
|---|---|
| 信号 233件 のうち取れた | **51件（22%）** |
| 年間の取引 | 10.7件 |
| 1取引の平均 | +3.92%（勝率61%） |
| 資産 | 2.43倍（年率 +20.4%） |

**この年率は当てにしないこと。** 51取引・4.8年で、1取引の標準誤差が 1.2pt ある。
枠を3にすると 72取引・年率 +18.6%、枠1だと 27取引・年率 +22.2% と、
**取れた取引がどれだったかで大きく動く**。信号が同じ日に固まるので、
枠が埋まっていて8割を見送る点も効いている。

枠を増やすほど信号を拾えるが、1枠あたりの資金は減る。**枠3〜5 が現実的**。

## 測って「やらない」と決めたこと

| やらないこと | 理由（実測） |
|---|---|
| lgbm 単体の順位で上位2件 | 2番手 +0.87%（最小順位なら +2.99%） |
| 地合いのフィルタを別途足す | 発火15件以上の日は100%が200日線より上。重複 |
| +5% / +10% の早い利確 | 平均が 1.0〜1.9pt 下がる。到達組は持ち切りなら +13.1% |
| 発火の少ない日を狙う | 最大上昇は大きい（+18.3%）が持ち切り +0.24%、−10%割れ 17.7% |
| 発火26件以上で切る | 取引が減りすぎる（年26件→枠2で実際は7件）。20件のほうが上 |
| 単一モデルだけで選ぶ | lgbm95 単体の「片方だけ」群は正例率 23.0%・+0.53% |

## 前提・注意

- 買値は分割調整後の翌営業日始値。+20% 到達は高値がその水準に触れたかで判定。
  指値が約定する前提で、スリッページ・板の薄さ・手数料・税は**含まない**
- スコアは種3つの平均。本番は単一種なので、実運用の選定はこれよりばらつく
  （同一設定で種を変えると正例率が 27.5〜29.1% に散る。実験25）
- **直近は候補が少ない。** 本番の画面と同じ基準（out-of-fold 全体に対する百分位）
  では 2026年の選定率は 0.9%（2024年は 8〜10%）。2025年に高スコアが集中して
  基準が上がっている。候補ゼロの週が半分ある前提で構える
- 「発火20件以上」「上位1〜2件」「+20%」はいずれも**結果を見てから選んだ線**。
  1取引あたりの差は統計的に有意ではない（発火26件以上・上位1件と全日・上位1件の
  差は z ≈ 0.99）。**方向**（発火が多い日ほど良い・3モデル合議が効く・
  早い利確は損）は複数の切り口で一貫しており、そちらは信頼してよい
