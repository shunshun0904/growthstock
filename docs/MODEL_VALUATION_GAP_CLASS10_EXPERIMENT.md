# 理論株価特徴量とLightGBM固定+10%分類：実験132追補

2026-11-15。**直近2窓・7群の固定設定／個別再探索を完了。本番は変更しない。**

[ランキング結果](MODEL_VALUATION_GAP_EXPERIMENT.md)とは目的変数・主指標を分けて評価した。

## 結果の解釈

**今回の直近2窓では、LightGBMの固定+10%分類でも、理論株価系列を追加して主指標PR-AUCが一貫して改善する結果にはなりませんでした。**

各群を再チューニングした全評価行の2窓平均は、既存A=0.27693、元指標B=0.27399、
EVA乖離C=0.27488、EVA時系列D=0.27267、RIM追加R=0.27478。
シャッフル対照P=0.27740、価格・PER・PBR対照M=0.27354でした。
D−Aは−0.00426、R−Aは−0.00214で、いずれも主指標で既存群を下回ります。

Rの上位10%適合率は30.99%で、Aの30.78%より0.21ポイント高い一方、
前半は27.31%対22.22%、後半は34.67%対39.33%と符号が変わります。
Dの上位10%適合率は29.34%でAを下回りました。
DのAP差は前半+0.00768・後半−0.01619、Rは+0.00953・−0.01381で、期間間で改善が続きません。

上位10%の20日終値収益はA=3.398%、D=3.826%、R=4.072%ですが、P=4.447%を下回ります。
D/Rの収益差も前半は改善、後半は悪化しました。収益の平均だけで理論価値情報の追加効果とは解釈しません。
ROC-AUCはD=0.60521、R=0.60551、A=0.59922と上がりますが、主指標APと上位の適合率を合わせた一貫した改善はありません。

共通行ではRのAP=0.27169がA=0.27017を少し上回る一方、P=0.27399、M=0.28003には届きません。
CもAより+0.00026、Dは−0.01030で、算出可能集合に限定しても理論株価系列の優位性は未確認です。
水準追加CはB比で全行APが両窓とも小幅に上がります（平均+0.00089）が、既存Aは下回ります。

補助の学習なし割安順では、共通行のAPはEVA=0.19771、RIM=0.19375で、同じ集合のA=0.27017を下回りました。
前回のリターン順位の結果を、固定+10%・終盤条件の識別力へ一般化しません。

固定設定でも全行APはA=0.28415、D=0.28233、R=0.27885。
元指標Bは0.28591とAより小幅に高いものの、再探索では下回り、安定した改善とは扱いません。
再探索が固定設定を必ず上回るわけではなく、外側結果を見て固定／再探索のどちらかを選び直していません。

結論は、**本番は現状を維持し、この追加特徴量は研究用のまま残す**です。
評価は全行3,654件、両ギャップがある共通行1,446件。既参照の2窓であり、新しい独立検証ではありません。
現在の本番重みを過去へ適用した精度ではなく、本番と同じ+10%定義・クラス重みの研究モデルを各窓で再学習した比較です。


## 条件・目的変数

本番`label_specs.for_model("lgbm")`と同じ固定+10%分類。
翌営業日寄り基準、20営業日以内の終値で+10%到達、20営業日目の直近5日平均終値が買値の+5%以上、同日のMA5≧MA20。
保存済み22,110行・3,748銘柄のラベル再計算は元ラベルと全件一致し、正例4,067件（18.394%）。
これを各訓練・評価期間に分けるため、全体正例率をクラス重みに使わない。

前回と同じ元マート・理論価値特徴量・価格ラベルを使用した。
評価は固定+10%ラベル・20日終値収益・結果確定日が有効な同一行に限る。
外側は36か月訓練・6か月評価、最後の2窓。20日結果が評価開始前に確定した訓練行のみを使用した。
各7群・各窓に同じ30候補、内側3窓のAverage Precisionで個別に設定を選び、全14設定凍結後に外側を採点した。
内側1,260論理適合、最終比較は固定／再探索それぞれ14条件×3種（42適合分）。最終種42/43/44の予測を平均し、木200本で揃えた。
訓練ラベルだけから本番同様の`scale_pos_weight`を計算した。
理論株価側のERP・成長率・収束期間は事前のシナリオを維持した。

| 群 | 内容 |
|---|---|
| A | 既存373特徴量 |
| B | A＋資本効率・簿価WACC・品質 |
| C | B＋現金区分なしEVAのギャップ等 |
| D | C＋ギャップの時系列 |
| R | A＋外生RIMの入力・ギャップ・時系列 |
| P | Dの数値を日付内・欠損パターン内で入れ替えた対照。品質は保持 |
| M | B＋価格・PER・PBRの時系列対照 |

主指標PR-AUCはAverage Precision（AP）で、台形積分ではない。
上位10%は**窓内全レコードのスコア順位**で、日次上位10%やライブ固定閾値の検証ではない。
重み付き分類器のスコアを校正済みの到達確率とみなさない。
分類APでは1日に5銘柄以上というランキング評価の制限は適用しない。
全行と共通行は同じ訓練済み予測を絞り直して採点し、各集合内でAとの差を読む。
以下の主表は2窓の単純平均で、全行をプールしたPR-AUCではない。

## 検証・制約

全28個別予測ファイルのCode/Date・ラベル・20日収益・共通行フラグ一致、
AP/ROC/適合率/収益の再計算、全420候補の3内側スコアと最良設定を照合した。
固定／再探索の入力・ライブラリ・コード指紋一致、本番23ファイル不変、過去ランキング62出力の不変も確認した。
環境再接続で外側評価が中断したため、保存済みCVを再利用し同じ設定で外側を再実行した。中断前11条件の予測が再現されることも照合した。
新CLIは`--tasks class10`。既存の引数なしLTR、従来`--classification`の3タスクの挙動は保つ。

保存APIの事後訂正原本は未照合。E120/E121で既参照の期間であり、新しい独立ホールドアウトではない。
EVAは年次財務、RIMはTTMで、利益・資本の定義や情報鮮度が異なる。
現金区分なしEVAは現金を控除も別途加算もしない近似で、欠損現金を0に補完したものではない。
上位10%収益は個別ラベル平均で、資金配分・保有重複を扱う運用損益ではない。

[採否規則](MODEL_ADOPTION_RULES.md)に必要な複数モデル・複数窓切り方等の確認を満たした判定ではなく、本番採用は行わない。
