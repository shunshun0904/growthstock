## 読み方

- 相関が高くても2位と僅差なら同定できていない。業種どうしは
  もともと相関するので、1位だけを見て決めてはいけない
- 業種コードの意味は `research/build_dataset.py` の `encode_category` と
  `master_hist` の生の値を参照。ここでは API が返した値をそのまま使う
- 手元の系列は東証の指数と算出方法が違う（浮動株調整をしていない、
  構成銘柄の出入りを再現していない）。完全一致は期待できない
