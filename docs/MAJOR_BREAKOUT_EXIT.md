# 本ブレイク予測モデル: 利確+30%・98%超と「下落が先」（m03・2026-09-23）

`research/exp/m03_major_exit.py` / Actions の Run Experiment（run 35858531142）。
前提は `docs/MAJOR_BREAKOUT_TUNE.md`（m02。点数は §1 で探索したパラメータの3モデル）。

運用者の依頼:
「利確タイミングを30%にしてほしいです。それと思った以上に対象銘柄があるので、3モデルとも、98%超えで
購入銘柄を絞るとどうなりますか？」
「「上下におおきく動く銘柄」を拾う。下落が先に来てしまうものも拾ってしまうということですよね？
それをファンダメンタルズや、信用倍率等で拾いたいのですが。」

## 結論

1. **98%超で買い、+30%で利確すると、1取引の平均は −1.3% / +3.1% / −1.3%（窓の区切りを 0 / 2 / 4 か月
   ずらした3通り）。** +30%に届くのは 50〜57%（届くまで中央値 12〜16営業日）で、勝率は 53〜59%、
   中央値は +26〜+30%。ただ届かなかった半分近くは平均 −33% 前後で終わるので、平均はほぼゼロになる
2. **98%超に絞っても、1取引の成績は95%超とほとんど変わらない**（95%超・+30%の平均は
   −1.2% / ±0.0% / +0.3%）。件数は月 9.5件 → 月 2.6〜3.6件になる
3. **2倍で売るのと比べても、+30%で利確して平均が上がるわけではない**（98%超・2倍は +2.0% / +8.3% / −1.5%）。
   ブレイクを全部買って +30%で利確すると +5.8〜+6.3% で、モデルで選ぶよりこちらが高い。
   一方、日次ボラの上位2%を買って +30%で利確すると −7.1〜−7.4% で、モデルはこれより 6〜10pt 良い
4. **「下落が先」はそのとおりで、98%超の候補の 56〜62% は +30% より先に −20% に触れた。**
   触れるまでは中央値 7〜8営業日と速い。そのうち後から +30% に戻るのは2割前後（20〜24%）。上下どちらかに先に
   触れたものの中で「上が先」は 37〜44%。ブレイク全件では 52% なので、モデルの候補は普通のブレイクより
   下に先に動きやすい
5. **+30%で利確・−20%で損切りなら、損益がとんとんになる「上が先」の割合は40%。** 候補はちょうどその辺り
   （37〜44%）にいる。損切りを置いた場合の平均は −0.7% / +1.6% / −2.0%
6. **信用倍率では見分けられない**（「上が先」を分ける AUC 0.499。0.5 が見分けられない）。
   信用残を出来高と比べた重さ・買残の増え方・日々公表の比率も 0.495〜0.540（期間別でも 0.47〜0.55）。
   1列だけ見たときの偶然の幅（±0.032）を少し超えるのは信用買残 ÷ 出来高（0.540、買残が多いほど上が先）だけで、
   167列の中で偶然に出る最大の幅（±0.087）の中
7. **ファンダメンタルズは弱い傾向だけ。** 割安（PER・PBR・PSR が低い、利益・純資産・売上・配当の利回りが高い）、
   上方修正が多い・下方修正が少ない、売上の伸びが大きいほど、「上が先」がわずかに多い（AUC 0.54〜0.58、
   逆向きは 0.43〜0.45）。ただ167列を調べた中で偶然に出る最大の幅（±0.087）は超えず、割安さの傾向は
   2023年11月以降の窓では弱い
8. **ファンダ・信用の171列で「上が先か」を学習したモデルでも、98%超の候補の中では見分けられない**
   （AUC 0.497〜0.522）。95%超の候補では 0.55〜0.58 で、上側に分けた方が平均 +2.5〜+3.4pt 良かったが、
   理由は「上が先」が増えたからではなく大負けが減ったから（最悪 −54〜−57% 対 −78%）で、上側は
   月 0.8〜2.7件しかない

## 測り方

- **点数**: m02 §1 で探索したパラメータ（`research/major/params_v3.json`）の LightGBM / XGBoost / CatBoost を、
  窓ごとにテスト開始の121営業日前まで学習し直した out-of-fold（種3つの平均）。95%超・2倍の結果は m02 §8 と
  同じ数字になった（512件・平均 +2.1%）
- **買う**: 3モデルがそろって「それより前の窓の点数」の98%点（または95%点）を超えた銘柄を、ブレイク翌営業日の寄りで
- **売る**: 場中の高値が +30%（または2倍）に届いたらちょうどその値で売る（指値）。届かなければ120営業日目
  （買った日が1日目）の終値。途中で上場廃止したら最後の終値。手数料・税なし
- **参考の損切り（+30%/−20%）**: 場中の安値が −20% に触れたら −20% で売る。その日の寄りがすでに −20% を
  割っていたら寄りで売る。同じ日に両方に触れたら損切りが先とみなす（控えめ）。依頼ではなく、「下が先」の
  痛さを見るための比べ物
- **上下どちらが先か**: 買値から +30%（場中の高値）と −20%（場中の安値）のどちらに先に触れたか（120営業日）
- **ファンダ・信用の列**: 205列から株価・出来高・地合いで作る列（price / breakout / volume / sector_index /
  market / flow と log_trading_value）を外した168本に、信用残から作った3本（`research/major/margin_feats.py`）
  を足した171本
  - `m_long_days` 信用買残 ÷ 直近20営業日の平均出来高、`m_short_days` 信用売残 ÷ 同じ平均出来高、
    `m_long_chg4` 信用買残の4週前からの変化率。株数は分割を調整してそろえ、週次の記録日（金曜）から6日
    たってから使う（公表前の値を使わない）
- **1列ずつの分離力（§3）**: 3モデルの点数（前の窓の中での位置の平均）が90%以上で、上下どちらかに先に触れた
  1,311件（上が先 42.3%）。列は窓の中の順位にして AUC を測る。偶然の幅は、窓の中でラベルを200回入れ替えて測った
- **方向モデル（§4）**: 売買を数えられるブレイクのうち上下どちらかに先に触れた行で「上が先（1）/ 下が先（0）」を
  学習（LightGBM・m02 のパラメータ・種3つ）。候補を「前の窓の点数の中央値より上 / 以下」に分けた
- **窓の区切り**: 0 / 2 / 4 か月ずらした3通り。テスト開始が 2023-11-01 以降の窓は探索に一度も使っていない

## 読み取り

1. **モデルは「大きく動く銘柄」は選べているが、向きは選べていない。** 上下どちらかに先に触れた中で「上が先」は
   98%超で 37〜44%、ブレイク全件の 52% より低い。+30%/−20% のとんとんの線（40%）の上下にいる
2. 98%超に絞っても、95%超から1取引の成績はほとんど変わらない。**しきい値を上げても「向き」は良くならない**
3. 日次ボラの上位2%を買うよりは、モデルで選ぶ方がはっきり良い（+30%で利確して平均 6〜10pt 上）。
   モデルは荒さだけでなく何かを足しているが、それでもブレイクを全部買う（+5.8〜+6.3%）には届かない
4. **信用倍率は「下が先」を見分けない。** ファンダメンタルズは「割安・上方修正・売上の伸び」の側に弱い傾向があるが、
   167列を調べた偶然の幅の中で、2023年11月以降の窓では割安さの傾向が弱い。これだけで候補を絞るのは根拠が足りない
5. 探索と重なる窓（2021-11〜2023-10）は3通りとも平均 −4〜−5%、使っていない窓は +0.3〜+7.4%。
   期間による差が大きく、どちらか一方だけを見て判断すると外す
